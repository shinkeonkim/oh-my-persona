# T13 — 1인칭 페르소나·관리 콘솔·메신저 UI

상태: DOING (구현 완료, 운영 배포 검증 대기)
선행: T12

## 목표

1. 챗봇은 김신건을 설명하는 제3자가 아니라 김신건 본인으로 정중하게 답한다.
2. 일반 화면은 모바일과 PC에서 익숙한 메신저형 말풍선 UI를 제공한다.
3. 관리자는 별도 토큰으로 패키지 검색 청크와 관리 지식을 확인한다.
4. 관리 지식은 PostgreSQL에서 CRUD하며 활성 자료는 즉시 검색과 답변 근거에 반영한다.
5. 관리자는 저장된 대화 목록과 전체 메시지를 조회한다.

## 보안 경계

- `/admin` 화면은 공개될 수 있지만 모든 관리 API는 `PERSONA_ADMIN_TOKEN` Bearer 인증을 요구한다.
- 토큰은 브라우저의 현재 탭 `sessionStorage`에만 저장하며 일반 채팅 번들에는 포함하지 않는다.
- 관리 지식은 `https://` 근거 URL을 필수로 하고 `active` 자료만 검색한다.
- 패키지 청크는 재현 가능한 빌드 산출물이므로 관리 화면에서 조회만 하며, 실시간 CRUD 대상은
  PostgreSQL 관리 지식으로 분리한다.

## 완료 기준

- 1인칭·존댓말 프롬프트 회귀 테스트가 통과한다.
- 미인증 관리 API가 401을 반환한다.
- 지식 생성·수정·검색 반영·삭제와 대화 조회 테스트가 통과한다.
- 운영에서 관리자 로그인, CRUD, 대화 상세, 실제 1인칭 답변을 확인한다.
