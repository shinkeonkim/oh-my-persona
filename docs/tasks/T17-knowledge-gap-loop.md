# T17 — 질문 기반 지식 공백 탐지·보강 루프

상태: DOING
선행: T16

## 목표

1. 질문별로 현재 corpus의 근거량, 출처 다양성, 직접 답변 유무를 측정한다.
2. 공백이 큰 질문부터 김신건이 직접 답하고 날짜·공개범위·근거 URL을 검토한다.
3. 답변을 corpus로 승격한 뒤 같은 분석을 반복해 공백이 실제로 줄었는지 확인한다.
4. 운영 대화에서 반복되지만 제대로 답하지 못한 질문을 다음 질문지 후보로 수집한다.

## 순서

1. `persona knowledge-gaps`로 `empty`, `single_source`, `indirect_evidence`를 분류한다.
2. 생성된 private 답변 template에서 상위 질문 5~10개에 직접 답한다.
3. 공개 가능성과 개인정보를 검토한 항목만 `visibility: public`으로 바꾼다.
4. `build-answers → chunk → audit → evaluate → knowledge-gaps`를 실행한다.
5. 관리자 대화 기록에서 무근거 답변, 반복 질문, 사용자의 정정 요청을 주기적으로 검토한다.
6. 새 질문은 기존 질문과 중복 제거 후 질문지에 추가하고 같은 루프를 반복한다.

## 공백을 찾는 신호

- 검색 결과 0개 또는 인용 가능한 URL 0개
- 하나의 출처에만 의존
- 프로젝트의 결과는 있으나 본인의 역할·판단·수치·날짜가 없음
- 과거 기록은 있으나 현재 관점이 없음
- 챗봇이 정중하게 모른다고 답했거나 사용자가 사실을 정정함
- 같은 의미의 질문이 여러 대화에서 반복됨

## 완료 기준

- 공백 보고서와 private 답변 template이 재현 가능하게 생성된다.
- 공개 답변은 본인 직접 진술 source와 답변일을 가진다.
- AI가 만든 추정 사실은 corpus에 자동 승격되지 않는다.
- 최소 1회 보강 전후의 상태 변화가 보고서로 확인된다.
