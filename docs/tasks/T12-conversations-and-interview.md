# T12 — 대화 기억·속도 제한·본인 인터뷰

상태: DONE (운영 배포, 서버 복원, 실제 모델 대화, 429 검증 완료)
선행: T11

## 목표

1. 브라우저가 `conversation_id`를 보관하고 서버가 대화 이력을 PostgreSQL에 저장한다.
2. 최근 대화를 검색 질의와 LLM 프롬프트에 포함해 후속 질문을 이해한다.
3. 공개 채팅 API에 원 IP를 저장하지 않는 분산 속도 제한을 적용한다.
4. 50개 로컬 질문지와 공개 범위 검토 절차로 1인칭 자료를 점진적으로 보강한다.

## 실행 순서

1. migration과 저장소 단위 테스트
2. 동기·SSE API의 생성, 복원, 후속 질문, 404, 429 테스트
3. 질문지 답변 validation과 민감정보 검사
4. 이미지 빌드 후 `oh-my-homelab`에서 digest·환경변수·SOPS secret 갱신
5. 두 개 이상의 Pod를 오가는 대화 복원과 속도 제한을 운영에서 검증

## 완료 기준

- 새로고침 후에도 대화가 복원된다.
- 후속 질문이 직전 사용자 문맥을 검색과 생성에 반영한다.
- 설정된 시간창의 요청 수를 넘으면 `429`와 `Retry-After`가 반환된다.
- 답변하지 않은 질문이나 `public=false` 답변은 corpus에 들어가지 않는다.
- 질문지 산출물도 source URL, 관측일, 공개 등급을 유지한다.

- 별도 조회 요청에서 네 메시지의 역할 순서가 `user/assistant/user/assistant`로 복원됐다.
