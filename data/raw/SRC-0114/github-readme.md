# HomeWarpPlugin

## 간단한 요약

플레이어가 원하는 위치를 개인 홈으로 등록해두고 `/home`으로 순간이동하거나, 운영자가 등록한 서버 공용 워프 지점으로 이동할 수 있게 해주는 Paper 플러그인입니다.

## 설명

- **홈 기능**: 플레이어는 `/sethome`으로 현재 위치를 자신의 홈으로 저장하고, `/home`으로 그 위치에 순간이동할 수 있습니다. 이름을 지정하면 여러 개의 홈을 만들 수 있으며, 이름을 생략하면 `home`이라는 이름의 기본 홈을 사용합니다.
- **홈 개수 제한**: 플레이어 한 명당 최대 3개(`MAX_HOMES_PER_PLAYER` 상수)의 홈을 만들 수 있습니다. 이미 존재하는 이름으로 다시 `/sethome`을 실행해 덮어쓰는 것은 개수 제한에 걸리지 않지만, 새 이름으로 4개 이상 만들려고 하면 거부됩니다. 권한 노드로 이 제한을 플레이어별로 확장하는 기능은 아직 구현되어 있지 않습니다.
- **워프 기능**: 운영자(기본적으로 OP)는 `/setwarp <이름>`으로 서버 공용 워프 지점을 등록할 수 있고, 모든 플레이어는 `/warp <이름>`으로 그 지점에 순간이동할 수 있습니다. 워프 개수 제한은 없습니다.
- **목록 조회**: `/homes`로 자신이 등록한 홈 이름 목록을, `/warps`로 서버에 등록된 전체 워프 이름 목록을 확인할 수 있습니다.
- **순간이동 방식**: 홈/워프 이동 모두 `Player#teleportAsync`로 비동기 순간이동을 사용합니다. 텔레포트 전 안전 지점(용암/공중 등) 검사나 쿨다운/딜레이, 이동 시 텔레포트가 취소되는 조건 등은 구현되어 있지 않습니다 — 명령어를 입력하면 즉시 이동합니다.
- **저장 방식**: 홈은 `plugins/HomeWarpPlugin/homes.yml`에, 워프는 `plugins/HomeWarpPlugin/warps.yml`에 저장됩니다. 서버가 켜져 있는 동안은 메모리(`Map<UUID, Map<String, Location>>`, `Map<String, Location>`)에서 관리되고, 홈/워프를 추가·삭제할 때마다 즉시 파일에 저장되며 `onDisable()`에서도 다시 한 번 저장됩니다. 좌표는 월드 이름, x/y/z, yaw/pitch를 개별 필드로 풀어서 수동 직렬화합니다.
- **의존성**: 다른 플러그인에 대한 의존성은 없습니다. Paper API(`paper-api`)만 사용합니다.

## 사용 방법(매뉴얼)

### 명령어

| 명령어 | 설명 | 비고 |
|---|---|---|
| `/sethome [이름]` | 현재 위치를 홈으로 저장. 이름 생략 시 `home`으로 저장 | 플레이어당 최대 3개 |
| `/home [이름]` | 저장된 홈으로 순간이동. 이름 생략 시 `home` 홈으로 이동 | |
| `/delhome [이름]` | 저장된 홈 삭제. 이름 생략 시 `home` 홈 삭제 | |
| `/homes` | 자신이 등록한 홈 이름 목록 조회 | |
| `/setwarp <이름>` | 현재 위치를 서버 공용 워프로 저장 (이름 필수) | `homewarp.setwarp` 권한 필요 |
| `/warp <이름>` | 등록된 워프로 순간이동 (이름 필수) | |
| `/warps` | 서버에 등록된 전체 워프 이름 목록 조회 | |

`/sethome`, `/home`, `/delhome`, `/homes`, `/warp`는 플레이어만 사용할 수 있으며, 콘솔 등에서 실행하면 "플레이어만 사용할 수 있습니다." 메시지가 출력됩니다. `/sethome`, `/home`, `/delhome`, `/warp`는 자신이 가진 홈/전체 워프 이름으로 탭 자동완성을 지원합니다.

### 권한 노드

- `homewarp.setwarp` (기본값: **OP**) — `/setwarp` 명령어 실행에 필요합니다.
- 그 외 명령어(`/sethome`, `/home`, `/delhome`, `/homes`, `/warp`, `/warps`)는 별도의 권한 노드 없이 누구나 사용할 수 있습니다.

### config.yml

현재 별도의 `config.yml`은 없으며, 홈 개수 제한(`MAX_HOMES_PER_PLAYER = 3`)은 소스 코드 상수로 고정되어 있어 설정 파일로 변경할 수 없습니다.

### 빌드 방법

저장소 루트에서 다음 명령을 실행합니다.

```bash
./scripts/build-plugin.sh minecraft-homewarp-plugin
```
