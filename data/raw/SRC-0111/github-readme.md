# minecraft-enhance-plugin

## 1. 간단한 요약

손에 든 무기나 방어구를 다이아몬드를 소모해 `+1`, `+2`, ... `+15` 단계까지 강화하는 플러그인입니다. 강화에 성공하면 무기는 공격력이, 방어구는 방어력이 실제로 오르고, 실패해도 아이템은 파괴되지 않고 재료만 소모됩니다.

## 2. 설명

- `/enhance` 명령으로 주 손(main hand)에 든 아이템을 강화 시도합니다.
- 강화 대상 판정
  - 무기: 아이템 이름이 `_SWORD` 또는 `_AXE`로 끝나거나, `BOW` / `CROSSBOW` / `TRIDENT` / `MACE`
  - 방어구: 아이템 이름이 `_HELMET` / `_CHESTPLATE` / `_LEGGINGS` / `_BOOTS`로 끝나는 것
  - 그 외 아이템(또는 손이 비어있을 때)은 "강화하려면 무기나 방어구를 손에 들어주세요" 메시지와 함께 거부됩니다.
- 강화 단계는 아이템의 `PersistentDataContainer`(키: `enhance_level`)에 저장되므로, 상자에 넣거나 다른 플레이어에게 줘도 유지됩니다.
- **최대 강화 단계**: `MAX_ENHANCE_LEVEL = 15`. 이미 +15인 아이템은 더 강화할 수 없습니다.
- **소모 재료**: 다이아몬드(`Material.DIAMOND`) 고정. 현재 레벨이 `N`일 때 필요 개수는 `N + 1`개입니다(예: +0 → +1 강화 시 1개, +4 → +5 강화 시 5개). 재료가 부족하면 강화가 진행되지 않고 메시지만 출력됩니다.
- **성공 확률**: 현재 레벨이 `N`일 때 `max(1.0 - 0.05 * N, 0.10)`, 즉 레벨이 1 오를 때마다 5%p씩 낮아지고 최소 10%는 보장됩니다(+0→+1은 100%, +10→+11부터는 최소치인 10%로 고정).
- 재료는 성공 여부와 무관하게 시도 시점에 먼저 소모됩니다. **강화에 실패해도 아이템 자체는 파괴되거나 강화 단계가 내려가지 않고, 재료만 소모됩니다.**
- 강화에 성공하면
  - 무기는 `Attribute.ATTACK_DAMAGE`, 방어구는 `Attribute.ARMOR`에 `AttributeModifier`(연산 `ADD_NUMBER`, 슬롯은 무기는 `MAINHAND`, 방어구는 `ARMOR`)를 부여합니다.
  - 레벨 1당 공격력/방어력 보너스는 각각 `ATTACK_BONUS_PER_LEVEL = 0.5`, `ARMOR_BONUS_PER_LEVEL = 0.5`이며, 강화할 때마다 기존 보정치를 지우고 `새 레벨 * 0.5`로 다시 부여하므로 중첩되지 않고 항상 현재 레벨에 맞는 총량으로 유지됩니다.
  - 아이템 표시 이름이 `+N 아이템이름` 형태로 바뀝니다(예: `+3 Diamond Sword`). 이 과정에서 플레이어가 미리 붙여둔 커스텀 이름은 덮어써집니다.
- 다른 플러그인에 대한 의존성은 없습니다.

## 3. 사용 방법(매뉴얼)

### 명령어

| 명령어 | 설명 |
| --- | --- |
| `/enhance` | 주 손에 든 무기/방어구를 강화 시도 (인자 없음, 플레이어 전용) |

### 권한 노드

소스코드(`EnhanceCommand`, `EnhancePlugin`)상에 별도의 권한 노드가 등록되어 있지 않습니다. 즉 `/enhance` 명령은 서버에 접속한 모든 플레이어가 기본적으로 사용할 수 있습니다.

### 설정 파일

`config.yml`은 존재하지 않습니다. `MAX_ENHANCE_LEVEL`, 재료 종류, 성공 확률/비용 공식, 레벨당 스탯 보너스는 모두 `EnhancePlugin.kt` 상단의 상수로 하드코딩되어 있으며, 값을 바꾸려면 코드를 수정하고 다시 빌드해야 합니다.

### 빌드 방법

저장소 루트에서 다음을 실행합니다.

```bash
./scripts/build-plugin.sh minecraft-enhance-plugin
```
