# 엄랭 서버 (Umjunsik Lang Server)

엄랭(Umjunsik Language)을 활용한 구현체를 추가로 구현한 간단한 HTTP 웹서버입니다. 
정적 파일(HTML, CSS 등)을 서빙할 수 있습니다.

## 프로젝트 구조

```
umjunsik-lang-server/
├── umjunsik/              # 엄랭 인터프리터
│   ├── __init__.py
│   ├── __main__.py        # 메인 엔트리포인트
│   └── runtime.py         # 엄랭 런타임 & HTTP 서버 구현
├── public/                # 정적 파일 디렉토리
│   ├── index.html
│   └── umm.html
└── server.umm             # 엄랭으로 작성된 웹서버 코드
```

## 설치 및 실행

### 요구사항
- Python 3.x

### 서버 실행

```bash
python -m umjunsik server.umm
```

서버는 기본적으로 **포트 3000**에서 실행됩니다.

### 테스트

서버가 실행되면 다음 URL들로 접근할 수 있습니다:

```bash
# 루트 경로 (index.html 반환)
curl http://localhost:3000/

# 특정 HTML 파일 요청
curl http://localhost:3000/umm.html

# 직접 index.html 요청
curl http://localhost:3000/index.html
```

또는 브라우저에서 `http://localhost:3000/`으로 접속하세요.

## 엄랭 서버 코드 설명

`server.umm` 파일에는 다음과 같은 엄랭 코드가 작성되어 있습니다:

```
어떻게
무 히려 좋아 .............................. .......... ..........
무 들어볼게
무 받았어
무 쁘지 않아
무 자식
준...
이 사람이름이냐ㅋㅋ
```

### 코드 동작 설명

1. `어떻게` - 프로그램 시작
2. `무 히려 좋아 ...` - 포트 3000으로 HTTP 서버 시작 (30 × 10 × 10 = 3000)
3. `무 들어볼게` - 클라이언트 연결 대기 및 수락
4. `무 받았어` - HTTP 요청 데이터 수신
5. `무 쁘지 않아` - 요청된 경로의 파일을 `public/` 폴더에서 찾아 응답
6. `무 자식` - 클라이언트 연결 종료
7. `준...` - 3번째 줄로 점프 (무한 루프로 계속 요청 처리)
8. `이 사람이름이냐ㅋㅋ` - 프로그램 종료

## 엄랭 HTTP 명령어

런타임(`umjunsik/runtime.py`)에서 지원하는 HTTP 관련 명령어들:

- `무 히려 좋아 <포트숫자>` - 지정된 포트로 HTTP 서버 시작
- `무 들어볼게` - 클라이언트 연결 수락
- `무 받았어 [<크기>]` - HTTP 요청 수신
- `무 쁘지 않아 [<경로>]` - 파일 응답 (경로 생략시 요청 경로 사용)
- `무 이스 <상태코드> <메시지>` - 텍스트 응답
- `무 친 판단` - 요청 정보(메서드, 경로, 버전) 응답
- `무 자식` - 클라이언트 연결 종료

## 기능

- ✅ 정적 파일 서빙 (HTML, CSS 등)
- ✅ 자동 MIME 타입 감지
- ✅ 경로 보안 (public 폴더 외부 접근 차단)
- ✅ 404 에러 처리
- ✅ 무한 루프로 다중 요청 처리
