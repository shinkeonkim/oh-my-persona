# Tombstone Plugin

Paper(1.20 API) + Kotlin 기반 마인크래프트 서버 플러그인. 플레이어 사망 시 인벤토리 아이템이 바닥에 흩어지지 않도록 "무덤"에 보관했다가 나중에 안전하게 회수할 수 있게 해준다.

## 요약

플레이어가 죽으면 드롭될 아이템을 가로채 사망 지점에 무덤(해골 머리 블록)으로 만들어 보관한다. 본인이 무덤 블록을 우클릭하면 아이템을 인벤토리로 돌려받을 수 있고, 일정 시간 안에 회수하지 않으면 무덤은 자동으로 사라지며 아이템이 바닥에 드롭된다.

## 설명

- **`DeathListener` (`PlayerDeathEvent`)**: 사망 시 드롭 목록(`event.drops`)이 비어 있지 않으면 드롭을 취소(`event.drops.clear()`)하고, 사망 위치의 블록을 `PLAYER_HEAD`로 바꿔 무덤을 표시한다. 아이템 목록과 소유자 UUID를 `TombstoneData`에 담아 `TombstonePlugin.tombstones` 맵에 저장하고(키는 월드명:x:y:z 형태의 블록 좌표 문자열, `locationKey()`), 소멸 스케줄을 등록한 뒤 사망 좌표를 안내하는 메시지를 보낸다. 같은 좌표에 기존 무덤이 남아있으면 이전 예약 작업(경고/소멸)을 취소하고 덮어쓴다.
- **`TombstoneInteractListener` (`PlayerInteractEvent`)**: 플레이어가 블록을 우클릭(`RIGHT_CLICK_BLOCK`)했을 때, 클릭한 블록이 `PLAYER_HEAD`이고 해당 좌표에 등록된 무덤 데이터가 있으면 상호작용을 취소한다. 무덤 소유자가 아니면 안내 메시지만 보내고 종료한다. 소유자가 맞으면 보관된 아이템을 인벤토리에 지급하고(공간이 부족하면 초과분은 발밑에 드롭), 예약된 경고/소멸 작업을 취소하고 무덤 데이터를 제거한 뒤 블록을 `AIR`로 되돌린다.
- **자동 소멸 (`TombstonePlugin.scheduleExpiry`)**: 무덤이 생성되면 두 개의 `BukkitTask`가 예약된다.
  - 생성 8분 후(`WARNING_TICKS`, 9600틱): 소유자가 접속해 있으면 "무덤이 곧 사라집니다! 빨리 회수하세요." 경고 메시지 전송.
  - 생성 10분 후(`EXPIRE_TICKS`, 12000틱): 무덤 데이터를 제거하고, 블록이 아직 `PLAYER_HEAD`면 `AIR`로 되돌린 뒤 보관 중이던 아이템을 전부 그 자리에 자연 드롭한다.
- **플러그인 비활성화 시(`onDisable`)**: 남아있는 모든 무덤의 경고/소멸 예약 작업을 취소하고 메모리상의 무덤 목록을 비운다(서버 재시작 시 무덤 데이터 자체는 영속화되지 않음).
- 외부 플러그인 의존성은 없다. Paper API(`api-version: '1.20'`)만 사용하며, Kotlin 런타임은 Shadow 플러그인으로 셰이딩되어 `com.example.tombstone.libs.kotlin` 패키지로 재배치된다.

## 사용 방법

이 플러그인은 별도의 명령어나 권한 노드를 제공하지 않는다(`paper-plugin.yml`에 `commands`/`permissions` 섹션 없음). 모든 동작은 이벤트 리스너를 통해 자동으로 이루어진다.

- 플레이어가 사망하면 자동으로 무덤(해골 머리 블록)이 생성된다.
- 무덤 생성자가 해당 블록을 우클릭하면 아이템을 즉시 회수한다.
- 다른 플레이어가 우클릭하면 "이 무덤의 주인이 아닙니다." 메시지만 표시되고 아이템은 지급되지 않는다.
- 생성 후 10분이 지나면 무덤은 자동으로 사라지고 보관 중이던 아이템이 그 자리에 드롭된다(소멸 2분 전인 8분 시점에 소유자에게 경고 메시지 전송).

별도의 `config.yml`은 없으며, 소멸/경고 시간은 `TombstonePlugin.kt`의 `EXPIRE_TICKS`, `WARNING_TICKS` 상수를 수정해 조정한다.

### 빌드 방법

저장소 루트에서 다음 명령을 실행한다.

```bash
./scripts/build-plugin.sh minecraft-tombstone-plugin
```
