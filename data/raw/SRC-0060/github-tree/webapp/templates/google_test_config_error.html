⚠️ 환경 변수 설정이 필요합니다

Google OAuth 설정이 완료되지 않았습니다.

.env 파일에 Google OAuth 관련 환경변수가 설정되어 있지 않습니다.

📝 설정 방법

1. Google Cloud Console에서 OAuth 2.0 클라이언트 ID 생성

  1. Google Cloud Console에 접속
  2. 프로젝트 선택 또는 새 프로젝트 생성
  3. 좌측 메뉴에서 "API 및 서비스" → "사용자 인증 정보" 선택
  4. "사용자 인증 정보 만들기" → "OAuth 2.0 클라이언트 ID" 선택
  5. 애플리케이션 유형: "웹 애플리케이션" 선택
  6. 이름 입력 (예: "Joah Backend")
  7. 승인된 리디렉션 URI 추가:
    http://localhost:8000/api/v1/users/google/test/callback/
  8. "만들기" 클릭하여 클라이언트 ID와 보안 비밀 확인

2. .env 파일에 환경변수 추가

/Users/koa/joah-team/backend/.env 파일에 다음 내용을 추가하세요:

# Google OAuth Configuration
GOOGLE_CLIENT_ID=your-google-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-google-client-secret
GOOGLE_CALLBACK_URI=http://localhost:8000/api/v1/users/google/callback/
GOOGLE_TEST_CALLBACK_URI=http://localhost:8000/api/v1/users/google/test/callback/

3. 서버 재시작

환경변수를 추가한 후 Django 개발 서버를 재시작하세요:

# 현재 서버 중지 (Ctrl+C)
# 서버 다시 시작
python manage.py runserver

4. OAuth 동의 화면 설정 (필요시)

처음 OAuth 클라이언트를 만드는 경우, OAuth 동의 화면도 설정해야 합니다:

  1. Google Cloud Console → "API 및 서비스" → "OAuth 동의 화면"
  2. 사용자 유형: "외부" 선택 (테스트용)
  3. 앱 정보 입력 (앱 이름, 이메일 등)
  4. 범위(Scope) 추가: email, profile, openid
  5. 테스트 사용자 추가 (개발 중에는 등록된 사용자만 로그인 가능)

설정 완료 후 다시 시도
