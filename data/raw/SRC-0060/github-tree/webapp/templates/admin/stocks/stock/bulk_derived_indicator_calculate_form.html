참고사항

  • 처리 범위: 선택한 필터 조건에 맞는 모든 종목에 대해 해당 연도의 전체 분기(Q1-Q4)를 계산합니다.
  • 백그라운드 작업: 각 종목의 각 분기마다 별도의 Celery 작업이 실행됩니다.
  • 예상 작업 수: 상장 보통주 {{ stats.listed_primary }}개 × 4분기 = 약 {{ stats.listed_primary|add:"0"|add:"0"|add:"0"|add:"0"|slice:":4" }}개의 작업
  • 계산 지표: PER, EPS, PBR, BPS, ROE, ROA, 배당수익률, DPS
  • 필요 데이터: 재무제표(FinancialStatement)와 주가(StockPrice) 데이터가 필요합니다.
  • 기준 주가: 각 분기 말일의 종가를 기준으로 지표를 계산합니다.
  • 성능 고려: 대량 작업이므로 Celery Worker의 상태를 확인하고 실행하세요.

  • 이 작업은 수백~수천 개의 백그라운드 작업을 생성할 수 있습니다.
  • Celery Worker가 충분히 실행 중인지 확인하세요.
  • 처리 시간은 종목 수와 Worker 수에 따라 달라집니다.
  • 작업 진행 상황은 Celery Flower나 로그를 통해 확인할 수 있습니다.
