배치 처리 방식

  • 배치 단위 처리: 전체 회사를 지정한 배치 크기로 나누어 순차적으로 처리합니다.
  • 배치 간 대기: 각 배치 처리 후 지정한 시간만큼 sleep하여 API 요청 제한을 회피합니다.
  • 비동기 작업: 각 배치 내의 회사들은 Celery를 통해 비동기로 처리됩니다.
  • 예상 소요 시간: 배치 수 × sleep 시간 + 실제 작업 처리 시간
  • 예시: 3700개 회사, 배치 크기 25, sleep 180초 → 148 배치 × 3분 = 약 7.4시간
  • 처리 범위: 각 회사별로 지정한 연도의 모든 분기 데이터를 수집하고 재생성합니다.

⚠️ 주의사항

  • 이 작업은 수천 개의 백그라운드 작업을 생성할 수 있습니다.
  • Celery Worker가 충분히 실행 중인지 확인하세요.
  • 배치 크기와 sleep 시간을 신중하게 설정하세요. (권장: batch_size=25, sleep=180초)
  • API 요청 제한을 초과하지 않도록 주의하세요.
  • 작업 진행 상황은 Celery Flower나 로그를 통해 확인할 수 있습니다.
  • 처리 시간은 회사 수, 배치 크기, Worker 수에 따라 달라집니다.
