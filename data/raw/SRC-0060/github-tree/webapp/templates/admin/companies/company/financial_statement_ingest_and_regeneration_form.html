참고사항

  • 통합 작업: Raw 데이터 수집(Ingest)과 정제된 데이터 생성(Regeneration)을 순차적으로 실행합니다.
  • Phase 1 - Ingest: OpenDART API를 통해 재무제표 원본 데이터를 수집합니다.
  • Phase 2 - Regeneration: 수집된 데이터를 Mapping Rule에 따라 정제하여 FinancialStatementItem과 Account를 생성합니다.
  • Years: 수집할 회계연도를 쉼표로 구분하여 입력합니다. (예: 2023,2024)
  • Quarters: 수집할 분기를 1-4 범위에서 쉼표로 구분하여 입력합니다. (예: 1,2,3,4)
  • Page count: DART API 응답당 요청할 최대 행 수를 지정합니다.
  • 각 회사별로 별도의 백그라운드 작업이 실행됩니다.
  • 작업 완료 후 FinancialStatement, FinancialStatementItem, FinancialStatementAccount가 생성됩니다.
