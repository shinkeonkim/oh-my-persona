🔐 Google OAuth 2.0 테스트

📝 테스트 방법

  1. 아래 "Google로 로그인" 버튼을 클릭
  2. Google 계정으로 로그인
  3. 권한 동의 후 callback URL에서 authorization_code 확인
  4. 받은 code를 사용해서 API 테스트
Google로 로그인

API 테스트용 curl 명령어

curl -X POST http://localhost:8000/api/v1/users/google/login/ \ -H "Content-Type: application/json" \ -d '{"code": "YOUR_AUTHORIZATION_CODE_HERE"}'

설정 정보

Client ID: {{ client_id }}
Redirect URI: {{ redirect_uri }}
Scope: {{ scope }}
⚠️ 주의사항:
  • Google Cloud Console에서 Redirect URI를 {{ redirect_uri }}로 등록해야 합니다.
  • OAuth 2.0 클라이언트 ID의 승인된 리디렉션 URI에 추가해야 합니다.
  • 실제 프로덕션에서는 이 테스트 페이지를 사용하지 않습니다.

🔧 Google Cloud Console 설정 방법

  1. Google Cloud Console 접속
  2. 프로젝트 선택 또는 생성
  3. "사용자 인증 정보" → "OAuth 2.0 클라이언트 ID" 생성
  4. 애플리케이션 유형: 웹 애플리케이션
  5. 승인된 리디렉션 URI에 {{ redirect_uri }} 추가
