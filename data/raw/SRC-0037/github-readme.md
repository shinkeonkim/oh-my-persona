# Good Bye, BOJ

2016년, 제가 처음으로 알고리즘이라는 낯선 세계에 발을 들였을 때부터 2026년 오늘에 이르기까지... 지난 10 여년 동안 백준 온라인 저지(BOJ)는 제게 단순한 채점 사이트를 넘어 수많은 좌절과 벅찬 성취를 함께해 온 소중한 동반자였습니다. 

밤을 새우며 '맞았습니다!!'라는 초록색 글씨를 보기 위해 모니터 앞에서 수없이 머리를 쥐어뜯던 기억들은 제 개발자 인생에서 결코 잊을 수 없는 가장 빛나는 순간들로 남아있습니다.

최백준님께서 16년 동안 혼자 짊어지셨을 그 노고에 가슴 깊이 감사드리며, 저의 10대와 20대를 든든하게 지탱해준 이 사이트가 역사 속으로 사라진다는 사실에 깊은 슬픔을 느낍니다. 누군가에게는 그저 코딩 문제를 푸는 곳이었을지 몰라도, 저와 같은 수많은 사람들에게는 성장의 발판이자 놀이터였습니다.

> *"하지만 그래도 가기 전에 제가 맞았던 풀이는 다 모아두겠습니다... 죄송합니다."*

BOJ가 비록 서비스는 종료되지만, 제가 그동안 치열하게 고민하며 남겼던 수천 개의 코드와 정답들은 제 로컬 환경에라도 간직하고 싶어 이 스크래퍼를 만들게 되었습니다. 서버에 부담을 최소화하기 위해 충분한 지연 시간을 두고 동작하도록 구성했습니다. 다시 한번 그동안 정말 감사했습니다, 백준님.

---

## 🛠 사용 방법 (Usage)

본 프로젝트는 서비스 종료를 앞두고 안전하게 과거의 풀이 스니펫들을 아카이빙하기 위해 만들어졌습니다.

**요구 사항**
- Python 3.14+ 
- `uv` 패키지 관리자

### 1. 패키지 설치
이 프로젝트는 Playwright를 기반으로 동작합니다. Repository를 클론한 뒤 의존성과 브라우저 구동기를 설치해주세요.
```bash
uv sync
uv run playwright install chromium
```

### 2. 기본 실행 (대화형 마법사)
가장 추천하는 방식입니다. 특별한 인자 없이 실행하면 대화형 프롬프트가 나타납니다.
```bash
uv run python main.py
```
또는 [Releases](https://github.com/shinkeonkim/good-bye-boj/releases) 탭에서 다운로드 받은 OS별 실행 파일을 그대로 더블클릭하세요!

실행 후 진행 과정:
1. **범위 설정**: 전체를 다운로드할지, 특정 문제 번호 구간만 수집할지 터미널에서 물어봅니다.
2. **병렬 워커 설정**: 더 빠른 속도를 원한다면 병렬 처리 수(1~5)를 입력하세요. 백만 단위 요청 방지를 위해 최대 5개의 스레드로 안전하게 제한됩니다.
3. **로그인**: 크로미움 브라우저가 나타나면 수동으로 로그인해주세요.
4. **자동화 시작**: 로그인 완료 후 터미널 창으로 돌아와 `Enter` 키를 누르면 입력하신 워커 개수만큼 보이지 않는 브라우저(Headless)들이 백그라운드에서 빠르게 코드를 수집합니다!
5. **저장 구조**: 결과물은 `solutions/01000~01099/1000/12345.py`와 같이 깔끔하게 저장됩니다.

### 3. CLI를 이용한 빠른 실행 (고급)
터미널 환경이 익숙하신 분들은 직접 인자를 전달하여 바로 실행하실 수 있습니다.
```bash
uv run python main.py --start 1000 --end 1500 --workers 5
```

## 📜 서비스 종료 안내문 (BOJ 공식)

> 안녕하세요.  
> 2010년 3월부터 시작된 BOJ는 2026년 4월 28일을 끝으로 서비스를 종료합니다.  
> 그동안 16년간 함께해주신 모든 이용자 여러분께 진심으로 감사드립니다.  
> 
> 서비스를 계속 운영하기 위해 많은 노력을 기울였으나, 여러 상황의 변화로 인해 부득이하게 서비스를 종료하게 되었습니다.  
> 20대와 30대의 대부분을 함께해온 사이트를 닫게 되어 개인적으로도 매우 마음이 아픕니다. 16년 동안 혼자 운영해오면서 저 역시 많은 즐거운 기억을 쌓을 수 있었습니다.  
> 
> 초등학생 시절에 가입하여 취업까지 이어진 이용자분들도 계시기에, 언젠가는 그분들이 자녀와 함께 이 사이트를 사용하는 모습을 보는 것이 작은 꿈이었습니다. 하지만 안타깝게도 이제는 그 꿈을 멈춰야 할 시점이 되었습니다.  
> 
> 완전히 사라지기보다는, 문제만이라도 다시 볼 수 있는 형태로 돌아올 수 있도록 고민하고 있습니다. 향후 상황이 달라진다면 다시 서비스를 재개할 가능성도 염두에 두고 있습니다. 다만, 서비스 종료 시점에는 문제, 제출 기록, 대회 정보 등을 제외한 모든 데이터가 삭제될 예정입니다.  
> 
> 오늘 이후 접수되는 모든 탈퇴 요청은 서비스 종료 직후 일괄 처리될 예정입니다. 서비스 종료 전까지는 정상적으로 이용하실 수 있으나, 문제집 및 그룹 등의 생성 기능은 제한될 수 있습니다.  
> 
> 그동안 BOJ를 사랑해주셔서 다시 한 번 진심으로 감사드립니다.
