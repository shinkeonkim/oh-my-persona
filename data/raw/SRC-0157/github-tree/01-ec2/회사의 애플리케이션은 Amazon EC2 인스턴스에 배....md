## Question

회사의 애플리케이션은 Amazon EC2 인스턴스에 배포되고 이벤트 기반 아키텍처에 AWS Lambda 함수를 사용합니다. 회사는 기능을 프로덕션에 배포하기 전에 다른 AWS 계정의 비프로덕션 개발 환경을 사용하여 새로운 기능을 테스트합니다.
프로덕션 인스턴스는 시간대가 다른 고객으로 인해 지속적인 사용량을 보여줍니다. 회사는 평일 업무 시간에만 비프로덕션 인스턴스를 사용합니다. 회사는 주말에 비프로덕션 인스턴스를 사용하지 않습니다. 회사는 AWS에서 애플리케이션을 실행하는 데 드는 비용을 최적화하려고 합니다.
이러한 요구 사항을 가장 비용 효율적으로 충족하는 솔루션은 무엇입니까?

- [ ] A. 프로덕션 인스턴스에는 온디맨드 인스턴스를 사용합니다. 주말에만 비프로덕션 인스턴스에 전용 호스트를 사용합니다.
- [ ] B. 프로덕션 인스턴스와 비프로덕션 인스턴스에 예약 인스턴스를 사용합니다. 사용하지 않을 때는 비프로덕션 인스턴스를 종료합니다.
- [ ] C. 프로덕션 인스턴스에는 Compute Savings Plan을 사용합니다. 비프로덕션 인스턴스에는 온디맨드 인스턴스를 사용합니다. 사용하지 않을 때는 비프로덕션 인스턴스를 종료합니다.
- [ ] D. 프로덕션 인스턴스에는 전용 호스트를 사용합니다. 비프로덕션 인스턴스에는 EC2 Instance Savings Plans를 사용합니다.

## Answer

정답: C

## Explanation

프로덕션 인스턴스는 시간대가 다른 고객들로 인해 24/7 상시 사용되므로, Compute Savings Plan으로 EC2와 Lambda 모두의 비용을 절감하는 것이 최적입니다. Compute Savings Plan은 이벤트 기반 아키텍처에서 사용하는 Lambda 함수 비용도 함께 절감할 수 있어 전체 애플리케이션의 비용을 효과적으로 줄입니다. 비프로덕션 인스턴스는 평일 업무 시간에만 간헐적으로 사용되므로, 온디맨드 인스턴스를 사용하고 사용하지 않을 때 종료하면 실행 시간에 대해서만 비용이 발생하여 비용을 최소화할 수 있습니다.

오답 분석

A: 프로덕션 인스턴스에 온디맨드를 사용하면 24/7 실행에 대한 비용 절감이 전혀 없습니다. Savings Plan이나 RI 대비 훨씬 높은 비용을 지불하게 됩니다. 전용 호스트(Dedicated Hosts)는 BYOL(Bring Your Own License) 등 특수한 라이선스 요구 사항이 있을 때만 필요하며, 일반적으로 가장 비싼 옵션입니다.

B: 비프로덕션 인스턴스에 예약 인스턴스를 사용하면, 평일 업무 시간(약 40시간/주)에만 사용하는데도 168시간/주 전체에 대해 비용을 지불하게 됩니다. 예약 인스턴스는 사용 여부와 관계없이 약정 기간 동안 비용이 발생하므로, 간헐적 사용에는 온디맨드 + 종료가 더 비용 효율적입니다.

D: 전용 호스트(Dedicated Hosts)는 물리적 서버 전체를 전용으로 할당받는 것으로, 특수한 라이선스 규정 준수가 필요하지 않는 한 가장 비용이 높은 옵션입니다. EC2 Instance Savings Plan은 EC2에만 적용되어 Lambda 비용을 절감하지 못하므로, 이벤트 기반 아키텍처에서는 Compute Savings Plan이 더 적합합니다.
