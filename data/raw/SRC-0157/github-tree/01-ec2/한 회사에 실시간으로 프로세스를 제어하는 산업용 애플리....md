## Question

한 회사에 실시간으로 프로세스를 제어하는 산업용 애플리케이션이 있습니다. 이 회사는 VPC 내 여러 Amazon EC2 인스턴스에 작업을 분산하도록 애플리케이션을 재설계할 계획입니다. 이 솔루션은 네트워크 처리량을 극대화하고 인스턴스 간 네트워크 지연 시간을 최소화해야 합니다.

- [ ] A. 호스트 수준 파티션 배치 그룹에 인스턴스를 배치합니다. 향상된 네트워킹을 지원하는 인스턴스 유형을 선택합니다.
- [ ] B. 파티션 배치 그룹의 동일한 파티션에 있는 여러 전용 호스트에 인스턴스를 배치합니다. 향상된 네트워킹을 지원하는 전용 호스트를 선택합니다.
- [ ] C. 랙 수준 배치 그룹의 동일한 랙에 있는 여러 전용 호스트에 인스턴스를 배치합니다. 향상된 네트워킹을 지원하는 전용 호스트를 선택합니다.
- [ ] D. 클러스터 배치 그룹에 인스턴스를 배치합니다. 향상된 네트워킹을 지원하는 인스턴스 유형을 선택합니다.

## Answer

정답: D

## Explanation

클러스터 배치 그룹(Cluster Placement Group)은 인스턴스를 동일 가용 영역 내 가까운 하드웨어에 배치하여 네트워크 처리량을 최대화하고 지연 시간을 최소화합니다. 향상된 네트워킹(Enhanced Networking)을 지원하는 인스턴스 유형과 결합하면 최적의 네트워크 성능을 얻을 수 있습니다.

오답 분석

A: 호스트 수준 파티션 배치 그룹이라는 개념은 AWS에 존재하지 않습니다. 파티션 배치 그룹은 대규모 분산 워크로드에 적합하며 네트워크 지연 시간 최소화에는 클러스터 배치 그룹이 적합합니다.

B: 전용 호스트(Dedicated Hosts)를 같은 파티션에 배치하는 것은 클러스터 배치 그룹보다 네트워크 성능 최적화에 효과적이지 않으며 불필요한 비용이 발생합니다.

C: 랙 수준 배치 그룹(rack-level placement group)이라는 개념은 AWS에 존재하지 않습니다.
