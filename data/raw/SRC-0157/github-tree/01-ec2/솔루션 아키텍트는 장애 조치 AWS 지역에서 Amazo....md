## Question

솔루션 아키텍트는 장애 조치 AWS 지역에서 Amazon EC2 용량을 제공하기 위한 재해 복구(DR) 전략을 설계하고 있습니다. 비즈니스 요구 사항에 따르면 DR 전략은 장애 조치 지역의 용량을 충족해야 합니다.
어떤 솔루션이 이러한 요구 사항을 충족합니까?

- [ ] A. 장애 조치 지역에서 온디맨드 인스턴스를 구매합니다.
- [ ] B. 장애 조치 지역에서 EC2 Savings Plan을 구매합니다.
- [ ] C. 장애 조치 지역에서 지역 예약 인스턴스를 구매합니다.
- [ ] D. 장애 조치 지역에서 용량 예약을 구매합니다.

## Answer

정답: D

## Explanation

온디맨드 용량 예약(On-Demand Capacity Reservation)은 특정 가용 영역에서 특정 인스턴스 유형의 EC2 용량을 확실히 보장하는 유일한 메커니즘입니다. DR(재해 복구) 전략에서 장애 조치 리전에 EC2 용량이 반드시 확보되어야 하므로, 용량 예약을 사용하면 필요한 시점에 인스턴스를 즉시 시작할 수 있는 용량이 보장됩니다. 용량 예약은 장기 약정 없이도 생성할 수 있으며, 사용 여부와 관계없이 용량이 예약된 상태로 유지됩니다.

오답 분석

A: 온디맨드 인스턴스는 요청 시점에 사용 가능한 용량에서 할당되므로 용량이 보장되지 않습니다. 대규모 장애 발생 시 해당 리전/AZ의 수요가 급증하면 원하는 인스턴스 유형을 시작하지 못할 수 있어 DR 요구 사항을 충족하지 못합니다.

B: EC2 Savings Plan은 시간당 특정 달러 금액의 컴퓨팅 사용을 1년 또는 3년간 약정하여 비용 할인을 받는 메커니즘입니다. 비용 절감 도구일 뿐 실제 EC2 인스턴스의 물리적 용량을 예약하거나 보장하지 않습니다.

C: 지역 예약 인스턴스(Regional Reserved Instances)는 비용 할인을 제공하고 동일 리전 내 어떤 AZ에서든 자동 적용되지만, 특정 AZ에서의 용량을 보장하지 않습니다. 용량 보장이 필요한 DR 시나리오에서는 용량 예약(Capacity Reservation)이 필요합니다.
