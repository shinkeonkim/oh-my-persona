## Question

회사의 SAP 애플리케이션에는 온프레미스 환경에 백엔드 SQL Server 데이터베이스가 있습니다. 이 회사는 온프레미스 애플리케이션과 데이터베이스 서버를 AWS로 마이그레이션하려고 합니다. 회사는 SAP 데이터베이스의 높은 요구 사항을 충족하는 인스턴스 유형이 필요합니다. 온프레미스 성능 데이터에 따르면 SAP 애플리케이션과 데이터베이스 모두 메모리 사용률이 높습니다.
이러한 요구 사항을 충족하는 솔루션은 무엇입니까?

- [ ] A. 애플리케이션에 최적화된 컴퓨팅 인스턴스 제품군을 사용합니다. 데이터베이스에 메모리 최적화 인스턴스 제품군을 사용합니다.
- [ ] B. 애플리케이션과 데이터베이스 모두에 스토리지 최적화 인스턴스 제품군을 사용합니다.
- [ ] C. 애플리케이션과 데이터베이스 모두에 대해 메모리 최적화 인스턴스 제품군을 사용합니다.
- [ ] D. 애플리케이션에 고성능 컴퓨팅(HPC) 최적화 인스턴스 제품군을 사용합니다. 데이터베이스에 메모리 최적화 인스턴스 제품군을 사용합니다.

## Answer

정답: C

## Explanation

문제에서 SAP 애플리케이션과 데이터베이스 모두 메모리 사용률이 높다고 명시하고 있으므로, 두 서버 모두 메모리 최적화 인스턴스 패밀리를 사용하는 것이 적합합니다. 메모리 최적화 인스턴스(R5, R6g, R6i, X1, X2gd 등)는 대용량 메모리(최대 수 TB)를 제공하여 SAP HANA, SQL Server 같은 인메모리 데이터베이스에 최적화되어 있습니다. AWS는 SAP 워크로드에 대해 R5, X1, X2idn 등의 메모리 최적화 인스턴스 유형을 공식 인증하고 있습니다.

오답 분석

A: 컴퓨팅 최적화 인스턴스(C 패밀리: C5, C6i 등)는 CPU 집약적 워크로드(배치 처리, 과학 계산, 게임 서버 등)에 최적화되어 있으며, CPU 대비 메모리 비율이 낮습니다. 메모리 사용률이 높은 SAP 애플리케이션에는 메모리 최적화 인스턴스가 더 적합합니다.

B: 스토리지 최적화 인스턴스(I 패밀리: I3, I4i, D 패밀리: D2, D3 등)는 로컬 NVMe SSD를 통한 높은 순차적 읽기/쓰기 처리량이 필요한 워크로드(데이터 웨어하우징, 분산 파일 시스템 등)에 적합합니다. 메모리 집약적 워크로드에는 최적화되어 있지 않습니다.

D: HPC 최적화 인스턴스(Hpc6a, Hpc7g 등)는 대규모 병렬 계산, 유한 요소 분석, 분자 동역학 시뮬레이션 등 고성능 컴퓨팅 워크로드에 특화되어 있습니다. SAP 애플리케이션의 핵심 요구 사항인 높은 메모리 사용률에는 메모리 최적화 인스턴스가 더 적합합니다.
