## Question

회사에서 고객 요구를 지원하기 위해 애플리케이션을 개발하고 있습니다. 회사는 동일한 가용 영역 내의 여러 Amazon EC2 Nitro 기반 인스턴스에 애플리케이션을 배포하려고 합니다. 또한 회사는 더 높은 애플리케이션 가용성을 달성하기 위해 여러 EC2 Nitro 기반 인스턴스의 여러 블록 스토리지 볼륨에 동시에 쓸 수 있는 기능을 애플리케이션에 제공하고자 합니다.
이러한 요구 사항을 충족하는 솔루션은 무엇입니까?

- [ ] A. 범용 SSD(gp3) EBS 볼륨과 Amazon Elastic Block Store(Amazon EBS) Multi-Attach를 사용합니다.
- [ ] B. 처리량 최적화 HDD(st1) EBS 볼륨과 Amazon Elastic Block Store(Amazon EBS) Multi-Attach를 사용합니다.
- [ ] C. 프로비저닝된 IOPS SSD(io2) EBS 볼륨과 Amazon Elastic Block Store(Amazon EBS) Multi-Attach를 사용합니다.
- [ ] D. 범용 SSD(gp2) EBS 볼륨과 Amazon Elastic Block Store(Amazon EBS) Multi-Attach를 사용합니다.

## Answer

정답: C

## Explanation

Amazon EBS Multi-Attach 기능은 io1/io2 Provisioned IOPS SSD 볼륨을 동일한 가용 영역 내의 최대 16개 Nitro 기반 EC2 인스턴스에 동시에 연결할 수 있게 합니다. 이를 통해 여러 인스턴스가 동일한 블록 스토리지에 동시에 읽기/쓰기가 가능하며, 클러스터링된 데이터베이스나 고가용성 애플리케이션에 적합합니다. Multi-Attach는 오직 io1/io2 볼륨에서만 지원됩니다.

오답 분석

A: gp3 볼륨은 Multi-Attach를 지원하지 않습니다. Multi-Attach는 io1/io2 Provisioned IOPS SSD 볼륨에서만 사용할 수 있습니다.

B: st1(처리량 최적화 HDD) 볼륨은 Multi-Attach를 지원하지 않습니다. Multi-Attach는 io1/io2 볼륨에서만 지원됩니다.

D: gp2 볼륨은 Multi-Attach를 지원하지 않습니다. Multi-Attach는 io1/io2 Provisioned IOPS SSD 볼륨에서만 사용할 수 있습니다.
