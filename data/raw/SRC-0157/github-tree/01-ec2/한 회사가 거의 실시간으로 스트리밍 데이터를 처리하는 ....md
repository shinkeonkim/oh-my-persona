## Question

한 회사가 거의 실시간으로 스트리밍 데이터를 처리하는 애플리케이션을 배포하고 있습니다. 회사는 워크로드에 Amazon EC2 인스턴스를 사용할 계획입니다. 네트워크 아키텍처는 노드 간 가능한 최저 대기 시간을 제공하도록 구성 가능해야 합니다.
이러한 요구 사항을 충족하는 네트워크 솔루션 조합은 무엇입니까? (2개를 선택하세요.)

- [ ] A. 각 EC2 인스턴스에서 향상된 네트워킹을 활성화하고 구성합니다.
- [ ] B. EC2 인스턴스를 별도의 계정으로 그룹화합니다.
- [ ] C. 클러스터 배치 그룹에서 EC2 인스턴스를 실행합니다.
- [ ] D. 각 EC2 인스턴스에 여러 탄력적 네트워크 인터페이스를 연결합니다.
- [ ] E. Amazon Elastic Block Store(Amazon EBS) 최적화 인스턴스 유형을 사용합니다.

## Answer

정답: A, C

## Explanation

각 EC2 인스턴스에서 향상된 네트워킹(Enhanced Networking)을 활성화하고(A), 클러스터 배치 그룹에서 EC2 인스턴스를 실행하면(C) 노드 간 가능한 최저 지연 시간을 제공합니다. 향상된 네트워킹은 SR-IOV(Single Root I/O Virtualization)를 사용하여 더 높은 대역폭, 높은 PPS(초당 패킷 수), 낮은 인스턴스 간 지연 시간을 제공합니다. 클러스터 배치 그룹은 인스턴스를 물리적으로 가까운 위치에 배치하여 네트워크 지연 시간을 최소화합니다. 이 두 가지를 결합하면 최저 지연 시간을 달성할 수 있습니다.

오답 분석

B: EC2 인스턴스를 별도의 계정으로 그룹화하는 것은 비용 관리나 보안 격리에 사용되며, 네트워크 지연 시간에 영향을 주지 않습니다. 오히려 계정 간 통신이 필요하면 지연 시간이 증가할 수 있습니다.

D: 여러 탄력적 네트워크 인터페이스(ENI)를 연결하면 다중 네트워크 연결이 가능하지만, 인스턴스 간 지연 시간을 줄이지 않습니다. ENI는 다중 서브넷 연결이나 네트워크 분리에 사용됩니다.

E: EBS 최적화 인스턴스 유형은 EBS 볼륨에 대한 전용 대역폭을 제공하여 스토리지 성능을 향상시키지만, 인스턴스 간 네트워크 지연 시간과는 무관합니다.
