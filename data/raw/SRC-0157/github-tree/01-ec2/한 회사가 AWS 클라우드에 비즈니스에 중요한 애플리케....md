## Question

한 회사가 AWS 클라우드에 비즈니스에 중요한 애플리케이션을 배포할 계획입니다. 애플리케이션에는 일관되고 지연 시간이 짧은 성능을 갖춘 내구성 있는 스토리지가 필요합니다.
솔루션 설계자는 이러한 요구 사항을 충족하기 위해 어떤 유형의 스토리지를 권장해야 합니까?

- [ ] A. 인스턴스 스토어 볼륨
- [ ] B. Memcached 클러스터용 Amazon ElastiCache
- [ ] C. 프로비저닝된 IOPS SSD Amazon Elastic Block Store(Amazon EBS) 볼륨
- [ ] D. 처리량 최적화 HDD Amazon Elastic Block Store(Amazon EBS) 볼륨

## Answer

정답: C

## Explanation

Provisioned IOPS SSD(io1/io2) Amazon EBS 볼륨은 내구성 있는 블록 스토리지와 일관된 저지연 성능을 제공합니다. 높은 내구성을 위해 설계되었으며, 프로비저닝된 IOPS를 일관되게 유지하여 비즈니스 크리티컬 애플리케이션의 예측 가능한 성능 요구사항을 충족합니다. 밀리초 미만의 지연 시간으로 트랜잭션 워크로드에 최적화되어 있습니다.

오답 분석

A: 인스턴스 스토어 볼륨은 높은 I/O 성능을 제공하지만, 인스턴스가 중지되거나 종료되면 데이터가 손실됩니다. '내구성 있는 스토리지' 요구 사항을 충족하지 못합니다.

B: Amazon ElastiCache for Memcached는 인메모리 캐싱 서비스이며 블록 스토리지가 아닙니다. 데이터 내구성이 보장되지 않으며(Memcached는 데이터 지속성을 지원하지 않음), 스토리지 솔루션으로 적합하지 않습니다.

D: 처리량 최적화 HDD(st1)는 높은 순차 읽기/쓰기 처리량에 최적화된 볼륨이지만, 랜덤 I/O 지연 시간이 SSD보다 높아 '일관되고 지연 시간이 짧은 성능' 요구 사항에 적합하지 않습니다.
