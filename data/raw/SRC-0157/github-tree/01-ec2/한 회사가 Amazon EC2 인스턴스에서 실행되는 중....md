## Question

한 회사가 Amazon EC2 인스턴스에서 실행되는 중요한 데이터 처리 애플리케이션을 구축하고 있습니다. 이 회사는 동일한 기반 하드웨어에서 두 개의 노드를 실행해서는 안 됩니다. 회사는 애플리케이션에 대해 최소 99.99%의 가용성을 요구합니다.
이러한 요구 사항을 충족하는 솔루션은 무엇입니까?

- [ ] A. 클러스터 배치 그룹 전략을 사용하여 하나의 가용 영역에 애플리케이션을 배포합니다.
- [ ] B. 분산 배치 그룹 전략을 사용하여 세 개의 가용 영역에 애플리케이션을 배포합니다.
- [ ] C. 클러스터 배치 그룹 전략을 사용하여 세 개의 가용 영역에 애플리케이션을 배포합니다.
- [ ] D. 파티션 배치 그룹 전략을 사용하여 하나의 가용 영역에 애플리케이션을 배포합니다.

## Answer

정답: B

## Explanation

스프레드 배치 그룹(Spread Placement Group)은 각 인스턴스를 서로 다른 하드웨어에 배치하여 두 노드가 같은 하드웨어에서 실행되지 않도록 보장합니다. 3개의 가용 영역에 걸쳐 배포하면 99.99% 이상의 가용성을 달성할 수 있습니다.

오답 분석

A: 클러스터 배치 그룹은 인스턴스를 같은 하드웨어 근처에 배치하여 네트워크 성능을 최적화하지만, 같은 하드웨어 사용을 방지하지 않으며 단일 가용 영역은 99.99% 가용성을 보장하지 못합니다.

C: 클러스터 배치 그룹은 인스턴스를 가까이 배치하는 것이 목적이므로 서로 다른 하드웨어에 배치하는 요구사항을 충족하지 못합니다.

D: 파티션 배치 그룹은 파티션 내에서 하드웨어를 공유할 수 있으며, 단일 가용 영역은 99.99% 가용성을 보장하지 못합니다.
