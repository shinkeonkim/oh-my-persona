## Question

회사는 1주일 동안 지속되는 예정된 이벤트를 위해 특정 AWS 리전에 있는 3개의 특정 가용 영역에서 보장된 Amazon EC2 용량이 필요합니다.
회사는 EC2 용량을 보장하기 위해 무엇을 해야 합니까?

- [ ] A. 필요한 리전을 지정하는 예약 인스턴스를 구매합니다.
- [ ] B. 필요한 리전을 지정하는 온디맨드 용량 예약을 생성합니다.
- [ ] C. 필요한 리전과 3개의 가용 영역을 지정하는 예약 인스턴스를 구입합니다.
- [ ] D. 필요한 리전 및 세 개의 가용 영역을 지정하는 온디맨드 용량 예약을 생성합니다.

## Answer

정답: D

## Explanation

온디맨드 용량 예약(On-Demand Capacity Reservation)은 특정 리전 및 특정 가용 영역에서 EC2 인스턴스 용량을 확실히 보장합니다. 3개의 특정 가용 영역에서 보장된 용량이 필요하므로, 각 가용 영역을 지정하는 용량 예약을 개별적으로 생성해야 합니다. 용량 예약은 장기 약정이 필요 없으므로 1주일 이벤트 종료 후 즉시 취소할 수 있어 단기 이벤트에 적합합니다. 인스턴스를 실행하지 않아도 용량이 보장되며, 인스턴스 실행 시에만 EC2 요금이 발생합니다.

오답 분석

A: 지역 예약 인스턴스(Regional Reserved Instances)는 리전 수준에서 적용되지만, 특정 가용 영역에서의 용량을 보장하지 않습니다. 또한 최소 1년 약정이 필요하므로 1주일 이벤트에 비용 효율적이지 않으며, 사용하지 않는 나머지 기간에도 비용이 발생합니다.

B: 리전만 지정하는 용량 예약은 존재하지 않습니다. 용량 예약은 반드시 특정 가용 영역을 지정해야 합니다. 3개의 특정 AZ에서 용량이 필요하므로 각 AZ에 대해 별도의 용량 예약을 생성해야 합니다.

C: 예약 인스턴스는 특정 가용 영역을 지정할 수 있지만(Zonal RI), 최소 1년 약정이 필요합니다. 1주일 이벤트에 1년 RI를 구매하면 52주 중 1주만 사용하므로 극도로 비용 효율적이지 않습니다.
