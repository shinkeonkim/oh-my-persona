## Question

한 회사에 Amazon DynamoDB 테이블을 저장용으로 사용하는 애플리케이션이 있습니다. 솔루션 설계자는 테이블에 대한 많은 요청이 최신 데이터를 반환하지 않는다는 것을 발견했습니다. 회사 사용자는 데이터베이스 성능과 관련된 다른 문제를 보고하지 않았습니다. 지연 시간이 허용 가능한 범위 내에 있습니다.
솔루션 설계자는 어떤 디자인 변경을 권장해야 합니까?

- [ ] A. 테이블에 읽기 전용 복제본을 추가합니다.
- [ ] B. 글로벌 보조 인덱스(GSI)를 사용합니다.
- [ ] C. 테이블에 대해 강력하게 일관된 읽기를 요청합니다.
- [ ] D. 테이블에 대한 최종적 일관된 읽기를 요청합니다.

## Answer

정답: C

## Explanation

DynamoDB에서 Strongly Consistent Read(강력한 일관된 읽기)를 요청하면 가장 최근에 완료된 쓰기 결과를 반영한 데이터를 항상 반환합니다. DynamoDB는 기본적으로 Eventually Consistent Read(최종 일관된 읽기)를 사용하여 최근 쓰기가 반영되지 않은 이전 데이터를 반환할 수 있습니다. '최신 데이터를 반환하지 않는' 문제이면서 지연 시간과 성능에 다른 이슈가 없으므로 일관성 수준 변경이 정확한 해결책입니다.

오답 분석

A: DynamoDB에는 '읽기 전용 복제본'이라는 개념이 없습니다. DynamoDB는 자동으로 3개 AZ에 데이터를 복제하며, 글로벌 테이블을 통한 교차 리전 복제만 지원합니다.

B: 글로벌 보조 인덱스(GSI)는 대체 쿼리 패턴을 지원하기 위한 것이며, GSI의 데이터는 항상 Eventually Consistent입니다. 따라서 GSI는 데이터 일관성 문제를 오히려 악화시킬 수 있습니다.

D: Eventually Consistent Read는 현재 사용 중인 기본 설정이며, 이미 '최신 데이터가 반환되지 않는' 원인입니다. 동일한 설정을 다시 적용하는 것은 문제를 해결하지 못합니다.
