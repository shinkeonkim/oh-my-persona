## Question

회사에 여행 발권을 위한 웹 애플리케이션이 있습니다. 이 애플리케이션은 북미 지역의 단일 데이터 센터에서 실행되는 데이터베이스를 기반으로 합니다. 회사는 글로벌 사용자 기반에 서비스를 제공하기 위해 애플리케이션을 확장하려고 합니다. 회사는 애플리케이션을 여러 AWS 리전에 배포해야 합니다. 예약 데이터베이스 업데이트 시 평균 지연 시간은 1초 미만이어야 합니다.
이 회사는 여러 리전에 걸쳐 웹 플랫폼을 별도로 배포하려고 합니다. 그러나 회사는 전 세계적으로 일관된 단일 기본 예약 데이터베이스를 유지해야 합니다.
솔루션 설계자는 이러한 요구 사항을 충족하기 위해 어떤 솔루션을 권장해야 합니까?

- [ ] A. Amazon DynamoDB를 사용하도록 애플리케이션을 변환합니다. 중앙 예약 테이블에 전역 테이블을 사용합니다. 각 리전 배포에서 올바른 리전 엔드포인트를 사용합니다.
- [ ] B. 데이터베이스를 Amazon Aurora MySQL 데이터베이스로 마이그레이션합니다. 각 리전에 Aurora 읽기 전용 복제본을 배포합니다. 데이터베이스에 액세스하려면 각 리전 배포에서 올바른 리전 엔드포인트를 사용합니다.
- [ ] C. 데이터베이스를 Amazon RDS for MySQL 데이터베이스로 마이그레이션합니다. 각 리전에 MySQL 읽기 전용 복제본을 배포합니다. 데이터베이스에 액세스하려면 각 리전 배포에서 올바른 리전 엔드포인트를 사용합니다.
- [ ] D. 애플리케이션을 Amazon Aurora Serverless 데이터베이스로 마이그레이션합니다. 각 리전에 데이터베이스 인스턴스를 배포합니다. 각 리전 배포에서 올바른 리전 엔드포인트를 사용하여 데이터베이스에 액세스합니다. AWS Lambda 함수를 사용하여 각 리전에서 이벤트 스트림을 처리하여 데이터베이스를 동기화합니다.

## Answer

정답: A

## Explanation

Amazon DynamoDB 글로벌 테이블은 여러 AWS 리전에 걸쳐 완전 관리형 다중 활성(multi-active) 데이터베이스를 제공합니다. 글로벌 테이블은 자동 비동기 복제를 통해 밀리초 단위의 지연 시간으로 전 세계적으로 일관된 단일 데이터베이스를 유지할 수 있습니다. 업데이트 시 평균 대기 시간이 1초 미만이어야 하는 요구 사항과 전 세계적으로 일관된 단일 예약 데이터베이스 유지 요구 사항을 모두 충족합니다.

오답 분석

B: Aurora 읽기 전용 복제본은 비동기식으로 복제되며, 읽기 전용으로만 사용됩니다. 각 리전에서 읽기만 가능하고 쓰기는 기본 리전에서만 가능하므로, 글로벌 사용자 기반에 대한 1초 미만의 쓰기 지연 시간을 보장하기 어렵습니다.

C: Amazon RDS for MySQL 읽기 전용 복제본도 비동기식으로 복제되며, 쓰기는 기본 리전에서만 가능합니다. 글로벌 사용자가 예약을 업데이트할 때 기본 리전까지의 네트워크 지연 시간이 발생하여 1초 미만의 요구 사항을 충족하기 어렵습니다.

D: Aurora Serverless에서 Lambda 함수로 이벤트 스트림을 처리하여 데이터베이스를 동기화하는 방식은 복잡하고, 데이터 일관성을 보장하기 어렵습니다. 또한 직접 구현해야 하므로 운영 오버헤드가 높으며, 글로벌 일관성을 보장하는 DynamoDB 글로벌 테이블만큼 효율적이지 않습니다.
