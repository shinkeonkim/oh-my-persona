## Question

전자상거래 회사가 새로운 마케팅 캠페인을 시작합니다. 이 회사는 캠페인을 통해 자사의 전자상거래 애플리케이션을 통해 평소보다 10배 많은 일일 주문이 발생할 것으로 예상합니다. 캠페인은 3일간 진행됩니다. 전자상거래 애플리케이션 아키텍처는 Auto Scaling 그룹의 Amazon EC2 인스턴스와 Amazon RDS for MySQL 데이터베이스를 기반으로 합니다. 애플리케이션은 데이터베이스에 주문을 기록하기 전에 Amazon Elastic File System(Amazon EFS) 파일 시스템에 주문 트랜잭션을 기록합니다. 정상 운영 중 애플리케이션 쓰기 작업은 최대 5,000 IOPS에 달합니다. 솔루션 아키텍트는 마케팅 캠페인 기간 동안 애플리케이션이 예상되는 워크로드를 처리할 수 있는지 확인해야 합니다. 이 요구 사항을 충족하는 솔루션은 무엇입니까?

- [ ] A. 캠페인 기간 동안 RDS for MySQL 데이터베이스의 프로비저닝된 IOPS를 늘립니다. Amazon EFS 처리량 모드를 버스팅 처리량으로 설정합니다.
- [ ] B. 캠페인 기간 동안 RDS for MySQL 데이터베이스의 프로비저닝된 IOPS를 늘립니다. Amazon EFS 처리량 모드를 탄력적 처리량으로 설정합니다.
- [ ] C. 데이터베이스를 다중 AZ 배포로 전환합니다. 캠페인 기간 동안 Amazon EFS 처리량 모드를 탄력적 처리량으로 설정합니다.
- [ ] D. AWS Database Migration Service(AWS DMS)를 사용하여 데이터베이스를 RDS for PostgreSQL로 전환합니다. Amazon EFS 처리량 모드를 버스팅 처리량으로 설정합니다.

## Answer

정답: B

## Explanation

마케팅 캠페인 기간 동안 RDS MySQL의 프로비저닝된 IOPS를 증가시키면 데이터베이스 쓰기 성능을 확보할 수 있고, EFS를 Elastic throughput 모드로 설정하면 워크로드에 따라 자동으로 처리량이 조정되어 평소보다 10배 많은 처리량 수요를 처리할 수 있습니다. Elastic throughput 모드는 사전 프로비저닝 없이 EFS 처리량(MBps 단위)을 동적으로 확장하므로, 3일간의 캠페인에서 지속적인 높은 트래픽을 처리하는 데 이상적입니다.

오답 분석

A: EFS Bursting throughput 모드는 일시적인 성능 급증에 사용되지만, 3일 동안 지속적인 10배 트래픽에는 Elastic 모드가 더 적합합니다.

C: Multi-AZ 배포로 전환하는 것은 고가용성을 제공하지만, IOPS 성능을 증가시키지 않으므로 워크로드 처리에 불충분합니다.

D: PostgreSQL로 마이그레이션하는 것은 불필요한 변경이며, Bursting throughput은 지속적인 고부하에 적합하지 않습니다.
