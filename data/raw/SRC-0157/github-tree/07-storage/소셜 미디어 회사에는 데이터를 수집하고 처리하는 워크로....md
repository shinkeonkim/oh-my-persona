## Question

소셜 미디어 회사에는 데이터를 수집하고 처리하는 워크로드가 있습니다. 워크로드는 온프레미스 NFS 스토리지에 데이터를 저장합니다. 데이터 저장소는 회사의 확장되는 비즈니스 요구 사항을 충족할 만큼 빠르게 확장할 수 없습니다. 회사는 현재 데이터 스토어를 AWS로 마이그레이션하려고 합니다.
이러한 요구 사항을 가장 비용 효율적으로 충족하는 솔루션은 무엇입니까?

- [ ] A. AWS Storage Gateway 볼륨 게이트웨이를 설정합니다. Amazon S3 수명 주기 정책을 사용하여 데이터를 적절한 스토리지 클래스로 전환합니다.
- [ ] B. AWS Storage Gateway Amazon S3 파일 게이트웨이를 설정합니다. Amazon S3 수명 주기 정책을 사용하여 데이터를 적절한 스토리지 클래스로 전환합니다.
- [ ] C. Amazon Elastic File System(Amazon EFS) Standard-Infrequent Access(Standard-IA) 스토리지 클래스를 사용합니다. 빈번하지 않은 액세스 수명주기 정책을 활성화합니다.
- [ ] D. One Zone-Infrequent Access(One Zone-IA) 스토리지 클래스를 사용합니다. Amazon Elastic File System(Amazon EFS) 빈번하지 않은 액세스 수명주기 정책을 활성화합니다.

## Answer

정답: B

## Explanation

AWS Storage Gateway Amazon S3 파일 게이트웨이는 NFS 프로토콜을 기본 지원하여 온프레미스 NFS 워크로드와 완벽하게 호환됩니다. 파일을 S3 버킷에 객체로 저장하므로 스토리지가 사실상 무제한으로 확장되며, 온프레미스 스토리지 용량 부족 문제를 해결합니다. S3 수명 주기 정책을 적용하여 비활성 데이터를 S3 IA, Glacier 등 저비용 클래스로 자동 전환하여 비용을 최적화할 수 있습니다.

오답 분석

A: Storage Gateway 볼륨 게이트웨이는 iSCSI 블록 스토리지를 제공하며, 기존 NFS 워크로드에는 파일 게이트웨이(NFS 프로토콜)가 더 적합합니다. 볼륨 게이트웨이는 파일 시스템이 아닌 블록 레벨 스토리지를 제공하므로 NFS 프로토콜과 직접 호환되지 않습니다.

C: EFS Standard-IA는 NFS 파일 시스템이지만, S3 파일 게이트웨이 + S3 수명 주기 정책 조합보다 GB당 스토리지 비용이 훨씬 높습니다. S3의 저렴한 스토리지와 유연한 수명 주기 정책이 비용 효율성 면에서 우수합니다.

D: EFS One Zone-IA는 단일 가용 영역에만 데이터를 저장하여 다중 AZ EFS보다 내구성이 낮습니다. 또한 EFS의 스토리지 비용은 S3보다 높으므로 비용 효율적이지 않습니다.
