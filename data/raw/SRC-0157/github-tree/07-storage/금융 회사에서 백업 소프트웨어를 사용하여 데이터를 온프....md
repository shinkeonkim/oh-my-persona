## Question

금융 회사에서 백업 소프트웨어를 사용하여 데이터를 온프레미스의 물리적 테이프 스토리지에 백업합니다. 규정을 준수하기 위해 회사는 데이터를 7년 동안 보관해야 합니다. 회사는 필요한 경우 1주일 이내에 보관된 데이터를 복원할 수 있어야 합니다. 회사는 비용을 줄이기 위해 백업 데이터를 AWS로 마이그레이션하려고 합니다. 회사는 현재 백업 소프트웨어를 변경하고 싶지 않습니다.
이러한 요구 사항을 가장 비용 효율적으로 충족하는 솔루션은 무엇입니까?

- [ ] A. AWS Storage Gateway Tape Gateway를 사용하여 데이터를 가상 테이프에 복사합니다. AWS DataSync를 사용하여 가상 테이프를 Amazon S3 Standard-Infrequent Access(S3 Standard-IA)로 마이그레이션합니다. 백업 소프트웨어의 대상을 S3 Standard-IA로 변경합니다.
- [ ] B. 물리적 테이프를 가상 테이프로 변환합니다. AWS DataSync를 사용하여 가상 테이프를 Amazon S3 Glacier Flexible Retrieval로 마이그레이션합니다. 백업 소프트웨어의 대상을 S3 Glacier Flexible Retrieval로 변경합니다.
- [ ] C. AWS Storage Gateway Tape Gateway를 사용하여 데이터를 가상 테이프에 복사합니다. 가상 테이프를 Amazon S3 Glacier Deep Archive로 마이그레이션합니다. 백업 소프트웨어의 대상을 가상 테이프로 변경합니다.
- [ ] D. 물리적 테이프를 가상 테이프로 변환합니다. AWS Snowball Edge 스토리지 최적화 장치를 사용하여 가상 테이프를 Amazon S3 Glacier Flexible Retrieval로 마이그레이션합니다. 백업 소프트웨어의 대상을 S3 Glacier Flexible Retrieval로 변경합니다.

## Answer

정답: C

## Explanation

AWS Storage Gateway Tape Gateway를 사용하면 기존 백업 소프트웨어가 물리적 테이프와 동일한 iSCSI/VTL(Virtual Tape Library) 인터페이스를 통해 가상 테이프에 데이터를 기록합니다. 백업 소프트웨어 자체에는 코드나 프로토콜 변경이 필요하지 않으며, 테이프 대상을 Tape Gateway로 전환하는 구성만 변경하면 됩니다. 가상 테이프를 S3 Glacier Deep Archive로 이동하면 7년 장기 보관에 가장 비용 효율적이며, 필요 시 1주일 내 복원이 가능합니다.

오답 분석

A: Tape Gateway에서 DataSync로 S3 Standard-IA에 마이그레이션하면 Glacier Deep Archive보다 비용이 높으며, 장기 보관에 적합하지 않습니다.

B: 옵션 B와 D 모두 물리적 테이프를 DataSync 또는 Snowball을 통해 Amazon S3 Glacier에 직접 저장하도록 변환합니다. 두 옵션 모두 백업 소프트웨어의 스토리지 타겟을 S3 기반 엔드포인트로 변경해야 하므로, 백업 애플리케이션이 새 스토리지 대상을 가리키도록 재구성해야 합니다. 이는 백업 소프트웨어를 변경하지 않아야 한다는 요구사항에 위배됩니다.

D: Snowball Edge 디바이스를 사용한 마이그레이션은 물리적 배송 시간이 필요하며, 백업 소프트웨어의 타겟을 S3 Glacier Flexible Retrieval로 변경하면 기존 백업 애플리케이션의 구성을 수정해야 합니다.
