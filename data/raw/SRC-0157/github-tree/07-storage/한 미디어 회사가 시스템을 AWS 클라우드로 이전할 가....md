## Question

한 미디어 회사가 시스템을 AWS 클라우드로 이전할 가능성을 평가하고 있습니다. 회사는 비디오 처리를 위해 가능한 최대 I/O 성능을 갖춘 최소 10TB의 스토리지, 미디어 콘텐츠를 저장하기 위한 300TB의 내구성이 뛰어난 스토리지, 더 이상 사용하지 않는 아카이브 미디어에 대한 요구 사항을 충족하기 위해 900TB의 스토리지가 필요합니다.
이러한 요구 사항을 충족하기 위해 솔루션 설계자가 추천해야 하는 서비스 세트는 무엇입니까?

- [ ] A. 최대 성능을 위한 Amazon EBS, 내구성 있는 데이터 스토리지를 위한 Amazon S3, 아카이브 스토리지를 위한 Amazon S3 Glacier
- [ ] B. 최대 성능을 위한 Amazon EBS, 내구성 있는 데이터 스토리지를 위한 Amazon EFS, 아카이브 스토리지를 위한 Amazon S3 Glacier
- [ ] C. 최대 성능을 위한 Amazon EC2 인스턴스 스토어, 내구성 있는 데이터 스토리지를 위한 Amazon EFS, 아카이브 스토리지를 위한 Amazon S3
- [ ] D. 최대 성능을 위한 Amazon EC2 인스턴스 스토어, 내구성 있는 데이터 스토리지를 위한 Amazon S3, 아카이브 스토리지를 위한 Amazon S3 Glacier

## Answer

정답: D

## Explanation

Amazon EC2 인스턴스 스토어는 호스트 서버에 물리적으로 연결된 NVMe SSD 기반 임시 스토리지로, EBS(네트워크 연결 스토리지)보다 더 높은 IOPS와 낮은 지연 시간을 제공하여 비디오 처리와 같은 최대 I/O 성능이 필요한 워크로드에 가장 적합합니다. Amazon S3는 99.999999999%(11 9's) 내구성을 제공하는 객체 스토리지로 300TB의 미디어 콘텐츠 저장에 최적이며, Amazon S3 Glacier는 아카이브 목적의 저비용 스토리지로 더 이상 사용하지 않는 900TB의 미디어에 가장 경제적인 선택입니다.

오답 분석

A: Amazon EBS는 네트워크를 통해 연결되는 블록 스토리지로 높은 I/O 성능을 제공하지만, EC2 인스턴스 스토어(로컬 NVMe SSD)보다는 지연 시간이 높고 최대 I/O 성능이 낮습니다. '가능한 최대 I/O 성능'이라는 요구사항에서 인스턴스 스토어가 더 적합합니다.

B: Amazon EFS는 여러 인스턴스에서 공유할 수 있는 파일 시스템이지만, 300TB 규모의 미디어 콘텐츠 저장에는 S3보다 비용이 훨씬 높습니다. 또한 EBS가 최대 I/O 성능에 최적은 아닙니다.

C: Amazon EFS를 내구성 있는 스토리지로 사용하는 것은 가능하지만, 아카이브 스토리지에 Amazon S3 Standard를 사용하면 S3 Glacier보다 비용이 크게 높습니다. S3 Glacier는 S3 Standard 대비 약 80% 이상 저렴하여 아카이브 용도에 훨씬 적합합니다.
