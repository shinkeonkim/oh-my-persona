## Question

온라인 학습 회사가 AWS 클라우드로 마이그레이션하고 있습니다. 회사는 PostgreSQL 데이터베이스에 학생 기록을 유지합니다. 회사는 여러 AWS 리전에서 데이터를 항상 온라인으로 사용할 수 있는 솔루션이 필요합니다.
최소한의 운영 오버헤드로 이러한 요구 사항을 충족하는 솔루션은 무엇입니까?

- [ ] A. PostgreSQL 데이터베이스를 Amazon EC2 인스턴스의 PostgreSQL 클러스터로 마이그레이션합니다.
- [ ] B. PostgreSQL 데이터베이스를 다중 AZ 기능이 켜진 Amazon RDS for PostgreSQL DB 인스턴스로 마이그레이션합니다.
- [ ] C. PostgreSQL 데이터베이스를 Amazon RDS for PostgreSQL DB 인스턴스로 마이그레이션합니다. 다른 리전에서 읽기 전용 복제본을 생성합니다.
- [ ] D. PostgreSQL 데이터베이스를 Amazon RDS for PostgreSQL DB 인스턴스로 마이그레이션합니다. 다른 리전에 복사할 DB 스냅샷을 설정합니다.

## Answer

정답: C

## Explanation

Amazon RDS for PostgreSQL DB 인스턴스로 마이그레이션한 후 다른 리전에 읽기 전용 복제본을 생성하면, 여러 AWS 리전에서 데이터를 항상 온라인으로 사용할 수 있습니다. 교차 리전 읽기 전용 복제본은 비동기 복제를 통해 데이터를 다른 리전에 지속적으로 복제하며, 해당 리전의 사용자에게 낮은 지연 시간의 읽기 접근을 제공합니다. 장애 발생 시 읽기 복제본을 독립 DB 인스턴스로 승격할 수 있습니다.

오답 분석

A: EC2 인스턴스에 PostgreSQL 클러스터를 직접 구성하면 패치, 백업, 복제 관리 등 운영 오버헤드가 매우 큽니다.

B: Multi-AZ 기능은 동일 리전 내의 고가용성만 제공하며, 여러 AWS 리전에서 데이터를 사용할 수 있도록 하는 요구 사항을 충족하지 못합니다.

D: DB 스냅샷을 다른 리전으로 복사하면 데이터가 항상 온라인으로 사용 가능하지 않습니다. 스냅샷 복원에는 시간이 걸리며 실시간 데이터 접근이 불가능합니다.
