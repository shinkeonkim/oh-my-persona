## Question

한 회사에서 MySQL용 Amazon RDS에 데이터베이스를 배포했습니다. 트랜잭션 증가로 인해 데이터베이스 지원 팀은 DB 인스턴스에 대한 느린 읽기를 보고하고 있으며 읽기 전용 복제본을 추가할 것을 권장합니다.
이 변경 사항을 구현하기 전에 솔루션 설계자가 수행해야 하는 작업 조합은 무엇입니까? (두 가지를 선택하세요.)

- [ ] A. RDS 기본 노드에서 binlog 복제를 활성화합니다.
- [ ] B. 원본 DB 인스턴스의 장애 조치 우선 순위를 선택합니다.
- [ ] C. 원본 DB 인스턴스에서 장기 실행 트랜잭션이 완료되도록 허용합니다.
- [ ] D. 글로벌 테이블을 생성하고 테이블을 사용할 수 있는 AWS 리전을 지정합니다.
- [ ] E. 백업 보존 기간을 0 이외의 값으로 설정하여 원본 인스턴스에서 자동 백업을 활성화합니다.

## Answer

정답: C, E

## Explanation

MySQL용 RDS 읽기 전용 복제본(Read Replica) 생성 전 두 가지 필수 조건이 있습니다. (C) 원본 DB 인스턴스에서 장기 실행 트랜잭션이 완료되어야 합니다 - 진행 중인 장기 트랜잭션은 binlog 위치에 영향을 미쳐 복제 시작점을 결정하기 어렵게 만들 수 있습니다. (E) 자동 백업이 활성화(backup retention period > 0)되어야 합니다 - 읽기 전용 복제본은 자동 백업의 binlog를 사용하여 초기 동기화를 수행하므로 이는 필수 전제조건입니다.

오답 분석

A: RDS for MySQL은 읽기 전용 복제본 생성 시 자동으로 binlog 복제를 설정합니다. 사용자가 수동으로 binlog 복제를 활성화할 필요가 없으며, 이는 자체 관리형 MySQL에서 필요한 작업입니다.

B: 장애 조치 우선 순위(Failover Priority)는 Multi-AZ 배포의 장애 조치 순서를 결정하는 설정이며, 읽기 전용 복제본 생성과는 무관한 기능입니다.

D: 글로벌 테이블은 Amazon DynamoDB의 기능이며, RDS MySQL과는 전혀 관련이 없습니다.
