## Question

한 회사가 Amazon Aurora PostgreSQL Serverless v2 클러스터에 애플리케이션을 배포할 계획입니다. 애플리케이션은 많은 양의 트래픽을 수신하게 됩니다. 회사는 애플리케이션의 로드가 증가함에 따라 클러스터의 스토리지 성능을 최적화하려고 합니다.
이러한 요구 사항을 가장 비용 효율적으로 충족하는 솔루션은 무엇입니까?

- [ ] A. Aurora Standard 스토리지 구성을 사용하도록 클러스터를 구성합니다.
- [ ] B. 클러스터 스토리지 유형을 프로비저닝된 IOPS로 구성합니다.
- [ ] C. 클러스터 저장소 유형을 범용으로 구성합니다.
- [ ] D. Aurora I/O 최적화 스토리지 구성을 사용하도록 클러스터를 구성합니다.

## Answer

정답: D

## Explanation

Aurora I/O 최적화(I/O-Optimized) 스토리지 구성은 I/O 집약적인 워크로드에서 비용 효율적인 성능 최적화를 제공합니다. 이 구성은 읽기 및 쓰기 I/O 작업에 대한 추가 비용 없이 예측 가능한 요금을 제공하며, I/O 비용이 총 Aurora 데이터베이스 지출의 25%를 초과하는 워크로드에서 최대 40%의 비용을 절감할 수 있습니다. 대량 트래픽을 수신하는 애플리케이션에서 스토리지 성능을 최적화하는 데 가장 적합합니다.

오답 분석

A: Aurora Standard 스토리지 구성은 기본 설정으로, I/O 작업에 대해 별도의 비용이 부과됩니다. 대량 트래픽으로 인한 높은 I/O 워크로드에서는 비용이 급격히 증가할 수 있어 비용 효율적이지 않습니다.

B: 프로비저닝된 IOPS는 RDS의 스토리지 유형이지, Aurora의 스토리지 구성 옵션이 아닙니다. Aurora는 자체 분산 스토리지 시스템을 사용하며, Aurora Standard 또는 I/O-Optimized 중에서 선택합니다.

C: 범용(General Purpose) 스토리지도 RDS의 스토리지 유형이며, Aurora에서는 이 옵션을 직접 선택할 수 없습니다. Aurora의 스토리지는 자동으로 관리되며, Standard 또는 I/O-Optimized 구성 중 선택합니다.
