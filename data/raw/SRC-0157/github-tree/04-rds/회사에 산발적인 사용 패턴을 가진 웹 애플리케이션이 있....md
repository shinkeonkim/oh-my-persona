## Question

회사에 산발적인 사용 패턴을 가진 웹 애플리케이션이 있습니다. 매달 초에는 사용량이 많고, 매주 초에는 보통 사용량이 있으며, 주중에는 예측할 수 없는 사용량이 있습니다. 이 애플리케이션은 웹 서버와 데이터 센터 내에서 실행되는 MySQL 데이터베이스 서버로 구성됩니다. 이 회사는 애플리케이션을 AWS 클라우드로 이동하려고 하며 데이터베이스 수정이 필요하지 않은 비용 효율적인 데이터베이스 플랫폼을 선택해야 합니다.
이러한 요구 사항을 충족하는 솔루션은 무엇입니까?

- [ ] A. Amazon DynamoDB
- [ ] B. MySQL용 Amazon RDS
- [ ] C. MySQL 호환 Amazon Aurora Serverless
- [ ] D. Auto Scaling 그룹의 Amazon EC2에 배포된 MySQL

## Answer

정답: C

## Explanation

MySQL 호환 Amazon Aurora Serverless는 산발적이고 예측 불가능한 사용 패턴에 최적의 솔루션입니다. Aurora Serverless는 트래픽에 따라 자동으로 용량을 확장하고 축소하며, 사용하지 않을 때는 자동으로 일시 중지하여 비용을 절감합니다. MySQL 호환이므로 데이터베이스 수정이 필요하지 않으며, 월초 높은 사용량, 주초 보통 사용량, 주중 예측 불가능한 사용량 패턴에 모두 자동으로 대응할 수 있습니다.

오답 분석

A: Amazon DynamoDB는 NoSQL 데이터베이스로, 기존 MySQL 데이터베이스에서 마이그레이션하려면 스키마와 쿼리를 변환해야 하므로 '데이터베이스 수정이 필요하지 않은' 요구 사항에 위배됩니다.

B: MySQL용 Amazon RDS는 고정된 인스턴스 크기를 사용하므로 트래픽이 낮을 때에도 동일한 비용이 발생하여 비용 효율적이지 않습니다. 산발적인 사용 패턴에 자동 확장되지 않습니다.

D: Auto Scaling 그룹의 EC2에 MySQL을 배포하면 데이터베이스 관리, 패칭, 백업 등의 운영 오버헤드가 크고, EC2 Auto Scaling은 데이터베이스 상태를 고려하지 않으므로 적합하지 않습니다.
