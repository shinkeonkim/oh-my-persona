## Question

한 회사가 Amazon RDS for PostgreSQL을 사용하여 us-east-1 리전에서 애플리케이션을 실행합니다. 이 회사는 또한 기계 학습(ML) 모델을 사용하여 거의 실시간 보고서를 기반으로 연간 수익을 예측합니다. 보고서는 동일한 RDS for PostgreSQL 데이터베이스를 사용하여 생성됩니다. 데이터베이스 성능은 영업 시간 동안 느려집니다. 이 회사는 데이터베이스 성능을 개선해야 합니다. 어떤 솔루션이 이러한 요구 사항을 가장 비용 효율적으로 충족할까요?

- [ ] A. 교차 리전 읽기 전용 복제본을 생성하고, 보고서는 해당 읽기 전용 복제본에서 생성되도록 구성합니다.
- [ ] B. RDS for PostgreSQL에 대해 Multi-AZ DB 인스턴스 배포를 활성화하고, 보고서는 스탠바이 데이터베이스에서 생성되도록 구성합니다.
- [ ] C. AWS 데이터베이스 마이그레이션 서비스(AWS DMS)를 사용하여 새 데이터베이스로 데이터를 논리적으로 복제하고, 보고서는 새 데이터베이스에서 생성되도록 구성합니다.
- [ ] D. us-east-1 리전에 읽기 전용 복제본을 생성하고, 보고서는 해당 읽기 전용 복제본에서 생성되도록 구성합니다.

## Answer

정답: D

## Explanation

동일 리전(us-east-1)에 읽기 전용 복제본을 생성하면 ML 보고서 생성의 읽기 쿼리를 복제본으로 분산하여 기본 데이터베이스의 영업 시간 성능 저하를 방지합니다. 교차 리전 복제본보다 데이터 전송 비용이 낮고 복제 지연이 적어 거의 실시간 보고서 생성에 적합하며 비용 효율적입니다.

오답 분석

A: 교차 리전 읽기 전용 복제본은 동일 리전 복제본보다 데이터 전송 비용이 높고, 리전 간 복제 지연으로 실시간 보고서의 정확도가 떨어질 수 있습니다.

B: Multi-AZ 배포의 스탠바이 인스턴스는 읽기 트래픽을 처리할 수 없으며, 장애 조치(failover) 목적으로만 사용됩니다.

C: AWS DMS로 새 데이터베이스에 데이터를 복제하면 추가 데이터베이스 관리가 필요하고, 읽기 전용 복제본보다 운영 오버헤드가 높습니다.
