## Question

한 회사가 프로덕션 환경 애플리케이션을 AWS 클라우드로 마이그레이션하고 있습니다. 이 회사는 데이터베이스 계층에 Amazon RDS for Oracle을 사용합니다. 이 회사는 낮은 지연 시간과 일관된 처리량이 요구되는 높은 I/O 집약적 워크로드의 요구 사항을 충족하도록 데이터베이스를 구성해야 합니다. 데이터베이스 워크로드는 읽기 및 쓰기 집약적입니다.
이러한 요구 사항을 충족하는 솔루션은 무엇입니까?

- [ ] A. RDS for Oracle 데이터베이스에 다중 AZ DB 인스턴스 배포를 사용합니다.
- [ ] B. RDS for Oracle 데이터베이스가 프로비저닝된 IOPS SSD 스토리지 유형을 사용하도록 구성합니다.
- [ ] C. RDS for Oracle 데이터베이스가 범용 SSD 스토리지 유형을 사용하도록 구성합니다.
- [ ] D. RDS for Oracle에 RDS 읽기 복제본을 활성화합니다.

## Answer

정답: B

## Explanation

Provisioned IOPS SSD(io1/io2) 스토리지 유형은 사용자가 지정한 IOPS를 일관되게 제공하여 예측 가능한 높은 I/O 성능과 한 자릿수 밀리초(single-digit millisecond) 수준의 낮은 지연 시간을 보장합니다. 읽기와 쓰기가 모두 집약적인 프로덕션 워크로드에 최적이며, IOPS를 스토리지 용량과 독립적으로 구성하여 성능을 세밀하게 조정할 수 있습니다.

오답 분석

A: Multi-AZ 배포는 고가용성과 자동 장애 조치(failover)를 제공하지만, I/O 성능을 직접 향상시키지 않습니다.

C: General Purpose SSD(gp2/gp3)는 범용 목적의 스토리지로, 높은 I/O 집약적 워크로드에서 일관된 성능을 보장하지 못할 수 있습니다.

D: RDS 읽기 복제본은 읽기 트래픽을 분산하지만, 쓰기 집약적 워크로드의 지연 시간과 처리량 문제를 해결하지 못합니다.
