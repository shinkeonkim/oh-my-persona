## Question

빠르게 성장하는 글로벌 전자상거래 회사는 AWS에서 웹 애플리케이션을 호스팅하고 있습니다. 웹 애플리케이션에는 정적 콘텐츠와 동적 콘텐츠가 포함됩니다. 웹사이트는 Amazon RDS 데이터베이스에 OLTP(온라인 트랜잭션 처리) 데이터를 저장합니다. 웹사이트 사용자의 페이지 로드 속도가 느려지고 있습니다.
이 문제를 해결하기 위해 솔루션 아키텍트가 취해야 할 조치 조합은 무엇입니까? (두 가지를 선택하세요.)

- [ ] A. Amazon Redshift 클러스터를 구성합니다.
- [ ] B. Amazon CloudFront 배포를 설정합니다.
- [ ] C. Amazon S3에서 동적 웹 콘텐츠를 호스팅합니다.
- [ ] D. RDS DB 인스턴스에 대한 읽기 전용 복제본을 생성합니다.
- [ ] E. RDS DB 인스턴스에 대한 다중 AZ 배포를 구성합니다.

## Answer

정답: B, D

## Explanation

Amazon CloudFront 배포를 설정하면 정적 콘텐츠를 엣지 로케이션에서 캐싱하여 글로벌 사용자에게 빠른 응답을 제공합니다. 또한 RDS DB 인스턴스에 대한 읽기 전용 복제본을 생성하면 데이터베이스 읽기 트래픽을 분산시켜 기본 DB 인스턴스의 부하를 줄이고 OLTP 성능을 향상시킵니다. 이 두 가지 조합으로 정적 콘텐츠 전달과 데이터베이스 읽기 성능 모두를 개선할 수 있습니다.

오답 분석

A: Amazon Redshift는 데이터 웨어하우스 서비스로, 전자상거래 웹 애플리케이션의 OLTP 워크로드에는 적합하지 않습니다.

C: Amazon S3는 정적 콘텐츠 호스팅에 적합하지만, 동적 웹 콘텐츠를 호스팅하기에는 적합하지 않습니다. 동적 콘텐츠는 서버 측 처리가 필요합니다.

E: Multi-AZ 배포는 고가용성과 장애 조치를 위한 것이며, 대기 인스턴스는 읽기 요청을 처리하지 않으므로 페이지 로드 성능 개선에 도움이 되지 않습니다.
