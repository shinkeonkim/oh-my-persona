## Question

한 회사가 Amazon Aurora PostgreSQL 데이터베이스를 사용하는 새로운 웹 애플리케이션을 출시했습니다. 이 회사는 AI 기반 애플리케이션에 새로운 기능을 추가하려고 합니다. AI 도구를 사용하려면 벡터 스토리지 기능이 필요합니다.
이 요구 사항을 가장 비용 효율적으로 충족하는 솔루션은 무엇입니까?

- [ ] A. Amazon OpenSearch Service를 사용하여 OpenSearch 서비스를 생성합니다. 벡터 인덱스에 벡터 임베딩을 작성하도록 애플리케이션을 구성합니다.
- [ ] B. Amazon DocumentDB 클러스터를 생성합니다. 벡터 인덱스에 벡터 임베딩을 작성하도록 애플리케이션을 구성합니다.
- [ ] C. Amazon Neptune ML 클러스터를 생성합니다. 벡터 그래프에 벡터 임베딩을 작성하도록 애플리케이션을 구성합니다.
- [ ] D. Aurora PostgreSQL 데이터베이스에 pgvector 확장 프로그램을 설치합니다. 벡터 테이블에 벡터 임베딩을 작성하도록 애플리케이션을 구성합니다.

## Answer

정답: D

## Explanation

기존 Aurora PostgreSQL 데이터베이스에 pgvector 확장을 설치하면, 별도의 벡터 데이터베이스 서비스를 프로비저닝하지 않고 동일한 데이터베이스 인스턴스에서 벡터 임베딩을 저장하고 코사인 유사도 등 벡터 검색을 수행할 수 있어 가장 비용 효율적입니다. 기존 인프라를 그대로 활용하므로 추가 운영 비용이 발생하지 않습니다.

오답 분석

A: Amazon OpenSearch Service는 벡터 검색을 지원하지만, 별도의 클러스터를 프로비저닝하고 관리해야 하므로 추가 비용이 발생합니다.

B: Amazon DocumentDB 클러스터를 생성하면 별도의 데이터베이스 관리와 추가 비용이 발생합니다.

C: Amazon Neptune ML은 그래프 데이터베이스 기반이며, 벡터 스토리지 전용 솔루션으로는 과도하고 비용이 높습니다.
