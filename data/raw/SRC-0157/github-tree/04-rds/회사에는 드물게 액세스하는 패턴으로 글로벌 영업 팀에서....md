## Question

회사에는 드물게 액세스하는 패턴으로 글로벌 영업 팀에서 사용하는 온프레미스 MySQL 데이터베이스가 있습니다. 영업팀은 데이터베이스의 가동 중지 시간을 최소화해야 합니다. 데이터베이스 관리자는 향후 더 많은 사용자를 예상하여 특정 인스턴스 유형을 선택하지 않고 이 데이터베이스를 AWS로 마이그레이션하려고 합니다.
솔루션 설계자는 어떤 서비스를 추천해야 합니까?

- [ ] A. Amazon Aurora MySQL
- [ ] B. MySQL용 Amazon Aurora 서버리스
- [ ] C. Amazon Redshift Spectrum
- [ ] D. MySQL용 Amazon RDS

## Answer

정답: B

## Explanation

Amazon Aurora Serverless for MySQL은 드문 액세스 패턴과 미래 사용자 증가를 모두 충족하는 최적의 솔루션입니다. Aurora Serverless는 특정 인스턴스 유형을 선택할 필요 없이 자동으로 용량을 조정하며, 사용하지 않을 때는 자동으로 일시 중지되어 비용을 절감합니다. MySQL 호환이므로 마이그레이션이 간편하고, 가동 중지 시간을 최소화할 수 있습니다.

오답 분석

A: Amazon Aurora MySQL은 특정 인스턴스 유형을 선택해야 하므로 '특정 인스턴스 유형을 선택하지 않고'라는 요구 사항에 맞지 않습니다. 또한 드물게 액세스하는 패턴에서는 고정 비용이 발생하여 비용 효율적이지 않습니다.

C: Amazon Redshift Spectrum은 데이터 웨어하우스 서비스로, Amazon S3에 저장된 데이터에 대한 분석 쿼리를 실행하기 위한 것입니다. MySQL 데이터베이스의 트랜잭션 처리 용도로는 적합하지 않습니다.

D: Amazon RDS for MySQL도 특정 인스턴스 유형을 선택해야 하며, 자동 확장 기능이 Aurora Serverless만큼 유연하지 않습니다. 드문 사용 패턴에서 고정 비용이 발생합니다.
