## Question

회사에서 워크로드를 AWS로 마이그레이션하고 있습니다. 회사는 데이터베이스에 거래 및 민감한 데이터를 가지고 있습니다. 이 회사는 AWS 클라우드 솔루션을 사용하여 보안을 강화하고 데이터베이스의 운영 오버헤드를 줄이려고 합니다.
이러한 요구 사항을 충족하는 솔루션은 무엇입니까?

- [ ] A. 데이터베이스를 Amazon EC2로 마이그레이션합니다. 암호화에 AWS Key Management Service(AWS KMS) AWS 관리형 키를 사용합니다.
- [ ] B. 데이터베이스를 Amazon RDS로 마이그레이션합니다. 유휴 암호화를 구성합니다.
- [ ] C. 데이터를 Amazon S3로 마이그레이션합니다. 데이터 보안 및 보호를 위해 Amazon Macie를 사용합니다.
- [ ] D. 데이터베이스를 Amazon RDS로 마이그레이션합니다. 데이터 보안 및 보호를 위해 Amazon CloudWatch Logs를 사용합니다.

## Answer

정답: B

## Explanation

Amazon RDS로 데이터베이스를 마이그레이션하고 유휴 암호화(encryption at rest)를 구성하면 보안을 강화하면서 운영 오버헤드를 줄일 수 있습니다. RDS는 완전 관리형 데이터베이스 서비스로 패칭, 백업, 장애 조치 등을 자동으로 관리합니다. 유휴 암호화는 AWS KMS를 사용하여 데이터, 자동 백업, 스냅샷, 읽기 전용 복제본을 포함한 모든 데이터를 암호화하여 민감한 데이터를 보호합니다.

오답 분석

A: Amazon EC2에 데이터베이스를 마이그레이션하면 관리형 서비스가 아니므로 OS 패칭, 백업, 고가용성 구성 등을 직접 관리해야 합니다. 운영 오버헤드를 줄이려는 요구 사항에 맞지 않습니다.

C: Amazon S3는 객체 스토리지 서비스로, 트랜잭션 데이터를 저장하는 데이터베이스를 대체할 수 없습니다. Amazon Macie는 S3 데이터의 개인 식별 정보(PII) 검색에 사용되며, 데이터베이스 보안 솔루션이 아닙니다.

D: Amazon CloudWatch Logs는 로그 모니터링 서비스이지, 데이터 보안 및 보호 솔루션이 아닙니다. 데이터 암호화나 접근 제어 기능을 제공하지 않습니다.
