## Question

한 회사가 비운영 애플리케이션에 관리형 MySQL 데이터베이스 솔루션을 배포할 계획입니다. 이 회사는 AWS에서 수년간 시스템을 운영할 계획입니다.
이러한 요구 사항을 가장 비용 효율적으로 충족하는 솔루션은 무엇입니까?

- [ ] A. Amazon RDS for MySQL 인스턴스를 생성합니다. 예약 인스턴스를 구매합니다.
- [ ] B. Amazon RDS for MySQL 인스턴스를 생성합니다. 해당 인스턴스를 온디맨드 방식으로 사용합니다.
- [ ] C. 쓰기 노드와 읽기 노드가 있는 Amazon Aurora MySQL 클러스터를 생성합니다. 해당 클러스터를 온디맨드 방식으로 사용합니다.
- [ ] D. Amazon EC2 인스턴스를 생성합니다. 해당 인스턴스에 MySQL 서버를 수동으로 설치하고 구성합니다.

## Answer

정답: A

## Explanation

Amazon RDS for MySQL 인스턴스를 생성하고 예약 인스턴스(Reserved Instance)를 구매하면, 수년간 연속 실행되는 비프로덕션 애플리케이션에 대해 온디맨드 대비 최대 72%까지 할인된 비용으로 관리형 MySQL 데이터베이스를 사용할 수 있습니다. RDS 관리형 서비스로 자동 패치, 백업, 모니터링이 제공됩니다.

오답 분석

B: RDS 인스턴스를 온디맨드로 수년간 사용하면 예약 인스턴스보다 총 비용이 크게 높아 비용 효율적이지 않습니다.

C: Aurora MySQL 클러스터(쓰기+읽기 노드)는 RDS MySQL보다 비용이 높으며, 비프로덕션 환경에 과도한 구성입니다.

D: EC2에 MySQL을 수동 설치/구성하면 데이터베이스 관리 오버헤드가 크고, 관리형 서비스의 자동화 이점을 잃습니다.
