## Question

한 회사가 관계형 데이터를 저장하기 위해 Amazon RDS for MySQL을 사용하는 웹 애플리케이션을 운영하고 있습니다. 데이터베이스의 데이터는 자주 변경되지 않습니다. 솔루션 아키텍트는 사용량이 많은 시간대에 데이터베이스에서 데이터를 제공할 때 성능 문제가 발생한다는 것을 발견했습니다. 회사는 데이터베이스 성능을 개선하고자 합니다.
다음 요구 사항을 충족하는 단계 조합은 무엇입니까? (2개 선택)

- [ ] A. AWS WAF를 애플리케이션과 통합합니다.
- [ ] B. 데이터베이스의 읽기 전용 복제본을 생성합니다. 읽기 트래픽을 읽기 전용 복제본으로 리디렉션합니다.
- [ ] C. Amazon ElastiCache(Memcached) 클러스터를 생성합니다. 클러스터와 통합되도록 애플리케이션과 데이터베이스를 구성합니다.
- [ ] D. Amazon S3 One Zone-Infrequent Access(S3 One Zone-IA) 스토리지 클래스를 사용하여 자주 변경되지 않는 데이터를 저장합니다.
- [ ] E. 데이터베이스를 Amazon DynamoDB로 마이그레이션합니다. DynamoDB 데이터베이스를 사용하도록 애플리케이션을 구성합니다.

## Answer

정답: B, C

## Explanation

읽기 전용 복제본을 생성하면 읽기 트래픽을 분산하여 기본 데이터베이스의 부하를 줄입니다(B). ElastiCache(Memcached)를 사용하면 자주 변경되지 않는 데이터를 메모리에 캐싱하여 데이터베이스 쿼리 횟수를 크게 줄여 성능이 향상됩니다(C). 두 솔루션을 함께 사용하면 읽기 부하 분산과 캐싱의 이중 효과를 얻습니다.

오답 분석

A: AWS WAF는 웹 애플리케이션 방화벽으로, 데이터베이스 성능 향상과는 관련이 없는 보안 서비스입니다.

D: S3 One Zone-IA는 객체 스토리지로 관계형 데이터를 저장하는 데 적합하지 않으며, 데이터베이스 성능 문제를 해결하지 못합니다.

E: DynamoDB로 마이그레이션하는 것은 NoSQL로의 전환으로, 관계형 데이터 모델의 변경이 필요하여 최소한의 노력으로 충족되지 않습니다.
