## Question

회사는 다른 팀이 액세스할 수 있도록 하루에 한 번씩 데이터베이스를 Amazon S3로 내보내야 합니다. 내보낸 객체 크기는 2GB에서 5GB 사이입니다. 데이터에 대한 S3 액세스 패턴은 가변적이며 빠르게 변화합니다. 데이터는 즉시 사용할 수 있어야 하며 최대 3개월 동안 액세스할 수 있어야 합니다. 회사에는 검색 시간을 늘리지 않는 가장 비용 효율적인 솔루션이 필요합니다.
이러한 요구 사항을 충족하려면 회사에서 어떤 S3 스토리지 클래스를 사용해야 합니까?

- [ ] A. S3 Intelligent-Tiering
- [ ] B. S3 Glacier Instant Retrieval
- [ ] C. S3 Standard
- [ ] D. S3 Standard-Infrequent Access(S3 Standard-IA)

## Answer

정답: A

## Explanation

S3 Intelligent-Tiering은 가변적이고 빠르게 변화하는 액세스 패턴에 가장 적합한 스토리지 클래스입니다. 액세스 패턴에 따라 자동으로 비용이 가장 효율적인 계층으로 데이터를 이동하며, 즉시 접근성을 유지합니다. 검색 시간이 증가하지 않으면서도 비용을 최적화할 수 있습니다.

오답 분석

B: S3 Glacier Instant Retrieval은 분기별 1회 정도 액세스하는 데이터에 적합하지만, 이 시나리오에서는 액세스 패턴이 가변적이므로 자주 액세스할 때 높은 검색 비용이 발생할 수 있습니다.

C: S3 Standard은 비용 최적화 없이 모든 데이터에 동일한 높은 스토리지 비용을 적용하므로, 가장 비용 효율적인 솔루션이 아닙니다.

D: S3 Standard-IA는 자주 액세스하지 않는 데이터에 적합하지만, 가변적인 액세스 패턴에서는 검색 비용이 예측 불가능하게 증가할 수 있습니다.
