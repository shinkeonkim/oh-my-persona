## Question

소비자 조사 회사가 특정 지리적 지역에서 수년간 데이터를 수집했습니다. 이 회사는 이 데이터를 AWS 리전의 Amazon S3 버킷에 저장합니다. 이 회사는 이 데이터를 새로운 지리적 지역의 마케팅 회사와 공유하기 시작했습니다. 이 회사는 마케팅 회사의 AWS 계정에 S3 버킷에 대한 액세스 권한을 부여했습니다. 이 회사는 마케팅 회사가 S3 버킷에서 데이터를 요청할 때 데이터 전송 비용을 최소화하려고 합니다.
어떤 솔루션이 이러한 요구 사항을 충족할까요?

- [ ] A. 회사의 S3 버킷에서 요청자 지불 기능을 구성합니다.
- [ ] B. 회사의 S3 버킷에서 마케팅 회사의 S3 버킷 중 하나로 S3 교차 리전 복제(CRR)를 구성합니다.
- [ ] C. AWS Resource Access Manager를 구성하여 마케팅 회사의 AWS 계정과 S3 버킷을 공유합니다.
- [ ] D. S3 Intelligent-Tiering을 사용하도록 회사의 S3 버킷을 구성합니다. S3 버킷을 마케팅 회사의 S3 버킷 중 하나와 동기화합니다.

## Answer

정답: A

## Explanation

S3 Requester Pays 기능을 활성화하면, 마케팅 회사가 S3 버킷에서 데이터를 요청할 때 데이터 전송 비용을 마케팅 회사의 AWS 계정이 부담하므로, 설문조사 회사의 데이터 전송 비용을 최소화할 수 있습니다. 설문조사 회사는 S3 스토리지 비용만 부담합니다.

오답 분석

B: S3 Cross-Region Replication은 데이터를 복제하여 마케팅 회사의 리전에 별도 사본을 유지하므로 추가 스토리지와 복제 비용이 발생합니다.

C: AWS Resource Access Manager는 VPC 서브넷, Route 53 규칙 등의 리소스를 공유하는 도구이며, S3 버킷 공유에는 사용할 수 없습니다.

D: S3 Intelligent-Tiering은 스토리지 클래스를 자동 최적화하지만 데이터 전송 비용을 줄이지 않으며, S3 버킷 동기화는 추가 비용이 발생합니다.
