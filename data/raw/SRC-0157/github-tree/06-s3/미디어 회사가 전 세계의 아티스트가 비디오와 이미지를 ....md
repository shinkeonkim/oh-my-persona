## Question

미디어 회사가 전 세계의 아티스트가 비디오와 이미지를 Amazon S3 버킷에 직접 업로드하는 데 사용할 수 있는 새로운 제품 플랫폼을 출시합니다. 이 회사는 S3 버킷을 소유하고 유지 관리합니다. 아티스트는 AWS 자격 증명이나 AWS 계정이 필요 없이 개인 기기에서 파일을 업로드할 수 있어야 합니다.
어떤 솔루션이 이러한 요구 사항을 가장 안전하게 충족할까요?

- [ ] A. S3 버킷에서 교차 출처 리소스 공유(CORS)를 활성화합니다.
- [ ] B. S3 버킷에 대한 공개 액세스 차단을 끕니다. 버킷 URL을 아티스트와 공유하여 자격 증명 없이 업로드를 활성화합니다.
- [ ] C. S3 버킷에 대한 업로드 권한이 있는 IAM 역할을 사용하여 각 아티스트에 고유한 S3 접두사에 대한 미리 서명된 URL을 생성합니다. URL을 아티스트와 공유합니다.
- [ ] D. S3 버킷에서 객체를 업로드하고 볼 수 있는 권한이 있는 IAM 역할을 사용하는 웹 인터페이스를 만듭니다. 웹 인터페이스 URL을 아티스트와 공유합니다.

## Answer

정답: C

## Explanation

S3 사전 서명된 URL(pre-signed URL)은 IAM 역할의 임시 자격 증명을 기반으로 생성되며, 지정된 시간 동안만 유효한 업로드 URL을 제공합니다. 아티스트는 AWS 계정이나 자격 증명 없이도 이 URL을 통해 안전하게 파일을 업로드할 수 있습니다. 각 아티스트에 고유한 S3 접두사를 지정하여 업로드 범위를 제한하므로 다른 아티스트의 데이터에 접근할 수 없어 보안이 강화됩니다.

오답 분석

A: CORS(Cross-Origin Resource Sharing) 설정은 브라우저의 교차 출처 HTTP 요청을 허용하는 메커니즘이며, 인증이나 업로드 권한을 부여하는 기능이 아닙니다.

B: 퍼블릭 액세스를 활성화하면 누구나 버킷에 접근할 수 있어 보안상 매우 위험하며, '가장 안전하게' 요구사항에 완전히 위배됩니다.

D: IAM 역할을 사용하는 웹 인터페이스를 공유하면 IAM 역할의 자격 증명이 클라이언트 측에서 노출될 수 있으며, 사전 서명된 URL 방식보다 보안이 취약합니다.
