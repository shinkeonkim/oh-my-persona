## Question

회사는 Amazon Linux EC2 인스턴스 그룹에서 애플리케이션을 실행합니다. 규정 준수를 위해 회사는 모든 애플리케이션 로그 파일을 7년 동안 보관해야 합니다. 로그 파일은 모든 파일에 동시에 액세스할 수 있어야 하는 보고 도구로 분석됩니다.
이러한 요구 사항을 가장 비용 효율적으로 충족하는 스토리지 솔루션은 무엇입니까?

- [ ] A. Amazon Elastic Block Store(Amazon EBS)
- [ ] B. Amazon Elastic File System(Amazon EFS)
- [ ] C. Amazon EC2 인스턴스 스토어
- [ ] D. Amazon S3

## Answer

정답: D

## Explanation

Amazon S3는 사실상 무제한 스토리지를 제공하며 7년간 로그 보관에 가장 비용 효율적인 솔루션입니다. S3는 여러 파일에 동시 액세스를 지원하므로 보고 도구가 모든 파일을 동시에 분석할 수 있습니다. 또한 S3 수명 주기 정책을 통해 자주 사용하지 않는 데이터를 S3 Standard-IA나 S3 Glacier로 자동 전환하여 장기 보관 비용을 크게 절감할 수 있으며, S3 Standard의 GB당 비용은 약 $0.023으로 다른 옵션보다 현저히 저렴합니다.

오답 분석

A: Amazon EBS는 단일 EC2 인스턴스에 연결되는 블록 스토리지 볼륨으로, 여러 인스턴스에서 동시 액세스가 제한적이며 GB당 비용이 S3의 약 4배 이상으로 7년간 보관 시 비용이 매우 높습니다.

B: Amazon EFS는 동시 액세스를 지원하지만 GB당 비용이 약 $0.30으로 S3($0.023)에 비해 약 13배 높아 7년간 대규모 로그 보관에 비용 효율적이지 않습니다.

C: EC2 인스턴스 스토어는 임시(ephemeral) 스토리지로, 인스턴스 중지 또는 종료 시 데이터가 영구적으로 손실되므로 7년간 장기 보관이 불가능합니다.
