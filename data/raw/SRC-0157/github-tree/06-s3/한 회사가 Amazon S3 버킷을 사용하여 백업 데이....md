## Question

한 회사가 Amazon S3 버킷을 사용하여 백업 데이터를 보관하려고 합니다. 규정에 따라 회사는 백업 데이터를 7년 동안 보관해야 합니다. 보관 기간 동안 회사는 관리자를 포함한 사용자가 데이터를 삭제하지 못하도록 해야 합니다. 회사는 7년 후에 데이터를 삭제할 수 있습니다.
이러한 요구 사항을 충족하는 솔루션은 무엇입니까?

- [ ] A. 7년 동안 삭제 작업을 거부하는 S3 버킷 정책을 생성합니다. 7년 후 데이터를 삭제하는 S3 수명 주기 정책을 생성합니다.
- [ ] B. 거버넌스 모드에서 7년 동안 데이터를 보관하는 S3 객체 잠금 기본 보관 정책을 생성합니다. 7년 후 데이터를 삭제하는 S3 수명 주기 정책을 생성합니다.
- [ ] C. 규정 준수 모드에서 7년 동안 데이터를 보관하는 S3 객체 잠금 기본 보관 정책을 생성합니다. 7년 후 데이터를 삭제하는 S3 수명 주기 정책을 생성합니다.
- [ ] D. 각 객체에 7년 동안 법적 보존을 설정하는 S3 배치 작업 작업을 생성합니다. 7년 후 데이터를 삭제하는 S3 수명 주기 정책을 생성합니다.

## Answer

정답: C

## Explanation

S3 Object Lock의 Compliance 모드는 보존 기간 동안 루트 사용자를 포함한 관리자도 객체를 삭제할 수 없게 합니다. 7년 보존 기간을 설정하고 S3 Lifecycle 정책으로 7년 후 자동 삭제를 구성하면 모든 요구사항을 충족합니다.

오답 분석

A: S3 버킷 정책은 관리자가 정책 자체를 변경할 수 있으므로 관리자의 삭제를 완전히 방지하지 못합니다.

B: Governance 모드는 특수 권한(s3:BypassGovernanceRetention)을 가진 사용자가 보존 설정을 우회하여 객체를 삭제할 수 있으므로 관리자 포함 삭제 방지 요구사항을 충족하지 못합니다.

D: S3 Batch Operations로 Legal Hold를 설정하면 보존 기간이 자동으로 만료되지 않아 7년 후 삭제가 복잡해지며, Legal Hold는 명시적으로 제거해야 합니다.
