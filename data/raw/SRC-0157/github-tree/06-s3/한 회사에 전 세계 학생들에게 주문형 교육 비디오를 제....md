## Question

한 회사에 전 세계 학생들에게 주문형 교육 비디오를 제공하는 애플리케이션이 있습니다. 또한 이 애플리케이션을 사용하면 승인된 콘텐츠 개발자가 비디오를 업로드할 수 있습니다. 데이터는 us-east-2 리전의 Amazon S3 버킷에 저장됩니다.
회사는 eu-west-2 리전에 S3 버킷을, ap-southeast-1 리전에 S3 버킷을 생성했습니다. 회사는 데이터를 새로운 S3 버킷에 복제하려고 합니다. 회사는 eu-west-2 및 ap-southeast-1 근처에서 비디오를 업로드하는 개발자와 비디오를 스트리밍하는 학생의 대기 시간을 최소화해야 합니다.
애플리케이션을 가장 적게 변경하여 이러한 요구 사항을 충족하는 단계 조합은 무엇입니까? (2개를 선택하세요.)

- [ ] A. us-east-2 S3 버킷에서 eu-west-2 S3 버킷으로 단방향 복제를 구성합니다. us-east-2 S3 버킷에서 ap-southeast-1 S3 버킷으로의 단방향 복제를 구성합니다.
- [ ] B. us-east-2 S3 버킷에서 eu-west-2 S3 버킷으로 단방향 복제를 구성합니다. eu-west-2 S3 버킷에서 ap-southeast-1 S3 버킷으로의 단방향 복제를 구성합니다.
- [ ] C. 세 지역 모두에 있는 S3 버킷 간에 양방향(bidirectional) 복제를 구성합니다.
- [ ] D. S3 다중 지역 액세스 포인트를 생성합니다. 비디오 스트리밍을 위해 다중 지역 액세스 포인트의 Amazon 리소스 이름(ARN)을 사용하도록 애플리케이션을 수정합니다. 비디오 업로드용 애플리케이션은 수정하지 않습니다.
- [ ] E. S3 다중 지역 액세스 포인트를 생성합니다. 비디오 스트리밍 및 업로드를 위해 다중 지역 액세스 포인트의 Amazon 리소스 이름(ARN)을 사용하도록 애플리케이션을 수정합니다.

## Answer

정답: C, E

## Explanation

C와 E가 정답입니다. 양방향(bidirectional) 복제를 세 리전 모두에 구성하면 어느 리전에서든 업로드된 비디오가 다른 리전으로 자동 복제됩니다. S3 Multi-Region Access Point를 생성하고 스트리밍과 업로드 모두에 ARN을 사용하면 사용자에게 가장 가까운 리전으로 자동 라우팅되어 대기 시간이 최소화됩니다. 이 조합이 애플리케이션 변경을 최소화합니다.

오답 분석

A: us-east-2에서만 단방향 복제를 구성하면 eu-west-2나 ap-southeast-1에서 업로드된 비디오가 다른 리전으로 복제되지 않습니다.

B: 체인 방식의 단방향 복제는 ap-southeast-1의 데이터가 us-east-2에 직접 복제되지 않아 데이터 일관성 문제가 발생합니다.

D: 업로드에 Multi-Region Access Point를 사용하지 않으면 eu-west-2나 ap-southeast-1의 개발자가 us-east-2에 직접 업로드해야 하여 대기 시간이 증가합니다.
