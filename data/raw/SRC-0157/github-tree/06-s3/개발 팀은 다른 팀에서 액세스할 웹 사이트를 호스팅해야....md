## Question

개발 팀은 다른 팀에서 액세스할 웹 사이트를 호스팅해야 합니다. 웹 사이트 콘텐츠는 HTML, CSS, 클라이언트 측 JavaScript 및 이미지로 구성됩니다.
웹 사이트 호스팅에 가장 비용 효율적인 방법은 무엇입니까?

- [ ] A. 웹 사이트를 컨테이너화하고 AWS Fargate에서 호스팅합니다.
- [ ] B. Amazon S3 버킷을 생성하고 그곳에서 웹사이트를 호스팅합니다.
- [ ] C. Amazon EC2 인스턴스에 웹 서버를 배포하여 웹사이트를 호스팅합니다.
- [ ] D. Express.js 프레임워크를 사용하는 AWS Lambda 대상으로 Application Load Balancer를 구성합니다.

## Answer

정답: B

## Explanation

HTML, CSS, 클라이언트 측 JavaScript, 이미지로만 구성된 정적 웹 사이트는 Amazon S3 버킷의 정적 웹 사이트 호스팅 기능을 사용하는 것이 가장 비용 효율적입니다. S3 정적 웹 사이트 호스팅은 서버 프로비저닝이나 관리가 불필요하며, 사용한 스토리지(GB당 $0.023)와 데이터 전송(GB당 $0.09)에 대해서만 비용을 지불합니다. S3는 99.999999999%의 내구성과 자동 확장을 제공하여 트래픽 변동에도 안정적으로 대응합니다.

오답 분석

A: AWS Fargate는 컨테이너 기반 서버리스 컴퓨팅으로, 정적 웹 사이트 호스팅에는 컨테이너 이미지 빌드, Task Definition 구성 등 불필요한 복잡성과 과도한 비용(vCPU/메모리 과금)을 초래합니다.

C: EC2 인스턴스에 웹 서버(Apache/Nginx)를 배포하면 인스턴스 비용이 24/7 발생하고, OS 패치, 보안 업데이트 등 서버 관리 오버헤드가 발생합니다. 정적 콘텐츠에 대해 S3보다 비용이 훨씬 높습니다.

D: ALB와 Lambda를 Express.js와 함께 사용하면 ALB 시간당 비용($0.0225/시간)과 Lambda 호출 비용이 발생하며, 정적 콘텐츠 제공에 불필요한 서버 측 처리 레이어를 추가합니다.
