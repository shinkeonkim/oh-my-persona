## Question

조사 회사는 미국 지역에서 몇 년 동안 데이터를 수집했습니다. 회사는 크기가 3TB이고 계속 증가하는 Amazon S3 버킷에서 데이터를 호스팅합니다. 회사는 S3 버킷을 보유한 유럽 마케팅 회사와 데이터를 공유하기 시작했습니다. 회사는 데이터 전송 비용이 가능한 한 낮게 유지되기를 원합니다.
이러한 요구 사항을 충족하는 솔루션은 무엇입니까?

- [ ] A. 회사의 S3 버킷에서 요청자 지불 기능을 구성합니다.
- [ ] B. 회사의 S3 버킷에서 마케팅 회사의 S3 버킷 중 하나로 S3 교차 리전 복제를 구성합니다.
- [ ] C. 마케팅 회사가 회사의 S3 버킷에 액세스할 수 있도록 마케팅 회사에 대한 교차 계정 액세스를 구성합니다.
- [ ] D. S3 Intelligent-Tiering을 사용하도록 회사의 S3 버킷을 구성합니다. 마케팅 회사의 S3 버킷 중 하나에 S3 버킷을 동기화합니다.

## Answer

정답: A

## Explanation

S3 Requester Pays 기능을 활성화하면 데이터를 요청하는 쪽(유럽 마케팅 회사)이 데이터 다운로드 및 요청에 대한 비용을 부담합니다. 이렇게 하면 조사 회사의 데이터 전송 비용이 최소화되며, 마케팅 회사는 자신의 AWS 자격 증명을 사용하여 데이터에 접근합니다. 조사 회사는 S3 스토리지 비용만 부담하면 되므로, 3TB 이상의 대규모 데이터를 공유하면서도 전송 비용 부담을 효과적으로 분리할 수 있습니다.

오답 분석

B: S3 교차 리전 복제(CRR)를 구성하면 US 리전에서 EU 리전으로의 복제 비용(데이터 전송 비용 + 스토리지 비용)이 모두 조사 회사에 청구되므로, 데이터 전송 비용을 최소화하려는 목표에 완전히 반합니다.

C: 교차 계정 액세스를 구성하면 마케팅 회사가 데이터에 접근할 수 있지만, Requester Pays 없이는 데이터 전송 비용이 여전히 버킷 소유자(조사 회사)에 청구됩니다.

D: S3 Intelligent-Tiering은 액세스 빈도에 따른 스토리지 비용 최적화 기능이며, 버킷 간 데이터 동기화 기능이 아닙니다. 데이터 전송 비용 절감과는 관련이 없습니다.
