## Question

어떤 회사가 사진을 저장하고 공유하는 애플리케이션을 운영합니다. 사용자는 사진을 Amazon S3 버킷에 업로드합니다. 사용자는 매일 약 150장의 사진을 업로드합니다. 이 회사는 각 새 사진의 썸네일을 만들고 두 번째 S3 버킷에 썸네일을 저장하는 솔루션을 설계하려고 합니다. 어떤 솔루션이 이러한 요구 사항을 가장 비용 효율적으로 충족할까요?

- [ ] A. Amazon EventBridge 예약 규칙을 구성하여 장기 실행 Amazon EMR 클러스터에서 매분 스크립트를 호출합니다. 썸네일이 없는 사진에 대한 썸네일을 생성하도록 스크립트를 구성합니다. 썸네일을 두 번째 S3 버킷에 업로드하도록 스크립트를 구성합니다.
- [ ] B. 항상 켜져 있는 메모리 최적화 Amazon EC2 인스턴스에서 매분 스크립트를 호출하도록 Amazon EventBridge 예약 규칙을 구성합니다. 썸네일이 없는 사진에 대한 썸네일을 생성하도록 스크립트를 구성합니다. 썸네일을 두 번째 S3 버킷에 업로드하도록 스크립트를 구성합니다.
- [ ] C. 사용자가 애플리케이션에 새 사진을 업로드할 때마다 AWS Lambda 함수를 호출하도록 S3 이벤트 알림을 구성합니다. Lambda 함수를 구성하여 썸네일을 생성하고 두 번째 S3 버킷에 썸네일을 업로드합니다.
- [ ] D. 사용자가 애플리케이션에 새 사진을 업로드할 때마다 AWS Lambda 함수를 호출하도록 S3 Storage Lens를 구성합니다. Lambda 함수를 구성하여 썸네일을 생성하고 두 번째 S3 버킷에 썸네일을 업로드합니다.

## Answer

정답: C

## Explanation

S3 이벤트 알림을 구성하면 사용자가 새 사진을 업로드할 때마다 AWS Lambda 함수가 자동으로 트리거되어 썸네일을 생성하고 두 번째 S3 버킷에 업로드합니다. 하루 약 150장의 적은 사진 수에서는 Lambda의 이벤트 기반 실행이 가장 비용 효율적이며, 사용한 컴퓨팅 시간에 대해서만 비용이 발생합니다.

오답 분석

A: Amazon EMR 클러스터를 장기 실행하면서 매분 스크립트를 실행하는 것은 하루 150장의 사진에 비해 과도한 인프라 비용이 발생합니다.

B: 메모리 최적화 EC2 인스턴스를 항상 실행하면 비활동 시간에도 비용이 발생하여 비용 효율적이지 않습니다.

D: S3 Storage Lens는 스토리지 분석 및 사용량 모니터링 도구이며, 이벤트 알림이나 Lambda 함수 트리거 기능을 제공하지 않습니다.
