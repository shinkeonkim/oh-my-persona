## Question

이미지 호스팅 회사는 대규모 자산을 Amazon S3 Standard 버킷에 업로드합니다. 회사는 S3 API를 사용하여 멀티파트 업로드를 병렬로 사용하고 동일한 객체가 다시 업로드되면 덮어씁니다. 업로드 후 처음 30일 동안 객체에 자주 액세스합니다. 객체는 30일 후에 덜 자주 사용되지만 각 객체에 대한 액세스 패턴은 일관되지 않습니다. 회사는 저장된 자산의 고가용성과 탄력성을 유지하면서 S3 스토리지 비용을 최적화해야 합니다.
이러한 요구 사항을 충족하기 위해 솔루션 설계자가 권장해야 하는 작업 조합은 무엇입니까? (두 가지를 선택하세요.)

- [ ] A. 30일 후에 자산을 S3 Intelligent-Tiering으로 이동합니다.
- [ ] B. 불완전한 멀티파트 업로드를 정리하도록 S3 수명 주기 정책을 구성합니다.
- [ ] C. 만료된 객체 삭제 마커를 정리하도록 S3 수명 주기 정책을 구성합니다.
- [ ] D. 30일 후에 자산을 S3 Standard-Infrequent Access(S3 Standard-IA)로 이동합니다.
- [ ] E. 30일 후 자산을 S3 One Zone-Infrequent Access(S3 One Zone-IA)로 이동합니다.

## Answer

정답: A, B

## Explanation

A와 B가 정답입니다. 30일 후 S3 Intelligent-Tiering으로 이동하면(A) 액세스 빈도에 따라 Frequent Access, Infrequent Access(30일 미접근 시), Archive Instant Access(90일 미접근 시) 계층 간 자동 전환되어, 일관되지 않는 액세스 패턴의 비용을 자동 최적화합니다. 모든 계층에서 밀리초 단위 즉시 접근이 가능하며 검색 비용이 없습니다. 불완전한 멀티파트 업로드를 정리하는 S3 수명 주기 정책(B)의 AbortIncompleteMultipartUpload 규칙을 구성하면, 병렬 멀티파트 업로드 중 완료되지 않은 파트(업로드 실패, 취소, 네트워크 중단)가 지정 일수(예: 7일) 후 자동 삭제되어 보이지 않는 스토리지 비용 누적을 방지합니다. 대규모 자산의 빈번한 멀티파트 업로드 환경에서 이 불완전한 파트는 상당한 비용을 발생시킬 수 있습니다.

오답 분석

C: 만료된 객체 삭제 마커(expired object delete markers) 정리는 S3 버전 관리 환경에서 모든 비현재 버전이 삭제되고 현재 버전도 삭제 마커뿐인 경우를 정리하는 기능입니다. 이 시나리오에서는 버전 관리가 명시되지 않았으며, 동일한 객체를 덮어쓰는(overwrite) 방식을 사용하므로 삭제 마커 정리의 비용 절감 효과가 미미합니다.

D: S3 Standard-IA는 고정된 스토리지 클래스로, 자주 액세스하는 객체에 GB당 $0.01의 검색 비용이 부과됩니다. 일관되지 않는 액세스 패턴에서 일부 객체가 자주 액세스되면 예상보다 높은 검색 비용이 발생할 수 있어, 검색 비용이 없는 Intelligent-Tiering보다 비용 예측이 어렵습니다.

E: S3 One Zone-IA는 단일 가용 영역에만 저장하므로 AZ 장애 시 데이터 손실 위험이 있어, '고가용성과 탄력성(high availability and resiliency)을 유지'하라는 요구 사항을 충족하지 못합니다.
