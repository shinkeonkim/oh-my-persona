## Question

미디어 회사는 구매 후 5분 이내에 스트리밍 콘텐츠를 제공하여 사용자 요구를 충족해야 하며, 영화의 출시 시기에 따라 수요가 다양합니다. 이에 따라 회사는 호스팅 서비스 비용을 최소화하는 것을 목표로 합니다.
이러한 요구 사항에 맞는 솔루션은 무엇입니까?

- [ ] A. 모든 미디어 콘텐츠를 Amazon S3에 저장합니다. 영화에 대한 수요가 감소함에 따라 S3 수명 주기 정책을 사용하여 미디어 데이터를 자주 액세스하지 않는 계층으로 전환합니다.
- [ ] B. 최신 영화 비디오 파일은 S3 Standard에 저장하고 이전 영화 비디오 파일은 S3 Standard-Infrequent Access(S3 Standard-IA)에 저장합니다. 표준 검색을 사용하여 오래된 영화의 비디오 파일을 검색합니다.
- [ ] C. S3 Intelligent-Tiering에 최신 영화 비디오 파일을 저장합니다. 오래된 영화 비디오 파일의 경우 S3 Glacier Flexible Retrieval을 사용합니다. 신속 검색을 사용하여 오래된 영화의 비디오 파일을 검색합니다.
- [ ] D. 최신 영화 비디오 파일은 S3 Standard에 저장하고 이전 영화 비디오 파일은 S3 Glacier Flexible Retrieval에 저장합니다. 대량 검색을 사용하여 오래된 영화의 비디오 파일을 검색합니다.

## Answer

정답: C

## Explanation

최신 영화는 S3 Intelligent-Tiering에 저장하여 수요 감소에 따라 자동으로 비용이 낮은 액세스 계층(Frequent, Infrequent, Archive Instant Access)으로 이동시킵니다. 오래된 영화는 S3 Glacier Flexible Retrieval에 저장하여 스토리지 비용을 GB당 약 $0.004로 최소화하고, 신속(Expedited) 검색을 사용하면 1-5분 이내에 검색이 완료되어 구매 후 5분 이내 스트리밍 요구 사항을 충족합니다. 이 조합이 비용 최소화와 성능 요구 사항을 모두 충족하는 최적의 솔루션입니다.

오답 분석

A: S3 수명 주기 정책으로 Infrequent Access 계층으로만 전환하는 것은 수요가 급격히 감소하는 오래된 영화의 비용을 Glacier만큼 절감하지 못하며, 5분 이내 스트리밍에 대한 명확한 검색 전략이 부재합니다.

B: S3 Standard-IA는 GB당 비용이 $0.0125로 Glacier($0.004)보다 약 3배 높아, 오래된 영화의 호스팅 비용 최소화 목표에 부합하지 않습니다.

D: 대량(Bulk) 검색은 5-12시간이 소요되어 구매 후 5분 이내 스트리밍 요구 사항을 전혀 충족하지 못합니다. 대량 검색은 비용 효율적이지만 긴급한 검색 요구에는 적합하지 않습니다.
