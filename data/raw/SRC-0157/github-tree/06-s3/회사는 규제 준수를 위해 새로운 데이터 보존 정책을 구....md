## Question

회사는 규제 준수를 위해 새로운 데이터 보존 정책을 구현해야 합니다. 이 정책의 일환으로 Amazon S3 버킷에 저장된 민감한 문서는 일정 기간 동안 삭제 또는 수정되지 않도록 보호해야 합니다.
어떤 솔루션이 이러한 요구 사항을 충족할까요?

- [ ] A. 필요한 객체에 대해 S3 객체 잠금을 활성화하고 거버넌스 모드를 활성화합니다.
- [ ] B. 필요한 객체에 대해 S3 객체 잠금을 활성화하고 규정 준수 모드를 활성화합니다.
- [ ] C. S3 버킷에서 버전 관리를 활성화합니다. 지정된 기간 후에 객체를 삭제하는 라이프사이클 정책을 설정합니다.
- [ ] D. 보존 기간 동안 객체를 S3 Glacier Flexible Retrieval로 전환하기 위한 S3 수명 주기 정책을 구성합니다.

## Answer

정답: B

## Explanation

S3 Object Lock의 규정 준수 모드(Compliance Mode)를 활성화하면, 지정된 보존 기간 동안 루트 사용자를 포함하여 누구도 객체를 삭제하거나 덮어쓸 수 없습니다. 보존 기간도 단축할 수 없어 규제 준수에 가장 적합하며, WORM(Write Once Read Many) 스토리지 모델을 제공합니다.

오답 분석

A: 거버넌스 모드(Governance Mode)는 s3:BypassGovernanceRetention 권한을 가진 사용자가 보존 설정을 우회할 수 있어 규제 준수에 불충분합니다.

C: 버전 관리와 라이프사이클 정책은 객체의 삭제나 수정을 방지하지 못하며, 보존 기간 동안 변경 불가 요구사항을 충족하지 않습니다.

D: S3 Glacier로의 전환은 스토리지 클래스 변경일 뿐, 객체의 삭제나 수정을 방지하지 못합니다.
