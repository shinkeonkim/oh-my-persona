## Question

회사에는 사용자가 웹 인터페이스 또는 모바일 앱을 통해 문서를 업로드하는 프로덕션 웹 애플리케이션이 있습니다. 새로운 규제 요구 사항에 따라 새 문서는 저장된 후에 수정하거나 삭제할 수 없습니다.
솔루션 설계자는 이 요구 사항을 충족하기 위해 무엇을 해야 합니까?

- [ ] A. S3 버전 관리 및 S3 객체 잠금이 활성화된 Amazon S3 버킷에 업로드된 문서를 저장합니다.
- [ ] B. 업로드된 문서를 Amazon S3 버킷에 저장합니다. 문서를 주기적으로 보관하도록 S3 수명 주기 정책을 구성합니다.
- [ ] C. 업로드된 문서를 S3 버전 관리가 활성화된 Amazon S3 버킷에 저장합니다. 모든 액세스를 읽기 전용으로 제한하도록 ACL을 구성합니다.
- [ ] D. 업로드된 문서를 Amazon Elastic File System(Amazon EFS) 볼륨에 저장합니다. 읽기 전용 모드로 볼륨을 마운트하여 데이터에 액세스합니다.

## Answer

정답: A

## Explanation

S3 Versioning과 S3 Object Lock이 모두 활성화된 버킷에 문서를 저장하면 WORM(Write Once Read Many) 모델을 구현하여 새로운 규제 요구 사항을 충족합니다. S3 Object Lock은 보존 기간(Retention Period)이나 법적 보존(Legal Hold)을 설정하여 저장된 문서의 덮어쓰기(수정)와 삭제를 완전히 방지합니다. 규정 준수(Compliance) 모드에서는 루트 사용자를 포함한 어떤 사용자도 보존 기간 동안 객체를 삭제할 수 없습니다.

오답 분석

B: S3 수명 주기 정책은 객체의 스토리지 클래스 자동 전환이나 만료 후 삭제를 자동화하는 도구이며, 문서의 수정이나 삭제를 방지하는 기능이 아닙니다. 오히려 자동 삭제를 설정할 수 있어 요구 사항에 반합니다.

C: 읽기 전용 ACL로 모든 액세스를 제한하면 새 문서 업로드도 불가능해지며, ACL은 버킷 소유자나 관리자에 의해 언제든 변경 가능하므로 완전한 WORM 보호를 제공하지 못합니다.

D: EFS 볼륨을 읽기 전용 모드로 마운트하면 새 문서 업로드가 불가능하며, 마운트 옵션은 재마운트로 언제든 변경 가능하므로 규제 준수를 보장하지 못합니다.
