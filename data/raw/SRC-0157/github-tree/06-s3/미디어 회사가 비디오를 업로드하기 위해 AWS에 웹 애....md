## Question

미디어 회사가 비디오를 업로드하기 위해 AWS에 웹 애플리케이션을 호스팅합니다. 인증된 사용자만 인증 후 지정된 시간 내에 업로드할 수 있어야 합니다.
어떤 솔루션이 최소한의 운영 오버헤드로 이러한 요구 사항을 충족할까요?

- [ ] A. 인증된 사용자에 대한 IAM 임시 보안 자격 증명을 생성하도록 애플리케이션을 구성합니다.
- [ ] B. 사용자가 인증될 때 사전 서명된 URL을 생성하는 AWS Lambda 함수를 만듭니다.
- [ ] C. Amazon Cognito와 통합되어 애플리케이션을 통한 직접 S3 버킷 액세스를 제어하고 기록하는 사용자 지정 인증 서비스를 개발합니다.
- [ ] D. AWS Security Token Service(AWS STS)를 사용하여 사전 정의된 IAM 역할을 수임하고, 인증된 사용자에게 비디오를 S3 버킷에 직접 업로드할 수 있는 임시 권한을 부여합니다.

## Answer

정답: B

## Explanation

AWS Lambda 함수를 생성하여 사용자 인증 후 S3 사전 서명된 URL(Pre-signed URL)을 생성하면, 지정된 만료 시간 내에만 S3 버킷에 직접 업로드가 가능합니다. 서버리스 방식으로 운영 오버헤드가 최소이며, 사전 서명된 URL의 시간 제한으로 보안이 보장됩니다.

오답 분석

A: IAM 임시 보안 자격 증명을 직접 생성하여 사용자에게 전달하는 것은 가능하지만, S3 업로드만을 위한 사전 서명된 URL이 더 간단하고 보안 범위가 제한적입니다.

C: Amazon Cognito와 통합된 사용자 정의 인증 서비스를 개발하면 커스텀 코드 작성과 관리가 필요하여 운영 오버헤드가 증가합니다.

D: AWS STS로 IAM 역할을 수임하여 임시 권한을 부여하면 구현이 복잡하고, 사전 서명된 URL보다 운영 오버헤드가 높습니다.
