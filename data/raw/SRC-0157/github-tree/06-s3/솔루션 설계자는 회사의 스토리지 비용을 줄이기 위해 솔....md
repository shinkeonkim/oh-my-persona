## Question

솔루션 설계자는 회사의 스토리지 비용을 줄이기 위해 솔루션을 구현해야 합니다. 회사의 모든 데이터는 Amazon S3 Standard 스토리지 클래스에 있습니다. 회사는 모든 데이터를 최소 25년 동안 보관해야 합니다. 가장 최근 2년 간의 데이터는 가용성이 높고 즉시 검색할 수 있어야 합니다.
이러한 요구 사항을 충족하는 솔루션은 무엇입니까?

- [ ] A. S3 수명 주기 정책을 설정하여 객체를 S3 Glacier Deep Archive로 즉시 전환합니다.
- [ ] B. 2년 후 객체를 S3 Glacier Deep Archive로 전환하도록 S3 수명 주기 정책을 설정합니다.
- [ ] C. S3 Intelligent-Tiering을 사용합니다. 보관 옵션을 활성화하여 데이터가 S3 Glacier Deep Archive에 보관되도록 합니다.
- [ ] D. 객체를 S3 One Zone-Infrequent Access(S3 One Zone-IA)로 즉시 전환하고 2년 후에 S3 Glacier Deep Archive로 전환하도록 S3 수명 주기 정책을 설정합니다.

## Answer

정답: B

## Explanation

최근 2년간의 데이터는 즉시 검색 가능해야 하므로 S3 Standard에 유지하고, 2년 후에 S3 Glacier Deep Archive로 전환하면 비용을 크게 절감할 수 있습니다. Glacier Deep Archive는 AWS에서 가장 저렴한 스토리지 클래스로 GB당 약 $0.00099이며, 25년 이상의 장기 보관에 최적입니다. S3 수명 주기 정책으로 730일(2년) 후 자동 전환을 설정하면 운영 개입 없이 비용이 최적화됩니다.

오답 분석

A: 즉시 Glacier Deep Archive로 전환하면 최근 2년간의 데이터에 즉시 접근할 수 없게 됩니다. Deep Archive의 표준 검색은 최대 12시간, 대량 검색은 최대 48시간이 소요되어 '즉시 검색 가능(immediately retrievable)' 요구 사항을 충족하지 못합니다.

C: S3 Intelligent-Tiering의 Deep Archive Access 계층은 180일 이상 액세스하지 않은 객체를 자동으로 아카이브할 수 있지만, '최근 2년 데이터는 즉시 접근 가능해야 한다'는 명확한 기준이 있으므로 수명 주기 정책으로 정확히 2년 시점에 전환하는 것이 더 적합하고 예측 가능합니다. Intelligent-Tiering은 액세스 빈도에 기반하여 전환하므로 시간 기반 요구사항에 불일치할 수 있습니다.

D: S3 One Zone-IA는 단일 가용 영역에만 데이터를 저장하여 AZ 장애 시 데이터 손실 위험이 있으며, 25년 이상 보관해야 하는 데이터에 이 위험은 허용되지 않습니다. 즉시 전환하면 자주 액세스하는 최근 데이터에 GB당 $0.01의 검색 비용이 추가 부과됩니다.
