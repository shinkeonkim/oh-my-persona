## Question

한 회사가 자율주행차에서 수집된 데이터를 자동차 업계와 공유하려고 합니다. 이 데이터는 Amazon S3 버킷에서 제공됩니다. 회사는 이 데이터를 다른 AWS 계정에 제공하는 데 드는 비용을 최소화하려고 합니다.
이 목표를 달성하기 위해 솔루션 아키텍트는 무엇을 해야 할까요?

- [ ] A. 버킷에 대한 S3 VPC 엔드포인트를 생성합니다.
- [ ] B. S3 버킷을 요청자 지불 버킷으로 구성합니다.
- [ ] C. S3 버킷 앞에 Amazon CloudFront 배포를 만듭니다.
- [ ] D. BitTorrent 프로토콜을 사용해서만 파일에 접근할 수 있도록 요구합니다.

## Answer

정답: B

## Explanation

S3 Requester Pays 버킷을 구성하면 데이터를 다운로드하는 요청자(다른 AWS 계정)가 데이터 전송 비용과 요청 비용을 부담합니다. 대규모 자율주행차 데이터셋을 여러 자동차 업계 파트너와 공유할 때, 데이터 소유 회사는 S3 저장 비용만 부담하고 각 데이터 소비자가 자신의 다운로드 비용을 지불하므로 비용을 최소화할 수 있습니다. 요청자는 x-amz-request-payer 헤더를 포함하여 비용 부담에 동의합니다.

오답 분석

A: S3 VPC 엔드포인트는 VPC 내부에서 S3에 프라이빗하게 접근하기 위한 것으로, 외부 AWS 계정과의 데이터 공유 비용 절감 메커니즘이 아닙니다.

C: CloudFront 배포는 콘텐츠 전송 속도를 높이지만, 데이터 전송 비용은 여전히 회사가 부담하므로 비용 최소화 요구사항을 충족하지 못합니다.

D: Amazon S3는 BitTorrent 프로토콜 지원을 중단하였으므로 유효한 솔루션이 아닙니다.
