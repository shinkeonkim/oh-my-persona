## Question

회사는 Amazon S3에 텍스트 파일을 저장합니다. 텍스트 파일에는 고객 채팅 메시지, 날짜 및 시간 정보, 고객 개인 식별 정보(PII)가 포함됩니다.
회사에는 품질 관리를 위해 외부 서비스 제공업체에 대화 샘플을 제공하는 솔루션이 필요합니다. 외부 서비스 제공자는 가장 최근 대화까지 샘플 대화를 무작위로 선택해야 합니다. 회사는 고객 PII를 외부 서비스 제공업체와 공유해서는 안 됩니다. 고객 대화 수가 증가하면 솔루션도 확장되어야 합니다.
최소한의 운영 오버헤드로 이러한 요구 사항을 충족하는 솔루션은 무엇입니까?

- [ ] A. 객체 Lambda 액세스 포인트를 생성합니다. 함수가 파일을 읽을 때 PII를 수정하는 AWS Lambda 함수를 생성합니다. 외부 서비스 공급자에게 객체 Lambda 액세스 포인트에 액세스하도록 지시합니다.
- [ ] B. 모든 새 파일을 정기적으로 읽고, 파일에서 PII를 수정하고, 수정된 파일을 다른 S3 버킷에 쓰는 Amazon EC2 인스턴스에 배치 프로세스를 만듭니다. PII가 포함되지 않은 버킷에 액세스하도록 외부 서비스 제공자에게 지시합니다.
- [ ] C. 파일 목록을 표시하고, 파일에서 PII를 수정하고, 외부 서비스 공급자가 PII가 수정된 파일의 새 버전을 다운로드할 수 있도록 하는 웹 애플리케이션을 Amazon EC2 인스턴스에 생성합니다.
- [ ] D. Amazon DynamoDB 테이블을 생성합니다. PII가 포함되지 않은 파일의 데이터만 읽는 AWS Lambda 함수를 생성합니다. 새 파일이 Amazon S3에 기록될 때 DynamoDB 테이블에 PII가 아닌 데이터를 저장하도록 Lambda 함수를 구성합니다. 외부 서비스 공급자에게 DynamoDB 테이블에 대한 액세스 권한을 부여합니다.

## Answer

정답: A

## Explanation

S3 Object Lambda Access Point를 사용하면 S3에서 객체를 읽을 때 Lambda 함수가 자동으로 호출되어 PII를 실시간으로 수정(redact)한 후 반환합니다. 원본 데이터를 변경하지 않으면서 외부 서비스 제공자에게는 PII가 제거된 데이터만 제공하므로 최신 대화 샘플까지 즉시 접근 가능합니다. 별도의 데이터 복사본이나 배치 처리 없이 읽기 시점에 변환이 수행되어 운영 효율적입니다.

오답 분석

B: EC2 배치 프로세스로 PII를 수정하고 별도 S3 버킷에 쓰는 방식은 데이터 복제에 따른 스토리지 비용 증가와 배치 지연이 발생합니다. 새 파일이 추가될 때까지 기다려야 하므로 '가장 최근 대화까지' 접근 요구사항에 불리합니다.

C: EC2 웹 애플리케이션으로 파일 목록을 표시하고 다운로드하게 하는 것은 인프라 관리 부담이 크고, PII 수정을 위한 커스텀 로직 개발과 EC2 인스턴스 운영이 필요합니다.

D: DynamoDB 테이블에 PII를 제외한 데이터만 저장하는 것은 원본 파일의 구조를 변경해야 하며, Lambda 트리거 기반 ETL 파이프라인 구축이 필요하여 복잡도가 높습니다.
