## Question

한 회사가 분석 및 장기 보관을 위해 대량의 데이터를 객체로 저장하려고 합니다. AWS 외부 리소스가 데이터에 액세스해야 합니다. 외부 리소스는 예측할 수 없는 빈도로 데이터에 액세스해야 합니다. 하지만 외부 리소스는 필요할 때 즉시 액세스할 수 있어야 합니다. 이 회사는 높은 내구성과 데이터 보안을 제공하는 비용 최적화된 솔루션이 필요합니다.
어떤 솔루션이 이러한 요구 사항을 충족할까요?

- [ ] A. Amazon S3 Standard에 데이터를 저장합니다. S3 수명 주기 정책을 적용하여 이전 데이터를 S3 Glacier Deep Archive로 이전합니다.
- [ ] B. Amazon S3 Intelligent-Tiering에 데이터를 저장합니다.
- [ ] C. Amazon S3 Glacier Flexible Retrieval에 데이터를 저장합니다. 신속 검색 기능을 사용하여 필요할 때 즉시 액세스할 수 있도록 합니다.
- [ ] D. Amazon Elastic File System(Amazon EFS) Infrequent Access(IA)에 데이터를 저장합니다. 수명 주기 정책을 사용하여 이전 파일을 보관합니다.

## Answer

정답: B

## Explanation

S3 Intelligent-Tiering은 접근 패턴이 예측 불가능한 데이터에 최적화된 스토리지 클래스입니다. 자동으로 자주 접근하는 데이터와 드물게 접근하는 데이터를 적절한 티어로 이동시키며, 즉각적인 접근이 필요할 때 항상 가능합니다. 높은 내구성을 제공하고 외부 리소스에서도 접근 가능합니다.

오답 분석

A: S3 Standard에서 Glacier Deep Archive로 전환하면 데이터 검색에 12시간 이상 걸려 즉각적인 접근 요구사항을 충족하지 못합니다.

C: S3 Glacier Flexible Retrieval의 긴급 검색(Expedited)도 1-5분이 걸리며, 데이터 저장 초기부터 Glacier에 저장하면 분석 용도로 즉각적인 접근이 불가능합니다.

D: Amazon EFS Infrequent Access는 AWS 외부 리소스에서 직접 접근하기 어렵고, 객체 스토리지가 아닌 파일 스토리지이므로 장기 보관 및 분석용으로 적합하지 않습니다.
