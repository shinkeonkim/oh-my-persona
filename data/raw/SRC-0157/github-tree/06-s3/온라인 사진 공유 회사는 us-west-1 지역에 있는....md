## Question

온라인 사진 공유 회사는 us-west-1 지역에 있는 Amazon S3 버킷에 사진을 저장합니다. 회사는 us-east-1 지역에 모든 새 사진의 사본을 저장해야 합니다.
최소한의 운영 노력으로 이 요구 사항을 충족할 수 있는 솔루션은 무엇입니까?

- [ ] A. us-east-1에 두 번째 S3 버킷을 생성합니다. S3 교차 리전 복제를 사용하여 기존 S3 버킷의 사진을 두 번째 S3 버킷으로 복사합니다.
- [ ] B. 기존 S3 버킷의 CORS(교차 원본 리소스 공유) 구성을 생성합니다. CORS 규칙의 AllowedOrigin 요소에 us-east-1을 지정합니다.
- [ ] C. 여러 가용 영역에 걸쳐 us-east-1에 두 번째 S3 버킷을 생성합니다. S3 수명 주기 규칙을 생성하여 두 번째 S3 버킷에 사진을 저장합니다.
- [ ] D. us-east-1에 두 번째 S3 버킷을 생성합니다. 객체 생성 및 업데이트 이벤트에 대한 S3 이벤트 알림을 구성하여 AWS Lambda 함수를 호출하여 기존 S3 버킷의 사진을 두 번째 S3 버킷으로 복사합니다.

## Answer

정답: A

## Explanation

S3 교차 리전 복제(Cross-Region Replication, CRR)를 사용하면 us-west-1의 소스 S3 버킷에서 us-east-1의 대상 S3 버킷으로 새로 업로드되는 사진을 자동으로 복제합니다. CRR은 한 번 복제 규칙을 구성하면 이후 업로드되는 모든 새 객체에 대해 자동으로 작동하므로 운영 노력이 최소화됩니다. 소스와 대상 버킷 모두에 버전 관리(Versioning)가 활성화되어야 하며, 복제 지연은 대부분 15분 이내입니다.

오답 분석

B: CORS(Cross-Origin Resource Sharing) 구성은 웹 브라우저의 교차 출처 HTTP 요청을 허용하기 위한 설정이며, S3 버킷 간 데이터를 복사하거나 복제하는 기능이 전혀 아닙니다.

C: S3 수명 주기 규칙은 객체의 스토리지 클래스 전환이나 만료 삭제를 자동화하는 기능이며, 다른 리전의 S3 버킷에 파일을 복사하거나 저장하는 기능을 제공하지 않습니다.

D: S3 이벤트 알림과 Lambda 함수를 사용하여 교차 리전 복사를 구현하는 것은 기술적으로 가능하지만, Lambda 함수 코드 개발, 오류 처리, IAM 역할 설정 등 CRR보다 훨씬 많은 운영 노력이 필요합니다.
