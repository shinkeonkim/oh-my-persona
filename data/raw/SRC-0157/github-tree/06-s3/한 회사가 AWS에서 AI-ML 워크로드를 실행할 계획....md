## Question

한 회사가 AWS에서 AI/ML 워크로드를 실행할 계획입니다. 이 회사는 Amazon S3 Standard에 있는 데이터 세트에서 모델을 학습해야 합니다. 모델 학습 애플리케이션은 여러 개의 컴퓨팅 노드와 한 자릿수 밀리초 단위의 데이터 액세스가 필요합니다.
가장 비용 효율적인 방식으로 이러한 요구 사항을 충족하는 솔루션은 무엇입니까?

- [ ] A. 데이터를 S3 Intelligent-Tiering으로 이동합니다. 모델 학습 애플리케이션이 S3 Intelligent-Tiering을 데이터 소스로 지정합니다.
- [ ] B. 임의의 접두사를 추가하여 S3 버킷에 파티션을 추가합니다. 모델 학습 애플리케이션이 새로운 접두사를 데이터 소스로 지정하도록 재구성합니다.
- [ ] C. 데이터를 S3 Express One Zone으로 이동합니다. 모델 학습 애플리케이션이 S3 Express One Zone을 데이터 소스로 지정합니다.
- [ ] D. Amazon EC2 인스턴스에 연결된 범용 SSD(gp3) Amazon Elastic Block Store(Amazon EBS) 볼륨으로 데이터를 이동합니다. 모델 학습 애플리케이션이 gp3 볼륨을 데이터 소스로 지정합니다.

## Answer

정답: C

## Explanation

S3 Express One Zone은 단일 자릿수 밀리초의 데이터 접근 지연 시간을 제공하며, AI/ML 모델 학습과 같은 고성능 워크로드에 최적화되어 있습니다. 여러 컴퓨팅 노드에서 동시에 접근할 수 있으며, S3 Standard보다 빠른 접근 속도를 비용 효율적으로 제공합니다.

오답 분석

A: S3 Intelligent-Tiering은 비용 최적화에는 도움이 되지만, 단일 자릿수 밀리초 접근 시간을 보장하지 않으며 S3 Standard와 동일한 지연 시간을 제공합니다.

B: S3 버킷에 접두사로 파티션을 추가하는 것은 처리량을 개선할 수 있지만, 단일 자릿수 밀리초 접근 시간 요구사항을 충족하지 못합니다.

D: EBS gp3 볼륨은 단일 EC2 인스턴스에만 연결 가능하므로 여러 컴퓨팅 노드에서 공유 접근이 불가능하며, 비용 효율적이지 않습니다.
