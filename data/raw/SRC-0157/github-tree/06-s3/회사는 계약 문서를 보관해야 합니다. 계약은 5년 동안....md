## Question

회사는 계약 문서를 보관해야 합니다. 계약은 5년 동안 지속됩니다. 회사는 5년 동안 문서를 덮어쓰거나 삭제할 수 없도록 해야 합니다. 회사는 미사용 문서를 암호화하고 매년 암호화 키를 자동으로 교체해야 합니다.
최소한의 운영 오버헤드로 이러한 요구 사항을 충족하기 위해 솔루션 설계자가 수행해야 하는 단계 조합은 무엇입니까? (두 가지를 선택하세요.)

- [ ] A. Amazon S3에 문서를 저장합니다. 거버넌스 모드에서 S3 객체 잠금을 사용합니다.
- [ ] B. Amazon S3에 문서를 저장합니다. 규정 준수 모드에서 S3 객체 잠금을 사용합니다.
- [ ] C. Amazon S3 관리형 암호화 키(SSE-S3)로 서버 측 암호화를 사용합니다. 키 순환을 구성합니다.
- [ ] D. AWS Key Management Service(AWS KMS) 고객 관리형 키로 서버 측 암호화를 사용합니다. 키 순환을 구성합니다.
- [ ] E. AWS Key Management Service(AWS KMS) 고객 제공(가져온) 키로 서버 측 암호화를 사용합니다. 키 순환을 구성합니다.

## Answer

정답: B, D

## Explanation

B와 D가 정답입니다. S3 Object Lock의 규정 준수(Compliance) 모드를 사용하면 5년 동안 루트 사용자를 포함한 누구도 문서를 덮어쓰거나 삭제할 수 없습니다. AWS KMS 고객 관리형 키로 서버 측 암호화를 사용하면 미사용 데이터가 암호화되고, KMS가 매년 자동으로 키를 교체합니다. 이 조합이 최소 운영 오버헤드로 요구 사항을 충족합니다.

오답 분석

A: 거버넌스(Governance) 모드는 특정 권한이 있는 사용자가 보존을 우회할 수 있어 '덮어쓰거나 삭제할 수 없다'는 요구 사항을 완전히 충족하지 못합니다.

C: SSE-S3는 Amazon이 키를 관리하며, 사용자가 키 교체 주기를 직접 제어할 수 없습니다. 또한 매년 자동 키 교체를 명시적으로 구성할 수 없습니다.

E: KMS 고객 제공(가져온) 키는 자동 키 교체를 지원하지 않으므로, 매년 수동으로 키를 교체해야 하여 운영 오버헤드가 증가합니다.
