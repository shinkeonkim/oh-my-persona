## Question

회사에 새로운 모바일 앱이 있습니다. 세계 어디에서나 사용자는 자신이 선택한 주제에 대한 지역 뉴스를 볼 수 있습니다. 사용자는 앱 내부에서 사진과 비디오를 게시할 수도 있습니다.
사용자는 콘텐츠가 게시된 후 처음 몇 분 안에 콘텐츠에 액세스하는 경우가 많습니다. 새로운 콘텐츠가 이전 콘텐츠를 빠르게 대체한 다음 이전 콘텐츠는 사라집니다. 뉴스의 지역적 특성은 사용자가 뉴스가 업로드되는 AWS 지역 내에서 콘텐츠의 90%를 소비한다는 것을 의미합니다.
콘텐츠 업로드에 가장 짧은 지연 시간을 제공하여 사용자 경험을 최적화하는 솔루션은 무엇입니까?

- [ ] A. Amazon S3에 콘텐츠를 업로드하고 저장합니다. 업로드에는 Amazon CloudFront를 사용합니다.
- [ ] B. Amazon S3에 콘텐츠를 업로드하고 저장합니다. 업로드에는 S3 Transfer Acceleration을 사용합니다.
- [ ] C. 사용자에게 가장 가까운 지역의 Amazon EC2 인스턴스에 콘텐츠를 업로드합니다. 데이터를 Amazon S3에 복사합니다.
- [ ] D. 사용자에게 가장 가까운 지역의 Amazon S3에 콘텐츠를 업로드하고 저장합니다. Amazon CloudFront의 여러 배포판을 사용합니다.

## Answer

정답: B

## Explanation

S3 Transfer Acceleration은 AWS 엣지 로케이션을 활용하여 전 세계 어디에서든 S3 업로드 속도를 크게 향상시킵니다. 사용자의 90%가 업로드 리전 내에서 콘텐츠를 소비하므로 동일 리전의 S3에 데이터가 저장되면 대부분의 읽기 요청이 빠르게 처리됩니다. 업로드 지연 시간 최소화가 핵심 요구 사항이므로 Transfer Acceleration이 가장 적합합니다.

오답 분석

A: CloudFront는 다운로드(콘텐츠 배포)에 최적화되어 있으며, 업로드에는 Transfer Acceleration이 더 효과적입니다.

C: EC2 인스턴스로 먼저 업로드 후 S3에 복사하는 것은 불필요한 중간 단계가 추가되어 지연 시간이 증가하고 운영 복잡성이 높아집니다.

D: 가장 가까운 리전의 S3에 직접 업로드하고 여러 CloudFront 배포를 사용하는 것은 여러 S3 버킷과 배포판 관리가 필요하여 복잡하며, Transfer Acceleration이 더 간단한 솔루션입니다.
