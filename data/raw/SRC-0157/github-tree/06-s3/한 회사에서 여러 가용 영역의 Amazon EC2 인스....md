## Question

한 회사에서 여러 가용 영역의 Amazon EC2 인스턴스에서 실행되는 웹 기반 애플리케이션을 구축하고 있습니다. 웹 애플리케이션은 총 약 900TB 크기의 텍스트 문서 저장소에 대한 액세스를 제공합니다. 회사는 웹 애플리케이션이 높은 수요 기간을 경험할 것으로 예상합니다. 솔루션 설계자는 텍스트 문서의 저장소 구성 요소가 항상 응용 프로그램의 요구 사항을 충족하도록 확장할 수 있는지 확인해야 합니다. 회사는 솔루션의 전체 비용에 대해 우려하고 있습니다.
이러한 요구 사항을 가장 비용 효율적으로 충족하는 스토리지 솔루션은 무엇입니까?

- [ ] A. Amazon Elastic Block Store(Amazon EBS)
- [ ] B. Amazon Elastic File System(Amazon EFS)
- [ ] C. Amazon OpenSearch Service(Amazon Elasticsearch Service)
- [ ] D. Amazon S3

## Answer

정답: D

## Explanation

Amazon S3는 사실상 무제한의 스토리지 용량을 제공하며, 900TB 규모의 텍스트 문서를 저장하는 데 가장 비용 효율적인 서비스입니다. S3는 자동으로 확장되어 높은 수요 기간에도 애플리케이션 요구 사항을 충족할 수 있으며, 여러 AZ에 걸쳐 데이터를 자동 복제하여 99.999999999%(11 9's)의 내구성을 보장합니다. S3 Standard의 GB당 스토리지 비용은 약 $0.023으로 EBS($0.10/GB)나 EFS($0.30/GB)보다 현저히 저렴합니다.

오답 분석

A: Amazon EBS는 단일 EC2 인스턴스에 연결되는 블록 스토리지로, 여러 AZ의 인스턴스에서 동시 액세스가 불가능하며 볼륨 최대 크기가 64TB로 900TB를 저장하려면 여러 볼륨이 필요합니다. GB당 비용도 S3보다 4배 이상 높습니다.

B: Amazon EFS는 여러 인스턴스에서 공유 가능한 파일 시스템이지만, GB당 스토리지 비용이 S3 Standard의 약 13배($0.30/GB)로 900TB 규모에서 비용이 매우 높습니다.

C: Amazon OpenSearch Service는 검색 및 분석 엔진으로, 대규모 텍스트 문서의 기본 스토리지로 사용하기에는 과도한 컴퓨팅 비용이 발생하며 설계 목적에 부합하지 않습니다.
