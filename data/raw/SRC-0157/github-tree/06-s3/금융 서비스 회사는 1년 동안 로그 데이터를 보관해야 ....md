## Question

금융 서비스 회사는 1년 동안 로그 데이터를 보관해야 합니다. 이 회사는 Amazon S3 버킷에 로그 파일을 저장하고 이 기간 동안 사용자가 로그 파일을 삭제하거나 덮어쓰지 못하도록 하려고 합니다. 데이터는 읽기 전용 요청에서만 사용할 수 있어야 합니다.

- [ ] A. 버킷에서 S3 버전 관리를 활성화합니다. 규정 준수 모드에서 1년 보관 기간의 객체 잠금을 사용합니다.
- [ ] B. 버킷에서 S3 Transfer Acceleration을 활성화합니다. 1년 후 객체를 Amazon S3 Glacier Flexible Retrieval로 이동하는 S3 수명 주기 구성 규칙을 생성합니다.
- [ ] C. 버킷에서 S3 버전 관리를 활성화합니다. 1년 후 객체를 Amazon S3 Glacier Flexible Retrieval로 이동하는 S3 수명 주기 구성 규칙을 생성합니다.
- [ ] D. S3 데이터의 타임스탬프를 프로그래밍 방식으로 확인하고, 데이터가 1년 이상 경과한 경우 Amazon S3 Glacier Deep Archive로 이동하는 AWS Lambda 함수를 생성합니다.

## Answer

정답: A

## Explanation

S3 Versioning을 활성화하고 Object Lock을 Compliance 모드로 설정하면 1년 보존 기간 동안 루트 사용자를 포함한 어떤 사용자도 객체를 삭제하거나 덮어쓸 수 없습니다. Compliance 모드는 보존 기간이 만료될 때까지 보호가 해제될 수 없어 가장 강력한 보호를 제공합니다.

오답 분석

B: S3 Transfer Acceleration은 전송 속도를 높이는 기능이며 데이터 보호와 관련이 없습니다. S3 Glacier로 이동하면 즉각적인 읽기 접근이 불가능합니다.

C: S3 Versioning과 Lifecycle 정책만으로는 사용자가 객체를 삭제하는 것을 방지할 수 없습니다. Object Lock이 필요합니다.

D: Lambda 함수로 타임스탬프를 확인하는 것은 삭제 방지 메커니즘이 아니며, 사용자가 데이터를 삭제하는 것을 막을 수 없습니다.
