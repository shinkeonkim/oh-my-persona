## Question

한 회사에서 Amazon S3 버킷에 파일을 업로드하는 새로운 애플리케이션을 설계하고 있습니다. 업로드된 파일은 메타데이터를 추출하기 위해 처리됩니다. 처리는 5초 이내에 완료되어야 합니다. 업로드의 양과 빈도는 시간당 몇 개의 파일에서 수백 개의 동시 업로드까지 다양합니다.
어떤 솔루션이 이러한 요구 사항을 가장 비용 효율적으로 충족할까요?

- [ ] A. Amazon S3 API 호출을 기록하도록 AWS CloudTrail 트레일을 구성합니다. AWS AppSync를 사용하여 파일을 처리합니다.
- [ ] B. 버킷 내에서 새 객체 생성 S3 이벤트 알림을 구성하여 AWS Lambda 함수를 호출하여 파일을 처리합니다.
- [ ] C. Amazon Kinesis Data Streams를 구성하여 파일을 S3 버킷에 전달합니다. AWS Lambda 함수를 호출하여 파일을 처리합니다.
- [ ] D. Amazon EC2 인스턴스를 배포합니다. S3 버킷의 모든 파일을 나열하고 새 파일을 처리하는 스크립트를 만듭니다. 매분 실행되는 cron 작업을 사용하여 스크립트를 실행합니다.

## Answer

정답: B

## Explanation

S3 이벤트 알림을 통해 새 객체 생성 시 AWS Lambda 함수를 자동으로 호출하는 것이 가장 비용 효율적입니다. Lambda는 서버리스로 사용한 만큼만 비용이 발생하며, 트래픽이 적을 때는 비용이 거의 없고, 동시 업로드가 많을 때는 자동으로 스케일링됩니다. 5초 이내 처리 요구사항도 충족합니다.

오답 분석

A: AWS CloudTrail은 API 호출 로깅 서비스이며, AWS AppSync는 GraphQL API 서비스로 파일 처리 용도에 적합하지 않습니다.

C: Amazon Kinesis Data Streams는 실시간 스트리밍 데이터 처리에 적합하지만, S3 파일 업로드 이벤트 처리를 위해 사용하려면 샤드 프로비저닝 및 관리가 필요하여 불필요한 인프라와 비용이 추가됩니다.

D: EC2 인스턴스를 배포하고 1분마다 cron 작업으로 폴링하는 것은 항상 실행 비용이 발생하며, 이벤트 기반이 아니므로 비용 효율적이지 않습니다.
