## Question

솔루션 아키텍트가 AWS 보안 계정에서 타사 네트워크 방화벽을 통해 트래픽을 전송하는 데이터 보고 애플리케이션을 만들고 있습니다. 방화벽과 애플리케이션 서버는 부하 분산되어야 합니다. 이 애플리케이션은 TCP 연결을 사용하여 보고서를 생성합니다. 보고서는 몇 시간 동안 실행될 수 있으며 최대 1시간 동안 유휴 상태가 될 수 있습니다. 유휴 기간 동안 보고서는 시간 초과되어서는 안 됩니다.
다음 요구 사항을 충족하는 솔루션은 무엇입니까?

- [ ] A. 방화벽에는 게이트웨이 로드 밸런서(GWLB)를 사용합니다. 애플리케이션 서버에는 애플리케이션 로드 밸런서(ALB)를 사용합니다. ALB 유휴 시간 초과 기간을 1시간으로 설정합니다.
- [ ] B. 보안 계정에서 단일 방화벽을 사용합니다. 애플리케이션 서버에는 애플리케이션 로드 밸런서(ALB)를 사용합니다. ALB 유휴 시간 초과 및 방화벽 유휴 시간 초과 기간을 1시간으로 설정합니다.
- [ ] C. 방화벽에는 게이트웨이 로드 밸런서(GWLB)를 사용합니다. 애플리케이션 서버에는 애플리케이션 로드 밸런서(ALB)를 사용합니다. ALB, GWLB 및 방화벽의 유휴 시간 초과 기간을 1시간으로 설정합니다.
- [ ] D. 방화벽에는 게이트웨이 로드 밸런서(GWLB)를 사용합니다. 애플리케이션 서버에는 애플리케이션 로드 밸런서(ALB)를 사용합니다. ALB 유휴 시간 초과를 1시간으로 설정합니다. 보고서 생성을 더 빨리 완료하기 위해 애플리케이션 서버 용량을 늘립니다.

## Answer

정답: C

## Explanation

Gateway Load Balancer(GWLB)로 방화벽을 로드 밸런싱하고, ALB로 애플리케이션 서버를 로드 밸런싱하되, ALB, GWLB, 방화벽 모두의 유휴 타임아웃을 1시간으로 설정해야 합니다. 전체 경로에서 가장 짧은 타임아웃이 연결을 끊을 수 있으므로 모든 구성 요소의 타임아웃을 맞춰야 합니다.

오답 분석

A: GWLB의 유휴 타임아웃과 방화벽의 유휴 타임아웃도 설정해야 합니다. ALB 타임아웃만 설정하면 다른 구성 요소에서 연결이 끊길 수 있습니다.

B: 단일 방화벽은 고가용성을 제공하지 않으며, GWLB가 방화벽을 로드 밸런싱하는 것이 적절합니다.

D: 애플리케이션 서버 용량을 늘려 보고서 생성을 빠르게 하는 것은 유휴 기간 동안의 타임아웃 문제를 해결하지 않으며, 보고서가 최대 1시간 유휴 상태일 수 있다는 요구사항에 대응하지 못합니다.
