## Question

온라인 비디오 게임 회사는 게임 서버에 대해 매우 낮은 대기 시간을 유지해야 합니다. 게임 서버는 Amazon EC2 인스턴스에서 실행됩니다. 회사에는 초당 수백만 건의 UDP 인터넷 트래픽 요청을 처리할 수 있는 솔루션이 필요합니다.
이러한 요구 사항을 가장 비용 효율적으로 충족하는 솔루션은 무엇입니까?

- [ ] A. 인터넷 트래픽에 필요한 프로토콜과 포트로 Application Load Balancer를 구성합니다. EC2 인스턴스를 대상으로 지정합니다.
- [ ] B. 인터넷 트래픽을 위한 게이트웨이 로드 밸런서를 구성합니다. EC2 인스턴스를 대상으로 지정합니다.
- [ ] C. 인터넷 트래픽에 필요한 프로토콜과 포트로 Network Load Balancer를 구성합니다. EC2 인스턴스를 대상으로 지정합니다.
- [ ] D. 별도의 AWS 지역에 있는 EC2 인스턴스에서 동일한 게임 서버 세트를 시작합니다. 인터넷 트래픽을 두 EC2 인스턴스 세트로 라우팅합니다.

## Answer

정답: C

## Explanation

Network Load Balancer(NLB)는 OSI 모델 4계층(전송 계층)에서 작동하며, TCP, UDP, TCP_UDP, TLS 프로토콜을 지원합니다. NLB는 초당 수백만 건의 요청을 초저지연으로 처리할 수 있도록 설계되었으며, 트래픽 변화에 따라 자동으로 확장됩니다. UDP 트래픽의 경우, NLB는 흐름 해시 알고리즘(프로토콜, 소스 IP, 소스 포트, 대상 IP, 대상 포트)을 사용하여 단일 대상으로 일관되게 라우팅하므로, 게임 세션의 안정적인 연결을 유지합니다. NLB는 가용 영역당 하나의 정적 IP 주소 또는 Elastic IP를 제공하여 DNS 기반 접근이 용이합니다.

오답 분석

A: Application Load Balancer(ALB)는 OSI 모델 7계층(애플리케이션 계층)에서 작동하며, HTTP와 HTTPS 프로토콜만 지원합니다. UDP 프로토콜을 처리할 수 없으므로 온라인 게임 서버의 UDP 트래픽 부하 분산에 사용할 수 없습니다. ALB는 경로 기반, 호스트 기반, 쿼리 문자열 기반 라우팅 등 HTTP 요청 수준의 라우팅에 특화되어 있습니다.

B: Gateway Load Balancer(GWLB)는 OSI 모델 3계층(네트워크 계층)에서 작동하며, 방화벽, IDS/IPS, 심층 패킷 검사(DPI) 등 보안 가상 어플라이언스를 투명하게 배포하기 위한 로드 밸런서입니다. GENEVE 프로토콜(포트 6081)을 사용하여 트래픽을 가상 어플라이언스로 전달하며, 일반적인 게임 서버의 UDP 부하 분산 용도로는 설계되지 않았습니다.

D: 별도 AWS 리전에 동일한 게임 서버를 배포하면 인프라 비용이 2배로 증가하며, 리전 간 트래픽 라우팅 구성(Route 53, Global Accelerator 등)이 추가로 필요합니다. 단일 리전에서 NLB를 사용하면 자동 확장과 초저지연을 제공하므로 훨씬 비용 효율적이고 간단한 솔루션입니다.
