## Question

한 회사가 최근 고객을 위해 새로운 애플리케이션을 출시했습니다. 이 애플리케이션은 두 개의 가용 영역에 걸쳐 여러 Amazon EC2 인스턴스에서 실행됩니다. 최종 사용자는 TCP를 사용하여 애플리케이션과 통신합니다. 애플리케이션은 고가용성이어야 하며 사용자 수가 증가함에 따라 자동으로 확장되어야 합니다.
이러한 요구 사항을 가장 비용 효율적으로 충족할 단계 조합은 무엇입니까? (두 가지를 선택하세요.)

- [ ] A. EC2 인스턴스 앞에 네트워크 로드 밸런서를 추가합니다.
- [ ] B. EC2 인스턴스에 대한 Auto Scaling 그룹을 구성합니다.
- [ ] C. EC2 인스턴스 앞에 애플리케이션 로드 밸런서를 추가합니다.
- [ ] D. 애플리케이션에 대한 EC2 인스턴스를 수동으로 추가합니다.
- [ ] E. EC2 인스턴스 앞에 게이트웨이 로드 밸런서를 추가합니다.

## Answer

정답: A, B

## Explanation

A(Network Load Balancer)는 TCP/UDP 트래픽을 Layer 4에서 처리하며 초고성능과 초저지연을 제공합니다. TCP 통신을 사용하는 애플리케이션에 가장 적합합니다. B(Auto Scaling 그룹)를 구성하면 사용자 수 증가에 따라 EC2 인스턴스를 자동으로 확장/축소하여 고가용성과 비용 효율성을 동시에 달성합니다.

오답 분석

C: Application Load Balancer는 HTTP/HTTPS(Layer 7) 트래픽에 최적화되어 있으므로, 순수 TCP 프로토콜을 사용하는 애플리케이션에는 NLB가 더 적합하고 비용 효율적입니다.

D: EC2 인스턴스를 수동으로 추가하는 것은 자동 확장이 아니므로 사용자 증가에 실시간 대응이 불가능하며, 수동 운영 오버헤드가 높습니다.

E: Gateway Load Balancer(GWLB)는 서드파티 네트워크 어플라이언스(방화벽, IDS/IPS, 패킷 검사 장치)를 투명하게 배포하기 위한 것으로, 일반 애플리케이션 트래픽 분산에는 사용하지 않습니다.
