## Question

한 회사가 등록된 상위 도메인으로 여러 사업 부문의 여러 웹사이트를 호스팅하고 있습니다. 이러한 웹사이트에 접속하는 사용자는 하위 도메인을 기반으로 적절한 백엔드 Amazon EC2 인스턴스로 라우팅됩니다. 웹사이트는 정적 웹페이지, 이미지, 그리고 PHP 및 JavaScript와 같은 서버 측 스크립트를 호스팅합니다. 일부 웹사이트는 영업 시작 후 처음 두 시간 동안 접속량이 가장 많고, 나머지 시간 동안은 지속적으로 접속됩니다. 솔루션 아키텍트는 비용을 절감하면서 이러한 트래픽 패턴에 맞춰 용량을 자동으로 조절하는 솔루션을 설계해야 합니다.
다음 요구 사항을 충족하는 AWS 서비스 또는 기능의 조합은 무엇입니까? (두 가지를 선택하세요.)

- [ ] A. AWS Batch
- [ ] B. Network Load Balancer
- [ ] C. Application Load Balancer
- [ ] D. Amazon EC2 Auto Scaling
- [ ] E. Amazon S3 웹사이트 호스팅

## Answer

정답: C, D

## Explanation

Application Load Balancer(ALB)는 호스트 기반 라우팅(Host-based Routing)을 지원하여 하위 도메인별로 트래픽을 적절한 백엔드 EC2 인스턴스로 라우팅할 수 있습니다. Amazon EC2 Auto Scaling은 트래픽 패턴에 따라 인스턴스 수를 자동으로 조정하여 피크 시간에는 확장하고 비활동 시간에는 축소하여 비용을 절감합니다.

오답 분석

A: AWS Batch는 배치 컴퓨팅 작업용 서비스로, 실시간 웹 트래픽 라우팅에는 적합하지 않습니다.

B: Network Load Balancer는 TCP/UDP 레이어(L4)에서 작동하여 호스트 기반 라우팅을 지원하지 않으며, 하위 도메인별 라우팅이 불가능합니다.

E: Amazon S3 웹사이트 호스팅은 정적 콘텐츠만 제공하며, PHP 같은 서버 측 스크립트를 실행할 수 없습니다.
