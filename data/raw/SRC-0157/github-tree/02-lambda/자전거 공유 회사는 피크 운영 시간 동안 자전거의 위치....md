## Question

자전거 공유 회사는 피크 운영 시간 동안 자전거의 위치를 추적하기 위해 다계층 아키텍처를 개발하고 있습니다. 회사는 기존 분석 플랫폼에서 이러한 데이터 포인트를 사용하려고 합니다. 솔루션 설계자는 이 아키텍처를 지원하기 위해 가장 실행 가능한 다중 계층 옵션을 결정해야 합니다. 데이터 포인트는 REST API에서 액세스할 수 있어야 합니다.
위치 데이터 저장 및 검색에 대한 이러한 요구 사항을 충족하는 작업은 무엇입니까?

- [ ] A. Amazon S3와 함께 Amazon Athena를 사용합니다.
- [ ] B. AWS Lambda와 함께 Amazon API Gateway를 사용합니다.
- [ ] C. Amazon Redshift와 함께 Amazon QuickSight를 사용합니다.
- [ ] D. Amazon Kinesis Data Analytics와 함께 Amazon API Gateway를 사용합니다.

## Answer

정답: B

## Explanation

Amazon API Gateway와 AWS Lambda 조합은 REST API를 통한 위치 데이터 저장 및 검색에 가장 적합한 다계층 솔루션입니다. API Gateway는 RESTful HTTPS 엔드포인트를 제공하고, Lambda는 서버리스로 피크 시간 트래픽에 자동 확장되어 수백만 요청을 처리할 수 있습니다. Lambda는 서버 관리가 불필요하며 pay-per-request 과금으로 비용 효율적이고, 기존 분석 플랫폼과의 통합도 용이합니다. 데이터 저장소(DynamoDB 등)와 연계하여 완전한 다계층 아키텍처를 구성할 수 있습니다.

오답 분석

A: Amazon Athena + S3는 S3에 저장된 데이터에 대한 애드혹 SQL 쿼리 분석 도구입니다. REST API 엔드포인트를 제공하지 않으며, 실시간 데이터 저장/검색 서비스가 아닙니다.

C: Amazon QuickSight + Redshift는 비즈니스 인텔리전스(BI) 대시보드와 데이터 웨어하우스 조합으로, REST API 기반 데이터 서비스 구축과는 목적이 다릅니다. QuickSight는 시각화 도구이며 API 제공 기능이 없습니다.

D: Amazon Kinesis Data Analytics는 실시간 스트리밍 데이터 분석용 서비스입니다. 데이터의 저장과 검색(store and retrieve) 용도가 아니며, REST API를 통한 데이터 접근 요구사항을 충족하지 못합니다.
