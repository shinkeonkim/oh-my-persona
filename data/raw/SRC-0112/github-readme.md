# Freeze Plugin

### 1. 간단한 요약

운영자가 `/freeze <닉네임>` 명령어로 특정 플레이어를 그 자리에 묶어두는(동결시키는) Paper 플러그인입니다. 어뷰징 의심 등 문제 상황 발생 시, 강퇴나 밴 전에 대상을 붙잡아두고 상황을 파악할 시간을 벌기 위한 모더레이션 도구입니다.

### 2. 설명

- `/freeze <닉네임>` 한 개의 명령어로 동결 상태를 **토글**합니다. 이미 동결된 플레이어를 대상으로 다시 실행하면 동결이 해제됩니다. (별도의 `/unfreeze` 명령어는 없습니다.)
- 동결된 플레이어 목록은 `FreezePlugin` 내부의 `MutableSet<UUID>` (`frozen`)로 메모리에서만 관리되며, 서버가 재시작되면 초기화됩니다(별도 영속 저장소 없음).
- 동결 중인 플레이어는 다음 행동이 막힙니다.
  - **이동**: `PlayerMoveEvent`를 가로채 좌표(x, y, z)를 원래 위치로 되돌립니다. 단, 시야 회전(yaw/pitch)은 그대로 반영되어 카메라를 돌려보는 것은 허용됩니다.
  - **블록 파괴**: `BlockBreakEvent`를 취소하고 "동결 중에는 블록을 부술 수 없습니다." 메시지를 안내합니다.
  - **블록 설치**: `BlockPlaceEvent`를 취소하고 "동결 중에는 블록을 설치할 수 없습니다." 메시지를 안내합니다.
  - 채팅이나 다른 명령어 사용은 별도로 막지 않습니다(기획 문서에는 검토 항목으로 언급되어 있으나 현재 구현에는 없습니다).
- 모든 이벤트 핸들러(`FreezeGuardListener`)는 대상이 `frozen` 집합에 있는지 먼저 확인하는 가드 패턴으로 동작하며, **플레이어만을 대상으로 합니다.** 몬스터 등 다른 엔티티는 이 플러그인의 영향을 받지 않습니다.
- 다른 플러그인에 대한 의존관계는 없습니다.

### 3. 사용 방법 (매뉴얼)

**명령어**

| 명령어 | 설명 |
| --- | --- |
| `/freeze <닉네임>` | 대상 플레이어의 동결 상태를 토글합니다(동결 ↔ 해제). 대상은 현재 접속 중인 플레이어여야 합니다. |

- 인자를 주지 않으면 `사용법: /freeze <닉네임>` 안내 메시지가 출력됩니다.
- 존재하지 않거나 접속 중이 아닌 닉네임을 입력하면 `접속 중인 플레이어가 아닙니다: <입력값>` 메시지가 출력됩니다.
- 명령어 실행 시 현재 접속 중인 플레이어 이름으로 자동완성(tab completion)을 지원합니다.

**권한 노드**

| 권한 | 기본값 | 설명 |
| --- | --- | --- |
| `freeze.use` | OP (운영자) | `/freeze` 명령어 실행 권한. 이 권한이 없으면 명령어를 사용할 수 없습니다. |

**config.yml**

이 플러그인은 별도의 `config.yml` 설정 파일을 사용하지 않습니다.

**빌드 방법**

저장소 루트에서 다음 명령어를 실행합니다.

```bash
./scripts/build-plugin.sh minecraft-freeze-plugin
```
