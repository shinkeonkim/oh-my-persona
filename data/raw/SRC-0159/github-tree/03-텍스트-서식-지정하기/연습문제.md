# 3장 연습문제 구현

[← 3장 결과물로](결과물.md) · [← 본문으로](텍스트-서식-지정하기.md#연습문제)

본문의 연습문제 5개를 모두 구현했습니다. `lab3.py` 는 그대로 두고, 1~2장 연습문제를
이어받아 그 위에 3장 기능을 얹은 `Layout` 과 `Browser` 를 `ex3.py` 에 정의했습니다.

## 실행

```bash
python3 ex3.py https://browser.engineering/
```

2장에서 만든 스크롤·창 크기 조절·스크롤바와 1장의 `data:`/`view-source:`/`about:blank`
가 그대로 살아 있습니다.

## 검증

```bash
python3 test_ex3.py
```

폰트 메트릭이 필요해 숨긴 Tk 루트를 하나 띄우고 28개 테스트로 배치 결과를 확인합니다.

## 구현 내용

| 문제 | 제목 | 구현 위치 | 요점 |
|---|---|---|---|
| 3-1 | 가운데 정렬 | `flush`, `line_width` | `<h1 class="title">` 안에서만. 줄을 마감할 때 그 줄의 실제 너비로 offset 을 구해 줄마다 따로 밉니다 |
| 3-2 | 위 첨자 | `font`, `flush` | 글자를 절반 크기로. `y = baseline - max_ascent` 로 두어 윗선을 보통 글자의 윗선에 맞춥니다 |
| 3-3 | 소프트 하이픈 | `hyphenate` | 들어갈 수 있는 가장 긴 앞부분을 찾아 `-` 를 붙여 남기고, 나머지는 다음 줄에서 다시 시도합니다 |
| 3-4 | 스몰 캡 | `smallcaps_word` | 한 낱말을 소문자/그 외 구간으로 쪼개 각각 다른 폰트로 놓습니다. 소문자는 대문자로 바꿔 작게·굵게 |
| 3-5 | 서식 텍스트 | `pre_text`, `font` | `<pre>` 안에서는 공백을 안 뭉개고 줄바꿈에서 줄을 끝냅니다. 고정폭 글꼴을 쓰되 굵게/기울임은 그대로 동작 |

## 설계 메모

**`lex` 가 공백을 보존합니다.** 3-5 때문에 원문 텍스트를 그대로 담아 두고, 공백을
버릴지 말지는 `Layout` 이 `<pre>` 안인지 보고 정합니다.

**한 낱말이 여러 조각이 될 수 있습니다.** 3-4 의 스몰 캡은 `aBc` 를 세 조각으로
쪼개 서로 다른 폰트로 그립니다. 그래서 `place()` 에 조각 사이 공백을 넣을지
고르는 인자를 두었습니다. 3-3 의 하이픈도 같은 장치를 씁니다.

**3-3 은 되돌아가지 않습니다.** 들어갈 수 있는 가장 긴 조각을 앞에서부터 찾고,
어디서도 못 끊으면 그냥 줄을 넘겨 통째로 놓습니다. 본문이 말한 대로 한 낱말에
소프트 하이픈이 여러 개 있어도 동작합니다.

**위 첨자는 크기만 줄이지 않습니다.** 크기만 줄이면 기준선에 붙어 아래로 처집니다.
`flush()` 에서 그 줄의 `max_ascent` 를 알아야 윗선을 맞출 수 있어서, 조각마다
위 첨자인지를 줄 버퍼에 함께 담아 둡니다.
