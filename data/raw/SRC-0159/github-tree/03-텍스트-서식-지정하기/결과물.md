# 3장 결과물 — 텍스트 서식 지정하기

[← 본문으로 돌아가기](텍스트-서식-지정하기.md)

3장까지 따라 만들면 완성되는 브라우저입니다. 1장부터 이 장까지의 코드가 모두 들어 있어 `code/` 폴더에서 바로 실행할 수 있습니다.

## 이 시점의 브라우저가 할 수 있는 일

- 단어 단위로 줄을 바꾼다
- `<b>`, `<i>`, `<big>`, `<small>` 로 굵기·기울임·크기를 바꾼다
- 크기가 다른 글자를 베이스라인에 맞춰 정렬한다
- 폰트를 캐시해 텍스트 측정을 빠르게 한다

## 실행

```bash
cd code
python3 lab3.py https://browser.engineering/
```

## 필요한 것

- tkinter (파이썬 표준. 배포판에 따라 `python3-tk` 설치가 필요할 수 있습니다)

## 이 장에서 새로 추가된 것

`lab3.py` 는 이 장에서 새로 생기거나 바뀐 코드만 담고, 나머지는 이전 장 파일에서 import 합니다.

- 새 클래스: `Text`, `Tag`, `Layout`, `Browser`
- 기존 클래스 확장: `Browser`
- 새 함수: `lex`, `get_font`
