# 4장 결과물 — HTML 트리 구성하기

[← 본문으로 돌아가기](HTML-트리-구성하기.md)

4장까지 따라 만들면 완성되는 브라우저입니다. 1장부터 이 장까지의 코드가 모두 들어 있어 `code/` 폴더에서 바로 실행할 수 있습니다.

## 이 시점의 브라우저가 할 수 있는 일

- HTML 을 토큰이 아니라 트리로 파싱한다
- 태그 속성을 읽고 자체 닫힘 태그를 처리한다
- `<html>`, `<head>`, `<body>` 같은 빠진 태그를 자동으로 채운다

## 실행

```bash
cd code
python3 lab4.py https://browser.engineering/
```

## 필요한 것

- tkinter (파이썬 표준. 배포판에 따라 `python3-tk` 설치가 필요할 수 있습니다)

## 이 장에서 새로 추가된 것

`lab4.py` 는 이 장에서 새로 생기거나 바뀐 코드만 담고, 나머지는 이전 장 파일에서 import 합니다.

- 새 클래스: `Text`, `Element`, `HTMLParser`, `Layout`, `Browser`
- 기존 클래스 확장: `Browser`, `Layout`
- 새 함수: `print_tree`
