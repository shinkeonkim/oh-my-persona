# 1장 연습문제 구현

[← 1장 결과물로](결과물.md) · [← 본문으로](웹페이지-다운로드하기.md#연습문제)

본문의 연습문제 9개를 모두 구현했습니다. `lab1.py` 는 그대로 두고, 그 위에 기능을
얹은 `URL` 과 `show` 를 `ex1.py` 에 새로 정의했습니다. 다음 장의 연습문제 파일은
이 모듈을 import 해 이어서 발전시킵니다.

## 실행

```bash
python3 ex1.py https://browser.engineering/
python3 ex1.py view-source:https://example.org/
python3 ex1.py file:///etc/hosts
python3 ex1.py 'data:text/html,<b>Hello</b> &lt;world&gt;'
```

## 검증

```bash
python3 test_ex1.py
```

네트워크 없이 돌도록 응답을 마음대로 정할 수 있는 작은 HTTP 서버를 띄워
16개 테스트로 확인합니다.

## 구현 내용

| 문제 | 제목 | 구현 위치 | 요점 |
|---|---|---|---|
| 1-1 | HTTP/1.1 | `_request_bytes` | 헤더를 딕셔너리로 모아 두어 나중에 추가하기 쉽게 했습니다. `Connection`, `User-Agent` 전송 |
| 1-2 | 파일 URL | `__init__`, `request` | `file://` 스킴. 호스트 없이 경로만 |
| 1-3 | `data` | `__init__`, `request` | `data:<mediatype>,<data>` 를 쪼개 본문으로 |
| 1-4 | 엔티티 | `decode_entities`, `lex` | `&lt;` `&gt;` `&amp;` `&quot;` `&#39;` |
| 1-5 | `view-source` | `__init__`, `show` | 다른 URL 을 감싸고, 렌더링 대신 소스를 출력 |
| 1-6 | Keep-alive | `_connect`, `_finish`, `_read_body` | `(스킴,호스트,포트)` 별 소켓 재사용. `Content-Length` 만큼만 읽고, `Connection: close` 면 버림 |
| 1-7 | 리다이렉트 | `_redirect` | 3xx 의 `Location` 추적. 절대·호스트상대·경로상대 URL 모두 처리하고 10회로 제한 |
| 1-8 | 캐싱 | `_cache_read`, `_cache_write` | `GET` + `200` 만 저장. `no-store` 는 저장 안 함, `max-age` 는 만료 시각 계산, 모르는 지시어가 있으면 저장 안 함 |
| 1-9 | 압축 | `_read_body`, `_read_chunked` | `Accept-Encoding: gzip` 전송, `gzip` 해제, `chunked` 전송 해제 (둘이 겹쳐도 동작) |

## 알아 둘 점

**캐시와 keep-alive 는 서로를 가립니다.** 캐시가 동작하면 요청이 아예 나가지 않아
소켓 재사용을 확인할 수 없습니다. `test_ex1.py` 의 keep-alive 테스트가 응답에
`Cache-Control: no-store` 를 붙이는 이유입니다.

**`Cache-Control` 에 모르는 지시어가 있으면 캐시하지 않습니다.** 본문이 권하는 대로
`no-store` 와 `max-age` 만 이해하고, `private` 처럼 해석할 수 없는 값이 오면
안전한 쪽(저장 안 함)을 택했습니다.

**기본 요청이 `Connection: keep-alive` 입니다.** 연습문제 1-1 은 `close` 를
보내라고 하지만 1-6 에서 keep-alive 로 바꾸라고 하므로, 최종 상태인 keep-alive 를
따랐습니다.
