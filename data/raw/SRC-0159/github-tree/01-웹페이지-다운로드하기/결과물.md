# 1장 결과물 — 웹페이지 다운로드하기

[← 본문으로 돌아가기](웹페이지-다운로드하기.md)

1장까지 따라 만들면 완성되는 브라우저입니다. 1장부터 이 장까지의 코드가 모두 들어 있어 `code/` 폴더에서 바로 실행할 수 있습니다.

## 이 시점의 브라우저가 할 수 있는 일

- URL 을 스킴·호스트·포트·경로로 분해한다
- 소켓과 TLS 로 서버에 접속해 HTTP 요청을 보낸다
- 응답을 상태 줄·헤더·본문으로 나누고 태그를 뺀 텍스트를 출력한다

## 실행

```bash
cd code
python3 lab1.py https://example.org/
```

## 필요한 것

- 파이썬 표준 라이브러리만 있으면 됩니다.

## 이 장에서 새로 추가된 것

`lab1.py` 는 이 장에서 새로 생기거나 바뀐 코드만 담고, 나머지는 이전 장 파일에서 import 합니다.

- 새 클래스: `URL`
- 새 함수: `show`, `load`
