# 14장 연습문제 구현

[← 14장 결과물로](결과물.md) · [← 본문으로](콘텐츠-접근성-만들기.md#연습문제)

본문의 연습문제 11개를 모두 구현했습니다. `lab14.py`·`browser14.css`·`runtime14.js`
는 그대로 두고, 1~13장 연습문제를 이어받아 그 위에 14장 기능을 얹은 것을
`ex14.py`·`ex14_sdl.py`·`runtime14ex.js` 에 두었습니다.

14장 본문 기능(확대, 다크 모드, 포커스 링, `tabindex`, 접근성 트리, 낭독,
마우스 호버 강조)도 함께 들어 있습니다.

## 실행

```bash
python3 server10ex.py               # 다른 터미널에서
python3 ex14_sdl.py http://localhost:8000/
```

| 키 | 하는 일 |
|---|---|
| `Ctrl` + `+` / `-` / `0` | 확대 / 축소 / 되돌리기 |
| `Ctrl` + `D` | 다크 모드 |
| `Ctrl` + `H` | 고대비 모드 (14-7) |
| `Ctrl` + `A` | 문서를 한 노드씩 읽기 (14-3) |
| `Tab` | 다음 포커스 대상 |

## 검증

```bash
python3 test_ex14.py
```

79개 테스트로 확인합니다. 말하기는 `RecordingSpeaker` 로 갈아 끼워 소리 없이
확인합니다.

## 구현 내용

| 문제 | 제목 | 구현 위치 | 요점 |
|---|---|---|---|
| 14-1 | 대비가 좋은 포커스 링 | `paint_outline` | 흰 굵은 선 바깥, 검은 얇은 선 안쪽 |
| 14-2 | `focus` 메서드와 이벤트 | `JSContext.focus`, `dispatch_focus_event` | 9-5 의 버블링을 그대로 씁니다 |
| 14-3 | 읽는 동안 요소 강조하기 | `advance_accessibility`, `reading_highlight` | 한 노드씩 옮기며 읽고 칠합니다 |
| 14-4 | 너비 미디어 쿼리 | `media_matches`, `Tab.media` | 확대하면 CSS 픽셀 너비가 줄어듭니다 |
| 14-5 | 혼합 인라인 | `focus_rects` | 줄별로 묶어 사각형 여러 개 |
| 14-6 | 스레드화된 접근성 | `AccessibilityThread` | 말하기가 브라우저 스레드를 막지 않습니다 |
| 14-7 | 고대비 모드 | `force_colors`, `FORCED_COLORS` | 색을 몇 개로 눌러 덮습니다 |
| 14-8 | `focus-visible` | `focus_visible`, `Tab.click` | 탭이면 보이고 클릭이면 감춥니다 |
| 14-9 | OS 통합 | `MacSaySpeaker` | macOS 의 `say` 를 그대로 |
| 14-10 | `zoom` CSS 속성 | `parse_zoom`, `effective_zoom` | 조상들의 zoom 을 곱합니다 |
| 14-11 | 소리 내어 말하기 | `PyttsxSpeaker`, `default_speaker` | 쓸 수 있는 뒷단 중 가장 나은 것 |

## 설계 메모

**말하기 뒷단을 갈아 끼울 수 있게 했습니다.** `Speaker` 하나의 얼굴 뒤에
`MacSaySpeaker`(14-9), `PyttsxSpeaker`(14-11), `PrintSpeaker`(아무것도 없을 때),
`RecordingSpeaker`(시험용)가 있습니다. 덕분에 테스트가 소리를 내지 않고도 무엇을
말했는지 그대로 확인합니다. `default_speaker()` 가 이 환경에서 쓸 수 있는 것 중
가장 나은 것을 고릅니다 — macOS 에서는 OS 의 음성 합성기입니다.

**14-4 는 확대와 한 몸입니다.** 확대하면 장치 픽셀은 그대로인데 **CSS 픽셀**
너비가 줄어듭니다. 그래서 `Tab.media()` 가 `WIDTH / zoom` 을 너비로 보고합니다.
미디어 쿼리 결과가 바뀌면 규칙 자체가 달라지므로, 스타일시트 원문을 들고 있다가
`rebuild_rules()` 로 다시 읽습니다.
`test_zooming_in_can_trigger_the_query` 가 확대만으로 규칙이 켜지는 것을 봅니다.

**14-5 는 인라인에 상자가 없다는 데서 옵니다.** 블록 요소는 자기 상자가 있지만
`<a>` 같은 인라인은 없습니다. 그래서 그 자손 글자 상자들을 찾아 **같은 줄끼리**
묶고, 묶음마다 사각형을 하나씩 만듭니다. 링크가 두 줄에 걸치면 링도 두 개입니다.

**14-8 은 포커스와 "포커스 표시"를 나눕니다.** 클릭으로 얻은 포커스도 포커스는
포커스입니다 — 키 입력은 거기로 갑니다. 다만 사용자가 자기 손으로 눌렀으니 링을
보여 줄 필요가 없습니다. `is_focused` 와 `focus_visible` 두 값을 따로 두고,
`:focus` 와 `:focus-visible` 이 각각을 봅니다.

**14-6 은 12장의 스레드 얼개를 재활용합니다.** `AccessibilityThread` 는 12장
`TaskRunner` 와 같은 모양(큐 + 조건 변수 + `set_needs_quit`)입니다. `speak()` 는
큐에 넣고 곧바로 돌아옵니다. `test_speak_returns_immediately` 가 이를 지킵니다.
