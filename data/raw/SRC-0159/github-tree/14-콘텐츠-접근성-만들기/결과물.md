# 14장 결과물 — 콘텐츠 접근성 만들기

[← 본문으로 돌아가기](콘텐츠-접근성-만들기.md)

14장까지 따라 만들면 완성되는 브라우저입니다. 1장부터 이 장까지의 코드가 모두 들어 있어 `code/` 폴더에서 바로 실행할 수 있습니다.

## 이 시점의 브라우저가 할 수 있는 일

- `Ctrl-+`/`Ctrl--` 로 확대하고 `Ctrl-d` 로 다크 모드를 켠다
- `Tab` 과 `Enter` 로 키보드만으로 페이지를 쓴다
- 포커스 외곽선을 그리고 `:focus` 와 `outline` 으로 꾸민다
- 접근성 트리를 만들어 내장 스크린 리더로 읽어 준다

## 실행

```bash
cd code
python3 lab14.py https://browser.engineering/
```

폼·쿠키·스크립트를 시험하려면 다른 터미널에서 웹 서버를 함께 띄우고 `http://localhost:8000/` 에 접속하세요.

```bash
python3 server12.py
```

## 필요한 것

- tkinter (파이썬 표준. 배포판에 따라 `python3-tk` 설치가 필요할 수 있습니다)
- dukpy
- skia-python
- pysdl2
- pysdl2-dll
- PyOpenGL

```bash
python3 -m pip install dukpy skia-python pysdl2 pysdl2-dll PyOpenGL
```

## 이 장에서 새로 추가된 것

`lab14.py` 는 이 장에서 새로 생기거나 바뀐 코드만 담고, 나머지는 이전 장 파일에서 import 합니다.

- 기존 클래스 확장: `BlockLayout`, `Browser`, `CSSParser`, `Chrome`, `DocumentLayout`, `Element`, `InputLayout`, `JSContext`, `LineLayout`, `Tab`, `Text`, `TextLayout`
- 새 함수: `parse_outline`, `paint_outline`, `dpx`, `get_tabindex`, `cascade_priority`, `style`, `is_focusable`, `speak_text`, `mainloop`
