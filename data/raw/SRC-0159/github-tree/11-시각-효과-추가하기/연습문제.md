# 11장 연습문제 구현

[← 11장 결과물로](결과물.md) · [← 본문으로](시각-효과-추가하기.md#연습문제)

본문의 연습문제 5개를 모두 구현했습니다. `lab11.py` 는 그대로 두고,
1~10장 연습문제를 이어받아 그 위에 11장 기능을 얹은 것을 `ex11.py`(배치·그리기)와
`ex11_sdl.py`(창과 이벤트 고리)에 두었습니다.

11장 본문 기능(`opacity`, `mix-blend-mode`, `border-radius`, `overflow: clip`)도
함께 들어 있습니다.

## 실행

```bash
python3 server10ex.py               # 다른 터미널에서
python3 ex11_sdl.py http://localhost:8000/
```

## 검증

```bash
python3 test_ex11.py
```

52개 테스트로 확인합니다. Skia 서피스에 직접 그려 보므로 SDL 창을 띄우지 않습니다.

## 구현 내용

| 문제 | 제목 | 구현 위치 | 요점 |
|---|---|---|---|
| 11-1 | 필터 | `parse_blur`, `Blend.paint` | 블러는 투명도·블렌딩보다 **안쪽**에서 |
| 11-2 | 히트 테스팅 | `inside_rounded`, `hit` | 깎여 나간 모서리는 클릭이 아닙니다 |
| 11-3 | 관심 영역 | `Tab.raster`, `Browser.needs_new_aoi` | `4 * HEIGHT` 만 들고 있습니다 |
| 11-4 | 오버플로 스크롤 | `is_scrollable`, `Translate`, `Tab.scroll_by` | 클릭으로 포커스, 방향키로 스크롤 |
| 11-5 | 터치 입력 | `handle_finger_*`, `handle_multi_gesture` | 탭은 클릭, 두 손가락은 스크롤 |

## 설계 메모

**바탕만 갈아 끼웠습니다.** 11장은 Tk 를 Skia + SDL 로 바꾸는 장인데, 그렇다고
3~10장에서 만든 배치 기능을 다시 쓸 이유는 없습니다. `install_backend()` 가
앞 장 모듈들의 `get_font` 와 그리기 명령 이름을 11장 것으로 바꿔 끼웁니다.
배치 코드는 이 이름들을 자기 모듈 전역에서 찾으므로, 한 곳만 바꾸면 소프트
하이픈도 스몰 캡도 익명 상자도 그대로 Skia 위에서 돕니다.

`Font` 클래스가 `measure()` 와 `metrics()` 를 Tk 폰트와 같은 모양으로 내주는 것이
이 방식의 핵심입니다. 배치 코드는 자기가 무엇 위에서 도는지 모릅니다.

**11-1 의 순서가 중요합니다.** 본문이 "블러가 언제 일어나는지 신중히 생각해
보라"고 하는 이유입니다. 블러는 자식들을 흐리게 만든 **결과**에 투명도와 블렌드
모드가 걸리는 순서여야 합니다. 그래서 같은 `saveLayer` 의 `Paint` 안에서
`ImageFilter` 로 넣습니다. 반대로 하면 흐려진 가장자리가 잘리거나 알파가 두 번
곱해집니다. `test_blur_is_inside_opacity` 가 이 순서를 지킵니다.

**11-2 는 그리기와 히트 테스팅이 어긋나는 문제입니다.** 화면에는 둥근 사각형을
그려 놓고 클릭 판정은 직사각형으로 하니 어긋납니다. `inside_rounded()` 가 네
모서리 구역만 따로 보고 중심에서의 거리를 잽니다. 반지름이 상자보다 크면
절반으로 깎아 씁니다.

**11-3 은 "다시 그려야 하는가"가 전부입니다.** 관심 영역 안에서 스크롤하는 동안은
이미 그려 둔 서피스를 옮겨 붙이기만 합니다. 화면이 영역 밖으로 나가려 할 때만
영역을 스크롤 위치 가운데로 옮기고 다시 그립니다.

**11-4 는 스크롤을 두 곳에서 다룹니다.** 스크롤 상자 안을 클릭하면 그 요소가
포커스를 갖고, 방향키가 페이지 대신 그 상자를 움직입니다. 움직임은
`Translate` 그리기 명령으로 넣고, `overflow: scroll` 이면 `clip` 과 같은
마스크를 씌워 밖으로 새지 않게 합니다.

**11-5 의 탭과 끌기는 구분해야 합니다.** 손가락을 뗄 때 처음 자리에서 얼마나
움직였는지 보고, 거의 안 움직였으면 클릭으로 봅니다. 손가락이 둘 이상이면 탭이
아니고, 두 손가락 끌기는 스크롤입니다.
