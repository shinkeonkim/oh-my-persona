# 11장 결과물 — 시각 효과 추가하기

[← 본문으로 돌아가기](시각-효과-추가하기.md)

11장까지 따라 만들면 완성되는 브라우저입니다. 1장부터 이 장까지의 코드가 모두 들어 있어 `code/` 폴더에서 바로 실행할 수 있습니다.

## 이 시점의 브라우저가 할 수 있는 일

- Tkinter 대신 Skia + SDL 로 그린다
- 투명도와 `mix-blend-mode` 로 색을 섞는다
- 둥근 모서리로 잘라내고, 탭 내용을 별도 서피스에 그려 스크롤을 빠르게 한다

## 실행

```bash
cd code
python3 lab11.py https://browser.engineering/
```

폼·쿠키·스크립트를 시험하려면 다른 터미널에서 웹 서버를 함께 띄우고 `http://localhost:8000/` 에 접속하세요.

```bash
python3 server10.py
```

## 필요한 것

- tkinter (파이썬 표준. 배포판에 따라 `python3-tk` 설치가 필요할 수 있습니다)
- dukpy
- skia-python
- pysdl2
- pysdl2-dll

```bash
python3 -m pip install dukpy skia-python pysdl2 pysdl2-dll
```

## 이 장에서 새로 추가된 것

`lab11.py` 는 이 장에서 새로 생기거나 바뀐 코드만 담고, 나머지는 이전 장 파일에서 import 합니다.

- 새 클래스: `Blend`, `DrawRect`, `DrawText`, `DrawOutline`, `DrawLine`, `DrawRRect`, `BlockLayout`, `LineLayout`, `TextLayout`, `InputLayout`, `DocumentLayout`, `Tab`, `Chrome`, `Browser`
- 기존 클래스 확장: `BlockLayout`, `Browser`, `Chrome`, `DocumentLayout`, `DrawLine`, `DrawOutline`, `DrawRect`, `DrawText`, `InputLayout`, `LineLayout`, `Tab`, `TextLayout`
- 새 함수: `get_font`, `parse_color`, `parse_blend_mode`, `linespace`, `paint_tree`, `paint_visual_effects`, `mainloop`
- 새 파일: `examples11.py`
