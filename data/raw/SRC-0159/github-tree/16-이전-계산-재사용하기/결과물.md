# 16장 결과물 — 이전 계산 재사용하기

[← 본문으로 돌아가기](이전-계산-재사용하기.md)

16장까지 따라 만들면 완성되는 브라우저입니다. 1장부터 이 장까지의 코드가 모두 들어 있어 `code/` 폴더에서 바로 실행할 수 있습니다.

## 이 시점의 브라우저가 할 수 있는 일

- `contenteditable` 로 페이지를 직접 편집한다
- `ProtectedField` 로 필드 단위 의존성을 추적한다
- 바뀐 부분만 다시 계산하고, 필요 없는 레이아웃 순회를 통째로 건너뛴다

## 실행

```bash
cd code
python3 lab16.py https://browser.engineering/
```

폼·쿠키·스크립트를 시험하려면 다른 터미널에서 웹 서버를 함께 띄우고 `http://localhost:8000/` 에 접속하세요.

```bash
python3 server12.py
```

## 필요한 것

- tkinter (파이썬 표준. 배포판에 따라 `python3-tk` 설치가 필요할 수 있습니다)
- dukpy
- skia-python
- pysdl2
- pysdl2-dll
- PyOpenGL

```bash
python3 -m pip install dukpy skia-python pysdl2 pysdl2-dll PyOpenGL
```

## 이 장에서 새로 추가된 것

`lab16.py` 는 이 장에서 새로 생기거나 바뀐 코드만 담고, 나머지는 이전 장 파일에서 import 합니다.

- 기존 클래스 확장: `AccessibilityNode`, `BlockLayout`, `DocumentLayout`, `Element`, `EmbedLayout`, `Frame`, `IframeLayout`, `ImageLayout`, `InputLayout`, `JSContext`, `LineLayout`, `Tab`, `Text`, `TextLayout`, `absolute_bounds_for_obj`, `font`, `is_focusable`, `paint_outline`, `paint_visual_effects`, `print_tree`, `style`, `tree_to_list`
- 새 함수: `is_focusable`, `print_tree`, `tree_to_list`, `paint_outline`, `font`, `absolute_bounds_for_obj`, `paint_visual_effects`, `DrawCursor`, `init_style`, `style`, `dirty_style`, `paint_tree`
