# 5장 결과물 — 페이지 배치하기

[← 본문으로 돌아가기](페이지-배치하기.md)

5장까지 따라 만들면 완성되는 브라우저입니다. 1장부터 이 장까지의 코드가 모두 들어 있어 `code/` 폴더에서 바로 실행할 수 있습니다.

## 이 시점의 브라우저가 할 수 있는 일

- 요소마다 레이아웃 객체를 만들어 레이아웃 트리를 세운다
- 블록 모드와 인라인 모드를 구분해 배치한다
- 크기와 위치를 계산하고 디스플레이 리스트로 그린다
- `<pre>` 에 배경을 칠한다

## 실행

```bash
cd code
python3 lab5.py https://browser.engineering/
```

## 필요한 것

- tkinter (파이썬 표준. 배포판에 따라 `python3-tk` 설치가 필요할 수 있습니다)

## 이 장에서 새로 추가된 것

`lab5.py` 는 이 장에서 새로 생기거나 바뀐 코드만 담고, 나머지는 이전 장 파일에서 import 합니다.

- 새 클래스: `BlockLayout`, `DocumentLayout`, `DrawText`, `DrawRect`, `Browser`
- 기존 클래스 확장: `Browser`, `Layout`
- 새 함수: `paint_tree`
