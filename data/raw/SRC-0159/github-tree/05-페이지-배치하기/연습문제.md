# 5장 연습문제 구현

[← 5장 결과물로](결과물.md) · [← 본문으로](페이지-배치하기.md#연습문제)

본문의 연습문제 6개를 모두 구현했습니다. `lab5.py` 는 그대로 두고, 1~4장 연습문제를
이어받아 그 위에 5장 기능을 얹은 `BlockLayout` 과 `DocumentLayout` 을 `ex5.py` 에
정의했습니다.

3~4장의 글자 배치 기능(가운데 정렬·위 첨자·소프트 하이픈·스몰 캡·`<pre>`)은
`BlockLayout` 안으로 옮겨 그대로 살아 있습니다.

## 실행

```bash
python3 ex5.py https://browser.engineering/
```

## 검증

```bash
python3 test_ex5.py
```

35개 테스트로 확인합니다. 마지막 묶음은 1~4장 연습문제가 여전히 도는지 보는
회귀 테스트입니다.

## 구현 내용

| 문제 | 제목 | 구현 위치 | 요점 |
|---|---|---|---|
| 5-1 | 링크 바 | `paint` | `<nav class="links">` 에 옅은 회색 배경을 글자보다 먼저 그립니다 |
| 5-2 | 숨겨진 head | `is_skipped`, `group_children` | `<head>`(와 `<script>`/`<style>`)를 레이아웃 트리에 넣지 않습니다. HTML 트리에는 그대로 남습니다 |
| 5-3 | 글머리 기호 | `list_indent`, `paint` | `<li>` 를 들여쓰고 비워진 왼쪽 자리에 작은 검은 사각형을 그립니다 |
| 5-4 | 목차 | `toc_label_height`, `content_top`, `paint` | `<nav id="toc">` 위에 한 줄을 비워 두고 회색 배경과 제목을 그립니다 |
| 5-5 | 익명 블록 박스 | `group_children`, `BlockLayout.nodes` | 이어지는 글자 같은 형제들을 하나의 익명 상자로 묶습니다 |
| 5-6 | 런인 제목 | `group_children`, `open_tag` | `<h6>` 이 자기 상자를 만들지 않고 다음 묶음의 첫머리로 들어갑니다 |

## 설계 메모

**`BlockLayout` 이 노드 하나가 아니라 형제 목록을 받습니다.** 5-5 도 5-6 도 결국
"어떤 형제들을 한 상자에 담을까" 의 문제입니다. 그래서 그 판단을 `group_children`
한 곳에 모으고, `BlockLayout` 은 받은 목록을 순서대로 훑기만 합니다. 덕분에 두
연습문제가 서로 얽히지 않고, `<head>` 건너뛰기(5-2)도 같은 자리에서 처리됩니다.

**5-6 은 줄을 끝내지 않는 제목입니다.** `<h6>` 을 열 때 굵게 바꾸고 닫을 때 되돌릴
뿐, `flush()` 를 부르지 않습니다. 그래서 뒤따르는 문단 글자가 같은 줄에 이어집니다.

**5-4 는 자리를 실제로 차지해야 합니다.** 제목을 그리기만 하면 목록과 겹칩니다.
`content_top()` 을 두어 자식이 시작할 y 를 제목 높이만큼 밀고, 부모의 높이에도
그만큼 더합니다. `DocumentLayout` 에도 같은 메서드를 두어 첫 자식이 같은 방식으로
자리를 잡습니다.

**회귀 테스트가 실제로 버그를 잡았습니다.** 처음엔 제목 높이를 계산만 하고 자식
위치에 반영하지 않아 목록이 제목 위에 겹쳐 그려졌습니다.
`test_label_does_not_overlap_list` 가 이를 잡아 `content_top()` 도입으로 이어졌습니다.
