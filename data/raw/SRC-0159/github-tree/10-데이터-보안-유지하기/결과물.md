# 10장 결과물 — 데이터 보안 유지하기

[← 본문으로 돌아가기](데이터-보안-유지하기.md)

10장까지 따라 만들면 완성되는 브라우저입니다. 1장부터 이 장까지의 코드가 모두 들어 있어 `code/` 폴더에서 바로 실행할 수 있습니다.

## 이 시점의 브라우저가 할 수 있는 일

- 쿠키를 저장하고 보내 로그인 상태를 유지한다
- `XMLHttpRequest` 를 지원하고 동일 출처 정책을 적용한다
- 논스와 `SameSite` 쿠키로 CSRF 를, 이스케이프와 CSP 로 XSS 를 막는다

## 실행

```bash
cd code
python3 lab10.py https://browser.engineering/
```

폼·쿠키·스크립트를 시험하려면 다른 터미널에서 웹 서버를 함께 띄우고 `http://localhost:8000/` 에 접속하세요.

```bash
python3 server10.py
```

## 필요한 것

- tkinter (파이썬 표준. 배포판에 따라 `python3-tk` 설치가 필요할 수 있습니다)
- dukpy

```bash
python3 -m pip install dukpy
```
