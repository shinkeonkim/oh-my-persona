# 10장 연습문제 구현

[← 10장 결과물로](결과물.md) · [← 본문으로](데이터-보안-유지하기.md#연습문제)

본문의 연습문제 6개를 모두 구현했습니다. `lab10.py`·`server10.py`·`runtime10.js`
는 그대로 두고, 1~9장 연습문제를 이어받아 그 위에 10장 기능을 얹은 것을
`ex10.py`·`server10ex.py`·`runtime10ex.js` 에 두었습니다.

10장 본문 기능(쿠키, `SameSite`, 동일 출처 정책, `XMLHttpRequest`, CSP,
CSRF 논스)도 함께 들어 있습니다.

## 실행

```bash
python3 server10ex.py         # 다른 터미널에서
python3 ex10.py http://localhost:8000/
```

로그인 계정은 `crashoverride` / `0cool` 입니다.

## 검증

```bash
python3 test_ex10.py
```

61개 테스트로 확인합니다. 네트워크는 쓰지 않습니다.

## 구현 내용

| 문제 | 제목 | 구현 위치 | 요점 |
|---|---|---|---|
| 10-1 | 새로운 입력 | `InputLayout`, `display_value` | `hidden` 은 폭·높이 0, `password` 는 별표 |
| 10-2 | 인증서 오류 | `CertificateError`, `Tab.load`, `HTMLChrome` | 잡아서 경고 페이지로, 안전하면 자물쇠 |
| 10-3 | 스크립트 접근 | `cookie_get`/`cookie_set` | `HttpOnly` 는 스크립트에만 숨깁니다 |
| 10-4 | 쿠키 만료 | `cookie_expiry`, `live_cookies`, `expire_sessions` | 브라우저와 서버 양쪽에서 |
| 10-5 | CORS | `XMLHttpRequest_send`, `/cors` | 보내되, 허락이 없으면 결과를 버립니다 |
| 10-6 | `Referer` | `URL.referrer_value` | 정책 세 가지를 지킵니다 |

## 설계 메모

**10-1 의 `hidden` 은 "안 그린다"로는 부족합니다.** 자리를 차지하면 줄 높이가
달라집니다. 그래서 폭도 높이도 0 이고 `ascent()` 도 0 입니다. 다만 폼을 낼 때는
보통 입력란과 똑같이 값이 실려 갑니다 — 서버의 CSRF 논스가 바로 이 방식으로
옵니다.

**`password` 는 보이는 값과 실린 값이 다릅니다.** 화면에는 `display_value()` 가
만든 별표가 나가고, 폼에는 `attributes["value"]` 원본이 실립니다. 둘을 섞으면
암호가 별표로 전송됩니다.

**10-3 의 `HttpOnly` 는 "누가 묻느냐"의 문제입니다.** 같은 쿠키 저장고에서
서버로 갈 때는 포함하고 스크립트가 읽을 때만 뺍니다. 그래서
`cookie_header(..., script_visible=True)` 한 자리에서 갈라집니다.
`test_httponly_is_still_sent_to_the_server` 가 이 구분을 지킵니다.

**10-4 는 `Max-Age` 가 `Expires` 를 이깁니다.** 명세가 그렇습니다. 만료된 쿠키는
보내지 않는 데서 그치지 않고 저장고에서 지웁니다. 서버 쪽도 마찬가지로,
세션을 만들거나 찾을 때마다 `expire_sessions()` 가 지난 것을 치웁니다. 안 그러면
`SESSIONS` 가 끝없이 자랍니다.

**10-5 는 "보내고 나서 버린다"입니다.** 요청 자체는 나갑니다(쿠키까지 함께).
브라우저가 하는 일은 응답의 `Access-Control-Allow-Origin` 을 보고 허락이 없으면
**결과를 스크립트에 넘기지 않는** 것입니다. 그래서 교차 출처 요청은
`top_level=False` 로 보내 `SameSite=Lax` 쿠키가 딸려 가지 않게 합니다.

**10-6 의 `no-referrer-when-downgrade` 가 기본값입니다.** HTTPS 페이지에서 HTTP
주소로 갈 때만 숨깁니다. 도청자가 볼 수 있는 자리로 주소를 흘리지 않기 위해서입니다.
