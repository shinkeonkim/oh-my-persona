## 최종 브라우저 — `app/`

책 전체를 따라 만든 브라우저를, 장 구분 없이 **하나의 파이썬 패키지**로 다시 쓴 것이 [`app/`](app/) 에 있습니다. 1~16장 본문 기능과 연습문제 134개의 구현이 모두 들어 있고, 433개 테스트로 검증합니다.

```bash
uv sync
uv run wbe          # 서버와 브라우저를 한 번에
uv run wbe test     # 433개 테스트
```

`code/` 가 장과 장 사이의 **차이**를 보여 준다면, `app/` 은 다 만들어진 **결과**를 보여 줍니다. 상속 사슬이나 이름 바꿔 끼우기 없이 `net/` · `dom/` · `css/` · `layout/` · `paint/` · `js/` 로 나뉘어 있습니다. 자세한 것은 [`app/README.md`](app/README.md) 에 있습니다.

## 장별 코드

책을 따라 만든 브라우저 전체가 [`code/`](code/) 한 폴더에 있습니다.

```bash
cd code
python3 lab5.py https://browser.engineering/     # 5장 시점의 브라우저
python3 lab13.py https://browser.engineering/    # 13장 시점의 브라우저
```

`labN.py` 가 **N장까지 따라 만들면 완성되는 브라우저**입니다. 그 장에서 새로 생기거나 바뀐 코드만 담고 나머지는 이전 장 파일에서 import 하므로, 장과 장 사이에 무엇이 달라졌는지 파일 하나로 바로 확인할 수 있습니다. 각 장 폴더의 `결과물.md` 에 그 시점 브라우저의 기능, 실행법, 새로 추가된 클래스·함수를 정리해 두었습니다.

필요한 외부 패키지는 장이 올라가면서 늘어납니다. 1장은 표준 라이브러리만으로 되고, 2장부터 `tkinter`, 9장부터 `dukpy`, 11장부터 `skia-python`·`pysdl2`, 13장부터 `PyOpenGL` 이 더 필요합니다. 저장소 루트에서 `uv sync` 로 한 번에 갖춰집니다.

> `labN.py` 와 에셋은 원저자들이 [MIT 라이선스로 공개한 소스](https://github.com/browserengineering/book)를 그대로 가져온 것입니다. 라이선스 전문은 `code/LICENSE` 에 있습니다.

## 연습문제 구현

각 장 본문 끝의 연습문제 **134개를 모두 구현**했습니다. [`code/exercises/`](code/exercises/) 안에 있습니다.

```bash
cd code/exercises
python3 test_ex6.py          # 6장까지의 연습문제 검증
python3 ex6.py https://browser.engineering/
```

`labN.py` 는 손대지 않고 `exN.py` 를 따로 두었습니다. 책 본문이 "연습문제를 풀지 않았다고 가정한다"고 밝히고 있어, 연습문제를 반영하면 이후 장의 코드 조각과 어긋나기 때문입니다. 대신 `exN.py` 는 `ex(N-1).py` 를 이어받아 **1장부터의 모든 연습문제가 누적된 채로** 발전합니다.
