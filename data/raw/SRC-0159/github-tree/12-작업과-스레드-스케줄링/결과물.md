# 12장 결과물 — 작업과 스레드 스케줄링

[← 본문으로 돌아가기](작업과-스레드-스케줄링.md)

12장까지 따라 만들면 완성되는 브라우저입니다. 1장부터 이 장까지의 코드가 모두 들어 있어 `code/` 폴더에서 바로 실행할 수 있습니다.

## 이 시점의 브라우저가 할 수 있는 일

- 작업 큐로 할 일을 나눠 실행한다
- `setTimeout` 과 비동기 `XMLHttpRequest` 를 지원한다
- `requestAnimationFrame` 으로 33ms 박자에 맞춰 렌더링한다
- 브라우저 스레드와 메인 스레드를 분리하고 스크롤을 브라우저 스레드에서 처리한다

## 실행

```bash
cd code
python3 lab12.py https://browser.engineering/
```

폼·쿠키·스크립트를 시험하려면 다른 터미널에서 웹 서버를 함께 띄우고 `http://localhost:8000/` 에 접속하세요.

```bash
python3 server12.py
```

## 필요한 것

- tkinter (파이썬 표준. 배포판에 따라 `python3-tk` 설치가 필요할 수 있습니다)
- dukpy
- skia-python
- pysdl2
- pysdl2-dll

```bash
python3 -m pip install dukpy skia-python pysdl2 pysdl2-dll
```
