# 13장 연습문제 구현

[← 13장 결과물로](결과물.md) · [← 본문으로](애니메이션과-합성.md#연습문제)

본문의 연습문제 12개를 모두 구현했습니다. `lab13.py`·`runtime13.js` 는 그대로 두고,
1~12장 연습문제를 이어받아 그 위에 13장 기능을 얹은 것을 `ex13.py`(합성·애니메이션),
`ex13_sdl.py`(창), `runtime13ex.js` 에 두었습니다.

13장 본문 기능(`transition`, `NumericAnimation`, `transform`, 페인트 청크,
`CompositedLayer`, 합성·래스터·그리기 분리)도 함께 들어 있습니다.

## 실행

```bash
python3 server10ex.py               # 다른 터미널에서
python3 ex13_sdl.py http://localhost:8000/
```

## 검증

```bash
python3 test_ex13.py
```

93개 테스트로 확인합니다. SDL 창 없이 Skia 서피스에 직접 그려 봅니다.

## 설계 메모

**13-2 의 기본값이 선형이 아닙니다.** CSS 의 기본 이징은
`cubic-bezier(0.25, 0.1, 0.25, 1.0)`, 곧 `ease` 입니다. 베지에는 x 로부터 t 를
바로 구할 수 없어 이분법으로 24번 좁혀 찾습니다. 애니메이션 한 프레임에 24번
곱셈이면 충분히 쌉니다.

**13-4 가 다른 애니메이션과 다른 점은 딱 하나입니다.** `opacity` 나 `transform` 은
그리기만 다시 하면 되지만 `width`/`height` 는 상자 크기가 바뀌므로 배치를 다시
해야 합니다. 그래서 애니메이션 객체에 `needs_layout` 을 두고, 그런 애니메이션이
움직일 때마다 `tab.set_needs_layout()` 을 부릅니다.

**13-7 은 "멀다"의 뜻이 중요합니다.** 줄줄이 이어진 긴 페이지는 아무리 길어도
희소하지 않습니다. 문제가 되는 건 **사이가 텅 빈 채로** 멀리 떨어진 두 덩어리입니다.
그래서 두 상자 사이의 빈틈을 재고, 겹치거나 붙어 있으면 0 입니다.
`test_continuous_content_still_merges` 가 이 구분을 지킵니다.

**13-8 과 13-12 는 같은 이야기의 두 면입니다.** 둘 다 쓸데없는 서피스 복사를
없앱니다. 13-8 은 명령이 몇 개 안 되면 서피스를 아예 만들지 않고, 13-12 는
`Blend` 안에 합성 레이어 하나뿐이면 `saveLayer` 대신 그릴 때 알파를 바로 먹입니다.
단, 블러가 걸려 있으면 층을 떠야 하므로 그때는 예전 길로 갑니다.

**13-9 는 방향이 반대입니다.** 지금까지는 각 상자의 경계를 절대 좌표로 **올려서**
클릭 위치와 견주었습니다. 이제는 클릭 위치를 트리를 따라 **내리면서** 변환을
거꾸로 적용합니다. 변환이 중첩되어도 자연스럽게 이어지고, 11-2 의 둥근 모서리
판정도 그대로 씁니다.

**바탕 갈아 끼우기를 이어 갑니다.** `install_compositing()` 이 앞 장의
`paint_visual_effects` 와 `paint_tree` 를 13장 것으로 바꾸고, `install_js()` 가
`JSContext` 를 바꿉니다. 그래서 5~12장에서 만든 모든 기능이 그대로 살아 있는 채로
합성과 애니메이션만 더해집니다.
