# 8장 결과물 — 서버에 정보 전송하기

[← 본문으로 돌아가기](서버에-정보-전송하기.md)

8장까지 따라 만들면 완성되는 브라우저입니다. 1장부터 이 장까지의 코드가 모두 들어 있어 `code/` 폴더에서 바로 실행할 수 있습니다.

## 이 시점의 브라우저가 할 수 있는 일

- `<input>` 과 `<button>` 을 그리고 클릭·입력을 받는다
- 폼을 HTTP `POST` 로 제출한다
- 동봉된 간단한 웹 서버(방명록)와 주고받는다

## 실행

```bash
cd code
python3 lab8.py https://browser.engineering/
```

폼·쿠키·스크립트를 시험하려면 다른 터미널에서 웹 서버를 함께 띄우고 `http://localhost:8000/` 에 접속하세요.

```bash
python3 server8.py
```

## 필요한 것

- tkinter (파이썬 표준. 배포판에 따라 `python3-tk` 설치가 필요할 수 있습니다)

## 이 장에서 새로 추가된 것

`lab8.py` 는 이 장에서 새로 생기거나 바뀐 코드만 담고, 나머지는 이전 장 파일에서 import 합니다.

- 새 클래스: `Element`, `Text`, `URL`, `InputLayout`, `DocumentLayout`, `LineLayout`, `TextLayout`, `BlockLayout`, `Tab`, `Chrome`, `Browser`
- 기존 클래스 확장: `BlockLayout`, `Browser`, `Chrome`, `DocumentLayout`, `Element`, `LineLayout`, `Tab`, `Text`, `TextLayout`, `URL`
- 새 함수: `paint_tree`
- 새 파일: `server8.py`
