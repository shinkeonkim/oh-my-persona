# 8장 연습문제 구현

[← 8장 결과물로](결과물.md) · [← 본문으로](서버에-정보-전송하기.md#연습문제)

본문의 연습문제 9개를 모두 구현했습니다. `lab8.py` 와 `server8.py` 는 그대로 두고,
브라우저 쪽은 `ex8.py`, 서버 쪽은 `server8ex.py` 에 따로 두었습니다.

## 실행

```bash
python3 server8ex.py          # 다른 터미널에서
python3 ex8.py http://localhost:8000/
```

## 검증

```bash
python3 test_ex8.py
```

64개 테스트로 확인합니다. 브라우저 쪽은 `data:` URL 로, 서버 쪽은 `do_request` 를
직접 불러 확인하므로 네트워크가 필요 없습니다.

## 구현 내용

| 문제 | 제목 | 구현 위치 | 요점 |
|---|---|---|---|
| 8-1 | Enter 키 | `Tab.enter` | 포커스된 입력란이 속한 폼을 냅니다 |
| 8-2 | `GET` 폼 | `URL.with_query`, `Tab.submit_form` | 본문 없이 물음표 뒤에 붙여 보냅니다 |
| 8-3 | 블러 | `Tab.blur`, `Browser.handle_click` | 포커스를 옮기기 전에 반드시 풉니다 |
| 8-4 | 체크박스 | `InputLayout`, `Tab.form_pairs` | 체크된 것만, `value` 가 없으면 `on` |
| 8-5 | 요청 재전송 | `HistoryEntry`, `Tab.go_back` | 목적지가 `POST` 였으면 물어봅니다 |
| 8-6 | 게시판 | `server8ex.Board` | 주제마다 URL 과 글 목록. 홈에서 주제를 만듭니다 |
| 8-7 | 영속성 | `Board.load`/`save` | `board.txt` 한 줄이 글 하나입니다 |
| 8-8 | 풍부한 버튼 | `ButtonLayout` | 버튼 안쪽이 제 나름의 블록 배치를 갖습니다 |
| 8-9 | HTML 크롬 | `HTMLChrome` | 크롬을 HTML+CSS 로 적고 같은 엔진으로 배치합니다 |

## 본문의 질문에 대한 답

> 다른 버튼이나 입력 영역이나 링크를 담은 버튼 같은 예외 사례들을 생각해 보세요.

**가장 안쪽 요소가 이깁니다.** 클릭한 자리의 노드에서 부모로 거슬러 올라가며
처음 만나는 상호작용 요소가 처리합니다. 그래서 버튼 안의 링크를 누르면 링크가
열리고, 버튼 안의 입력란을 누르면 입력란에 포커스가 갑니다. 실제 브라우저도
그렇습니다. `test_a_link_inside_a_button_wins` 가 이 순서를 확인합니다.

## 설계 메모

**8-9 가 8-8 을 요구했습니다.** 크롬을 HTML 로 적으려면 `<button>` 이 글자를 담을
수 있어야 하는데, 그게 바로 8-8 입니다. 두 문제를 따로 풀지 않고 `ButtonLayout`
하나로 함께 풀었습니다. 크롬도 페이지와 똑같이 파싱 → 스타일 → 배치 → 그리기를
거치고, 클릭도 똑같이 "그리기 명령 → 노드"(7-11)로 처리합니다.

**8-5 는 "어디로 가는가"를 봅니다.** 물어야 할 대상은 지금 보고 있는 페이지가 아니라
**돌아갈 페이지**입니다. `history.back()` 이 돌려주는 것이 목적지이므로 그것이
`POST` 였을 때만 묻습니다. 거절하면 `forward()` 로 방문 기록을 원래대로 되돌립니다.

**퍼센트 인코딩에 진짜 버그가 있었습니다.** `chr(byte)` 는 0x80 이상 바이트를
라틴-1 글자로 바꾸는데, 그 글자들이 파이썬에서 `isalnum()` 을 통과합니다. 그래서
한글이 인코딩되지 않고 그대로 남았다가 요청을 만들 때 다시 UTF-8 로 인코딩되어
이중 인코딩됐습니다. ASCII 범위인지 먼저 확인하도록 고쳤고,
`test_non_ascii_is_percent_encoded` 가 이를 지킵니다.

**서버가 `Connection: close` 를 보냅니다.** `server8ex.py` 는 HTTP/1.0 으로 답하고
요청마다 연결을 끊는데, 그 사실을 헤더로 알려 주지 않으면 1-6 에서 만든 소켓
재사용이 끊긴 소켓을 다시 씁니다. 첫 요청은 되고 두 번째부터 깨집니다.
