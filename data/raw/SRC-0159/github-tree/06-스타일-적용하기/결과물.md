# 6장 결과물 — 스타일 적용하기

[← 본문으로 돌아가기](스타일-적용하기.md)

6장까지 따라 만들면 완성되는 브라우저입니다. 1장부터 이 장까지의 코드가 모두 들어 있어 `code/` 폴더에서 바로 실행할 수 있습니다.

## 이 시점의 브라우저가 할 수 있는 일

- CSS 파일과 `style` 속성을 파싱한다
- 태그 선택자와 자손 선택자를 매칭한다
- 캐스케이딩과 상속을 적용한다
- 폰트와 색을 브라우저 기본 스타일시트로 옮긴다

## 실행

```bash
cd code
python3 lab6.py https://browser.engineering/
```

## 필요한 것

- tkinter (파이썬 표준. 배포판에 따라 `python3-tk` 설치가 필요할 수 있습니다)

## 이 장에서 새로 추가된 것

`lab6.py` 는 이 장에서 새로 생기거나 바뀐 코드만 담고, 나머지는 이전 장 파일에서 import 합니다.

- 새 클래스: `URL`, `CSSParser`, `TagSelector`, `DescendantSelector`, `BlockLayout`, `DrawText`, `Browser`
- 기존 클래스 확장: `BlockLayout`, `Browser`, `DrawText`, `URL`
- 새 함수: `tree_to_list`, `style`, `cascade_priority`
