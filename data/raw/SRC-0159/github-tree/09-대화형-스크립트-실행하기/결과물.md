# 9장 결과물 — 대화형 스크립트 실행하기

[← 본문으로 돌아가기](대화형-스크립트-실행하기.md)

9장까지 따라 만들면 완성되는 브라우저입니다. 1장부터 이 장까지의 코드가 모두 들어 있어 `code/` 폴더에서 바로 실행할 수 있습니다.

## 이 시점의 브라우저가 할 수 있는 일

- `<script>` 를 내려받아 JavaScript 를 실행한다
- `querySelectorAll`, `getAttribute`, `innerHTML` 로 DOM 을 읽고 고친다
- `addEventListener` 로 이벤트에 반응하고 `preventDefault` 로 기본 동작을 막는다

## 실행

```bash
cd code
python3 lab9.py https://browser.engineering/
```

폼·쿠키·스크립트를 시험하려면 다른 터미널에서 웹 서버를 함께 띄우고 `http://localhost:8000/` 에 접속하세요.

```bash
python3 server9.py
```

## 필요한 것

- tkinter (파이썬 표준. 배포판에 따라 `python3-tk` 설치가 필요할 수 있습니다)
- dukpy

```bash
python3 -m pip install dukpy
```
