# 2장 결과물 — 화면에 그리기

[← 본문으로 돌아가기](화면에-그리기.md)

2장까지 따라 만들면 완성되는 브라우저입니다. 1장부터 이 장까지의 코드가 모두 들어 있어 `code/` 폴더에서 바로 실행할 수 있습니다.

## 이 시점의 브라우저가 할 수 있는 일

- 운영체제 창을 띄우고 이벤트 루프를 돈다
- 글자를 격자로 배치해 창에 그린다
- 아래 방향키로 스크롤하고, 화면 밖 글자는 그리지 않는다

## 실행

```bash
cd code
python3 lab2.py https://browser.engineering/
```

## 필요한 것

- tkinter (파이썬 표준. 배포판에 따라 `python3-tk` 설치가 필요할 수 있습니다)

## 이 장에서 새로 추가된 것

`lab2.py` 는 이 장에서 새로 생기거나 바뀐 코드만 담고, 나머지는 이전 장 파일에서 import 합니다.

- 새 클래스: `Browser`
- 새 함수: `lex`, `layout`
