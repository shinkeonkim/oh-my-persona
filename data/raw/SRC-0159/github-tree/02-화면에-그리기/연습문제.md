# 2장 연습문제 구현

[← 2장 결과물로](결과물.md) · [← 본문으로](화면에-그리기.md#연습문제)

본문의 연습문제 7개를 모두 구현했습니다. `lab2.py` 는 그대로 두고, 1장 연습문제
(`ex1.py`)를 이어받아 그 위에 2장 기능을 얹은 `Browser` 를 `ex2.py` 에 정의했습니다.

## 실행

```bash
python3 ex2.py https://browser.engineering/
python3 ex2.py --rtl https://browser.engineering/     # 2-7 오른쪽에서 왼쪽
python3 ex2.py 'data:text/html,<b>hi</b>'             # 1장 연습문제도 그대로 동작
```

## 검증

```bash
python3 test_ex2.py
```

레이아웃·스크롤·스크롤바 계산을 순수 함수로 떼어 두어 창을 띄우지 않고 29개
테스트로 확인합니다.

## 구현 내용

| 문제 | 제목 | 구현 위치 | 요점 |
|---|---|---|---|
| 2-1 | 줄바꿈 | `layout` | 줄바꿈 문자에서 줄을 끝냅니다. 문단 사이는 `VSTEP + PARAGRAPH_STEP` 으로 자동 줄바꿈보다 더 벌립니다 |
| 2-2 | 마우스 휠 | `scrollup`, `on_wheel`, `clamp_scroll` | 위 방향키와 휠. 맨 위보다 위로는 못 갑니다. 플랫폼별 부호·단위를 각각 처리합니다 |
| 2-3 | 크기 조절 | `resize`, `layout(width=)` | `<Configure>` 로 새 크기를 받아 줄바꿈을 다시 계산합니다. 캔버스는 `fill`/`expand` 로 늘어납니다 |
| 2-4 | 스크롤바 | `max_scroll`, `scrollbar_geometry` | 마지막 줄 아래로는 안 갑니다. 오른쪽에 파란 막대를 그리고, 내용이 다 보이면 숨깁니다 |
| 2-5 | 이모지 | `is_emoji`, `emoji_image` | 코드포인트로 판별해 `openmoji/1F600.png` 형식의 파일을 찾아 그립니다 |
| 2-6 | `about:blank` | `URL`, `parse_url` | `about:` 스킴을 추가하고, 잘못된 URL 은 죽지 않고 빈 페이지로 대신합니다 |
| 2-7 | 텍스트 방향 | `layout(rtl=)` | 글자 순서는 그대로 두고 기준선만 뒤집어 오른쪽에서부터 채웁니다 |

## 이모지 그림 준비 (2-5)

코드는 파일이 없으면 조용히 글자로 그리므로 그냥 둬도 동작합니다. 그림으로 보려면
[OpenMoji](https://openmoji.org) 에서 PNG 를 받아 `openmoji/` 폴더에 코드포인트
이름으로 넣으세요.

```bash
mkdir -p openmoji
curl -L -o openmoji/1F600.png \
  https://raw.githubusercontent.com/hfg-gmuend/openmoji/master/color/72x72/1F600.png
```

## 설계 메모

**계산과 그리기를 분리했습니다.** `layout`, `max_scroll`, `clamp_scroll`,
`scrollbar_geometry` 는 tkinter 를 전혀 모르는 순수 함수입니다. 덕분에 창을 띄우지
않고 테스트할 수 있고, 3장에서 레이아웃이 복잡해질 때 그대로 확장할 수 있습니다.

**스크롤 한계를 한 곳에서 정합니다.** 방향키·휠·창 크기 조절이 모두
`clamp_scroll` 을 지나가므로, 어느 경로로 들어와도 화면 밖으로 넘어가지 않습니다.

**2-7 은 글자 순서를 뒤집지 않습니다.** 본문이 말하는 대로 영어 문장은 여전히
왼쪽에서 오른쪽으로 읽히되, 줄이 화면 오른쪽에서부터 자라납니다. 진짜 오른쪽에서
왼쪽으로 읽는 언어는 그 반대여야 합니다.
