# 7장 결과물 — 버튼과 링크 처리하기

[← 본문으로 돌아가기](버튼과-링크-처리하기.md)

7장까지 따라 만들면 완성되는 브라우저입니다. 1장부터 이 장까지의 코드가 모두 들어 있어 `code/` 폴더에서 바로 실행할 수 있습니다.

## 이 시점의 브라우저가 할 수 있는 일

- 단어마다 크기와 위치를 갖게 해 클릭 대상을 찾는다
- 링크를 클릭해 다른 페이지로 이동한다
- 탭 여러 개를 열고 전환한다
- 주소창에 URL 을 입력하고 뒤로 가기를 누른다

## 실행

```bash
cd code
python3 lab7.py https://browser.engineering/
```

## 필요한 것

- tkinter (파이썬 표준. 배포판에 따라 `python3-tk` 설치가 필요할 수 있습니다)

## 이 장에서 새로 추가된 것

`lab7.py` 는 이 장에서 새로 생기거나 바뀐 코드만 담고, 나머지는 이전 장 파일에서 import 합니다.

- 새 클래스: `URL`, `LineLayout`, `TextLayout`, `BlockLayout`, `DrawLine`, `DrawOutline`, `DrawText`, `Tab`, `Rect`, `DrawRect`, `Chrome`, `Browser`
- 기존 클래스 확장: `BlockLayout`, `DrawText`, `URL`
