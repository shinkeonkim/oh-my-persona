우리 브라우저에는 아직 _하이퍼텍스트_ 의 핵심 아이디어, 즉 하이퍼링크로 서로 연결된 문서가 빠져 있습니다. 지금은 파도를 구경할 수는 있어도 웹을 서핑할 수는 없는 셈입니다. 그래서 이 장에서는 하이퍼링크, 주소창, 그리고 나머지 브라우저 인터페이스를 구현하겠습니다. 브라우저 인터페이스란 우리가 _어떤_ 페이지를 보고 있는지를 결정하는 부분입니다.

## 링크는 어디에 있는가?

웹의 핵심은 링크이므로, 브라우저 인터페이스에서 가장 중요한 부분은 링크를 클릭하는 것입니다. 하지만 링크를 _클릭하는_ 데까지 가기 전에 더 근본적인 질문에 먼저 답해야 합니다. 화면에서 링크는 _어디에_ 있을까요? 문단과 제목은 레이아웃 트리에 크기와 위치가 기록되어 있지만, (링크 같은) 서식이 적용된 텍스트는 그렇지 않습니다. 이를 고쳐야 합니다.

핵심 아이디어는 두 가지 새로운 종류의 레이아웃 객체, `LineLayout`과 `TextLayout`을 도입하는 것입니다. 이제 `BlockLayout`은 텍스트의 각 줄마다 `LineLayout` 자식을 갖고, 그 `LineLayout`은 다시 그 줄의 각 단어마다 `TextLayout`을 갖게 됩니다. 이 새 클래스들 때문에 레이아웃 트리가 HTML 트리와 달라 보일 수 있습니다. 그러니 놀라지 않도록 간단한 예를 살펴봅시다.

```
<html>
  <body>
    Here is some text that is
    <br>
    spread across multiple lines
  </body>
</html>
```

`body` 요소의 텍스트는 (`br` 요소 때문에) 두 줄로 나뉘므로, 레이아웃 트리는 다음과 같은 구조를 갖게 됩니다.

```
DocumentLayout
  BlockLayout[block] (html element)
    BlockLayout[inline] (body element)
      LineLayout (first line of text)
        TextLayout ("Here")
        TextLayout ("is")
        TextLayout ("some")
        TextLayout ("text")
        TextLayout ("that")
        TextLayout ("is")
      LineLayout (second line of text)
        TextLayout ("spread")
        TextLayout ("across")
        TextLayout ("multiple")
        TextLayout ("lines")
```

`body` 요소 하나가 그 안에 두 개의 `LineLayout`을 가진 `BlockLayout` 하나에 대응하고, 텍스트 노드 두 개가 총 열 개의 `TextLayout`이 되는 것을 눈여겨보세요!

시작해 봅시다. `LineLayout`을 정의하는 것은 간단합니다.

```python
class LineLayout:
    def __init__(self, node, parent, previous):
        self.node = node
        self.parent = parent
        self.previous = previous
        self.children = []
```

`TextLayout`은 조금 더 까다롭습니다. 하나의 `TextLayout`은 HTML 노드 전체가 아니라 특정 단어 하나를 가리킵니다. 즉 `TextLayout`은 그 단어가 무엇인지 알기 위한 추가 인자가 필요합니다.

```python
class TextLayout:
    def __init__(self, node, word, parent, previous):
        self.node = node
        self.word = word
        self.children = []
        self.parent = parent
        self.previous = previous
```

다른 레이아웃 모드들과 마찬가지로 `LineLayout`과 `TextLayout`에도 각자의 `layout`과 `paint` 메서드가 필요하지만, 그 이야기로 가기 전에 `LineLayout`과 `TextLayout` 객체가 어떻게 만들어질지 생각해 봐야 합니다. 그 일은 줄바꿈 과정에서 일어나야 합니다.

`BlockLayout`의 `word` 메서드 안에서 [줄바꿈이 어떻게 동작하는지(3장 참조)](https://browser.engineering/text.html) 떠올려 봅시다. 이 메서드는 현재 줄의 모든 단어를 저장하는 `line` 필드를 갱신합니다.

```python
self.line.append((self.cursor_x, word, font, color))
```

다음 줄로 넘어갈 때가 되면 `word`는 `flush`를 호출하는데, `flush`는 줄의 위치와 그 안의 각 단어의 위치를 계산하고 모든 단어를 `display_list` 필드에 추가합니다. 이 필드는 인라인 요소 전체의 모든 단어를 저장합니다. `TextLayout`과 `LineLayout`이 생기면 이 복잡함의 상당 부분이 사라집니다. `LineLayout`은 자신의 `layout` 메서드에서 스스로 위치를 계산할 수 있고, `display_list` 필드 대신 각 `TextLayout`이 평소처럼 자신을 `paint`하기만 하면 됩니다. 자, 이 리팩터링을 시작해 봅시다.

줄에 단어를 추가하는 것부터 시작합시다. `line` 필드 대신 `TextLayout` 객체를 만들어 `LineLayout` 객체에 추가하려고 합니다. `LineLayout`은 `BlockLayout`의 자식이므로, 현재 줄은 `children` 배열의 끝에서 찾을 수 있습니다.

```python
class BlockLayout:
    def word(self, node, word):
        # ...
        line = self.children[-1]
        previous_word = line.children[-1] if line.children else None
        text = TextLayout(node, word, line, previous_word)
        line.children.append(text)
```

이제 줄 끝에 도달했을 때 무슨 일이 일어나야 하는지 생각해 봅시다. 현재 코드는 `flush`를 호출하는데, `flush`는 텍스트 위치를 정하고 `line` 필드를 비우는 등의 일을 합니다. 우리는 그 모든 것을 하고 싶지 않습니다. 그냥 새 `LineLayout` 객체를 만들고 싶을 뿐입니다. 그러니 그 일을 위해 다른 메서드를 사용합시다.

```python
class BlockLayout:
    def word(self, node, word):
        # ...
        w = font.measure(word)
        if self.cursor_x + w > self.width:
            self.new_line()
```

이 `new_line` 메서드는 그저 새 줄을 만들고 몇몇 필드를 초기화합니다.

```python
class BlockLayout:
    def new_line(self):
        self.cursor_x = 0
        last_line = self.children[-1] if self.children else None
        new_line = LineLayout(self.node, self, last_line)
        self.children.append(new_line)
```

이제 사용하지 않는 필드가 많아졌습니다. 정리합시다. 핵심 `layout` 메서드에서는 `display_list`, `cursor_y`, `line` 필드를 초기화할 필요가 없습니다. 더 이상 그중 어느 것도 쓰지 않을 테니까요. 대신 `new_line`과 `recurse`를 호출하기만 하면 됩니다.

```python
class BlockLayout:
    def layout(self):
        # ...
        else:
            self.new_line()
            self.recurse(self.node)
```

`layout` 메서드는 이미 자식들을 배치하기 위해 재귀 호출을 하므로 그 부분은 바꿀 필요가 없습니다. 게다가 이제는 문단의 높이를 그 줄들의 높이를 합해 계산할 수 있으므로, 코드의 이 부분이 더 이상 레이아웃 모드에 따라 달라질 필요가 없습니다.

```python
class BlockLayout:
    def layout(self):
        # ...
        self.height = sum([child.height for child in self.children])
```

이제 아무 데서도 호출되지 않으니 `flush` 메서드를 지우고 싶어질 수도 있습니다. 하지만 잠시만 남겨 두세요. 줄과 텍스트 객체의 `layout` 메서드를 작성하는 데 필요합니다.

### 더 알아보기

텍스트 노드가 만들어 내는 레이아웃 객체들은 연속적이지 않을 수도 있습니다. 예를 들어 페르시아어 인용문이 들어 있는 영어 문장은 한 줄 중간에서 왼쪽에서 오른쪽으로 가다가 오른쪽에서 왼쪽으로 뒤집힐 수 있습니다. 그러면 텍스트 레이아웃 객체들이 [놀라운 순서](https://www.w3.org/International/articles/inline-bidi-markup/uba-basics)로 배열됩니다. 게다가 [세로로](https://en.wikipedia.org/wiki/Mongolian_script) 배치되는 언어들도 있고요…

## 줄 레이아웃, 다시

이제 줄과 텍스트 객체를 만들고 있지만 아직 그것들을 배치해야 합니다. 줄부터 시작합시다. 줄은 세로로 쌓이고 부모의 너비를 모두 차지하므로, `x`, `y`, `width`를 계산하는 방식은 다른 박스들과 같아 보입니다.[^1]

```python
class LineLayout:
    def layout(self):
        self.width = self.parent.width
        self.x = self.parent.x

        if self.previous:
            self.y = self.previous.y + self.previous.height
        else:
            self.y = self.parent.y
        
        # ...
```

다만 높이 계산은 다릅니다. 여기가 바로 최대 어센트, 최대 디센트 등을 계산하는 부분입니다. 그것을 하기 전에 `TextLayout`을 배치하는 것을 먼저 살펴봅시다.

텍스트를 배치하려면 폰트 메트릭이 필요하므로, `BlockLayout`과 같은 폰트 생성 코드를 사용해 해당 폰트를 얻는 것부터 시작합시다.

```python
class TextLayout:
    def layout(self):
        weight = self.node.style["font-weight"]
        style = self.node.style["font-style"]
        if style == "normal": style = "roman"
        size = int(float(self.node.style["font-size"][:-2]) * .75)
        self.font = get_font(size, weight, style)
```

다음으로 단어의 크기와 `x` 위치를 계산해야 합니다. 크기 계산에는 폰트 메트릭을 사용하고, 위치 계산에는 단어들을 왼쪽에서 오른쪽으로 쌓습니다.

```python
class TextLayout:
    def layout(self):
        # ...

        self.width = self.font.measure(self.word)

        if self.previous:
            space = self.previous.font.measure(" ")
            self.x = self.previous.x + space + self.previous.width
        else:
            self.x = self.parent.x

        self.height = self.font.metrics("linespace")
```

다만 여기에는 `y` 위치를 계산하는 코드가 없습니다. 한 단어의 세로 위치는 같은 줄의 다른 단어들에 의존하므로, 그 `y` 위치는 `LineLayout`의 `layout` 메서드 안에서 계산하겠습니다.[^2]

그 메서드는 기존 `flush` 메서드에서 코드를 가져올 것입니다. 먼저 각 단어를 배치합니다.

```python
class LineLayout:
    def layout(self):
        # ...
        for word in self.children:
            word.layout()
```

다음으로 기존 `flush` 메서드와 사실상 같은 코드를 사용해, 최대 어센트와 디센트를 기준으로 줄의 베이스라인을 계산해야 합니다.

```python
# ...
max_ascent = max([word.font.metrics("ascent")
                  for word in self.children])
baseline = self.y + 1.25 * max_ascent
for word in self.children:
    word.y = baseline - word.font.metrics("ascent")
max_descent = max([word.font.metrics("descent")
            for word in self.children])
```

이 코드가 각 단어의 `font` 필드에서 읽고 각 단어의 `y` 필드에 쓴다는 점에 주의하세요. 즉 `TextLayout`의 `layout` 메서드 안에서는 `x`, `width`, `height`, `font`를 계산해야 하지만 `y`는 계산하지 않아야 합니다. 정확히 우리가 한 대로 말이죠.

마지막으로, 이제 각 줄이 독립적인 레이아웃 객체이므로 높이를 가져야 합니다. 최대 어센트와 디센트로부터 계산합니다.

```python
# ...
self.height = 1.25 * (max_ascent + max_descent)
```

이것이 `LineLayout`과 `TextLayout`의 `layout`입니다. 남은 것은 페인트뿐입니다. `LineLayout`에는 그릴 것이 없습니다.

```python
class LineLayout:
    def paint(self):
        return []
```

그리고 각 `TextLayout`은 하나의 `DrawText` 호출을 만들어 냅니다.

```python
class TextLayout:
    def paint(self):
        color = self.node.style["color"]
        return [DrawText(self.x, self.y, self.word, self.font, color)]
```

이제 `BlockLayout`에 `display_list` 필드가 필요 없고, `BlockLayout`의 `paint`에서 그것을 처리하는 부분도 제거할 수 있습니다. 대신 `paint_tree`가 자식들로 재귀해 들어가 그리기만 하면 됩니다. 이렇게 `LineLayout`과 `TextLayout`을 추가함으로써 `BlockLayout`을 꽤 단순하게 만들었고, 블록 레이아웃 모드와 인라인 레이아웃 모드 사이에 코드를 더 많이 공유하게 되었습니다.

휴, 정말 상당한 양의 리팩터링이었습니다. 잠시 시간을 내어 전부 테스트해 보세요. 이 리팩터링을 시작하기 전과 정확히 똑같아 보여야 합니다. 하지만 눈에 보이지는 않아도 결정적인 차이가 있습니다. 이제 페이지의 모든 파란 링크에는 각자의 레이아웃 객체와 자신만의 크기와 위치가 있습니다.

### 더 알아보기

사실 텍스트 렌더링은 이보다 [_훨씬_ 더 복잡합니다](https://gankra.github.io/blah/text-hates-you/). [글자](https://developer.apple.com/fonts/TrueType-Reference-Manual/RM06/Chap6morx.html)는 변형되고 겹칠 수 있으며, 사용자가 특정 글자를, 심지어 글자의 일부를 다른 색으로 칠하고 싶어 할 수도 있습니다. 이 모든 것이 HTML에서 가능하며, 실제 브라우저는 그것을 지원하도록 구현되어 있습니다.

## 클릭 처리하기

이제 링크가 어디에 있는지 알았으니 그것을 클릭하는 작업을 할 수 있습니다. Tk에서 클릭 처리는 키 입력 처리와 똑같이 동작합니다. 특정 이벤트에 이벤트 핸들러를 바인딩하면 됩니다. 클릭 처리의 경우 그 이벤트는 `<Button-1>`인데, 1번 버튼은 마우스의 왼쪽 버튼입니다.[^3]

```python
class Browser:
    def __init__(self):
        # ...
        self.window.bind("<Button-1>", self.click)
```

`click` 안에서 우리는 사용자가 어떤 링크를 클릭했는지 알아내고 싶습니다. 다행히 이벤트 핸들러에는 이벤트 객체가 넘어오는데, 그 객체의 `x`와 `y` 필드가 클릭이 일어난 위치를 가리킵니다.

```python
class Browser:
    def click(self, e):
        x, y = e.x, e.y
```

여기서 좌표계에 주의해야 합니다. 그 _x_ 와 _y_ 좌표는 브라우저 창을 기준으로 합니다. 캔버스가 창의 왼쪽 위 모서리에 있으므로 그 값은 캔버스를 기준으로 한 _x_, _y_ 좌표이기도 합니다. 우리가 원하는 것은 웹 페이지를 기준으로 한 좌표이므로 스크롤을 고려해야 합니다.

```python
class Browser:
    def click(self, e):
        # ...
        y += self.scroll
```

좀 더 일반적으로 말하면, 클릭 같은 이벤트를 처리하는 일은 평소의 렌더링 파이프라인을 _거꾸로 되짚는_ 것입니다. 보통 렌더링은 요소에서 레이아웃 객체로, 페이지 좌표로, 화면 좌표로 진행됩니다. 클릭 처리는 그 반대로, 화면 좌표에서 시작해 페이지 좌표로 변환하고, 그런 식으로 이어집니다. 실제로 이 대응이 완벽하게 역방향인 것은 아니지만[^4] 유용한 비유입니다.

그러니 다음 단계는 페이지 좌표에서 레이아웃 객체로 가는 것입니다.[^5]

```python
# ...
objs = [obj for obj in tree_to_list(self.document, [])
        if obj.x <= x < obj.x + obj.width
        and obj.y <= y < obj.y + obj.height]
```

원칙적으로 이 목록에는 레이아웃 객체가 여러 개 있을 수 있습니다.[^6] 하지만 클릭 처리가 페인트의 역방향임을 기억하세요. 페인트할 때 우리는 트리를 앞에서 뒤로 그리므로, 히트 테스팅을 할 때는 마지막 요소에서 시작해야 합니다.[^7]

```python
# ...
if not objs: return
elt = objs[-1].node
```

이 `elt` 노드가 클릭된 가장 구체적인 노드입니다. 링크의 경우 보통 텍스트 노드가 됩니다. 하지만 사용자가 클릭한 실제 URL을 알고 싶으므로, HTML 트리를 거슬러 올라가 링크 요소를 찾아야 합니다.[^8]

```python
# ...
while elt:
    if isinstance(elt, Text):
        pass
    elif elt.tag == "a" and "href" in elt.attributes:
        # ...
    elt = elt.parent
```

링크 요소 자체를 찾았으면 URL을 뽑아내 로드해야 합니다.

```python
# ...
elif elt.tag == "a" and "href" in elt.attributes:
    url = self.url.resolve(elt.attributes["href"])
    return self.load(url)
```

이 `resolve` 호출을 하려면 현재 페이지의 URL을 저장해 두어야 한다는 점에 주의하세요.

```python
class Browser:
    def __init__(self):
        # ...
        self.url = None

    def load(self, url):
        self.url = url
        # ...
```

시험해 보세요! 이제 링크를 클릭해 새 웹 페이지로 이동할 수 있을 것입니다.

### 더 알아보기

모바일 기기에서 "클릭"은 하나의 점이 아니라 어떤 영역에서 일어납니다. 모바일의 "탭"은 흔히 꽤 부정확하기 때문에, 클릭은 "히트 테스팅"에 [점이 아니라 영역 정보를 사용해야 합니다](http://www.chromium.org/developers/design-documents/views-rect-based-targeting). 회전되거나 크기가 조절된 요소를 클릭할 때는 [보통의 마우스 클릭](https://source.chromium.org/chromium/chromium/src/+/main:third_party/blink/renderer/core/layout/hit_test_location.h)에서도 이런 일이 일어날 수 있습니다.

## 여러 페이지

여러분이 저와 비슷하다면, 링크를 클릭한 다음으로 시도해 본 것은 아마 가운데 버튼으로 클릭해 새 탭에서 여는 일이었을 것입니다. 이제 모든 브라우저에 탭 브라우징이 있는데, 솔직히 우리 브라우저에 그것이 없다는 것은 조금 부끄러운 일입니다.[^9]

근본적으로 탭 브라우징을 구현하려면 브라우저 자체와 개별 웹 페이지를 보여 주는 탭을 구분해야 합니다. 예를 들어 브라우저가 그리는 캔버스는 모든 웹 페이지가 공유하지만, 레이아웃 트리와 디스플레이 리스트는 한 페이지에만 해당합니다. 탭과 브라우저를 떼어 놓아야 합니다.

계획은 이렇습니다. `Browser` 클래스가 창과 캔버스, 그리고 이벤트 처리 같은 모든 관련 메서드를 소유합니다. 또한 `Tab` 객체들의 리스트와 브라우저 크롬도 담습니다. 하지만 웹 페이지 자체와 그와 관련된 메서드들은 새로운 `Tab` 클래스로 옮깁니다.

우선, 지금까지 단일 웹 페이지만 다뤄 왔으므로 기존 `Browser` 클래스의 이름을 그냥 `Tab`으로 바꾸세요.

```python
class Tab:
    # ...
```

그다음 새로운 `Browser` 클래스가 필요합니다. 이 클래스는 탭들의 리스트와 그중 어느 것이 활성인지를 저장해야 합니다.

```python
class Browser:
    def __init__(self):
        self.tabs = []
        self.active_tab = None
```

또한 창을 소유하고 모든 이벤트를 처리합니다.

```python
class Browser:
    def __init__(self):
        self.window = tkinter.Tk()
        self.canvas = tkinter.Canvas(
            # ...
        )
        self.canvas.pack()
        self.window.bind("<Down>", self.handle_down)
        self.window.bind("<Button-1>", self.handle_click)
```

`Tab`의 생성자에서는 이 줄들을 제거하세요.

`handle_down`과 `handle_click` 메서드는 페이지별 정보가 필요하므로, 이 핸들러 메서드들은 이벤트를 활성 탭으로 전달하기만 합니다.

```python
class Browser:
    def handle_down(self, e):
        self.active_tab.scrolldown()
        self.draw()

    def handle_click(self, e):
        self.active_tab.click(e.x, e.y)
        self.draw()
```

`Tab`의 `scrolldown`과 `click` 메서드를 손봐야 합니다.

- `scrolldown`은 이제 (이벤트 객체가 아니라) 인자를 받지 않습니다.

- `click`은 이제 (이벤트 객체가 아니라) 좌표 두 개를 받습니다.

마지막으로 `Browser`의 `draw` 호출도 활성 탭을 호출합니다.

```python
class Browser:
    def draw(self):
        self.canvas.delete("all")
        self.active_tab.draw(self.canvas)
```

화면을 지우는 일은 `Tab`이 아니라 `Browser`의 몫이라는 점에 주의하세요. 그 뒤에는 활성 탭만 그리는데, 탭은 원래 그렇게 동작해야 합니다. `Tab`의 `draw` 메서드는 캔버스를 인자로 받아야 합니다.

```python
class Tab:
    def draw(self, canvas):
        # ...
```

`Browser`가 캔버스를 제어하고 이벤트를 처리하므로, 언제 렌더링이 일어나고 어떤 탭이 그리기를 할지는 `Browser`가 결정합니다. 그러니 `load`와 `scrolldown` 메서드에서도 `draw` 호출을 제거합시다. 좀 더 일반적으로 말하면 `Browser`는 "능동적"이고 `Tab`은 "수동적"입니다. 모든 사용자 상호작용은 `Browser`에서 시작되고, `Browser`가 필요에 따라 탭을 호출합니다.

이제 `Tab`을 `Browser`에서 분리하는 작업이 거의 끝났고, 이런 리팩터링 뒤에는 테스트를 해야 합니다. 그러려면 다음과 같이 탭을 최소한 하나는 만들어야 합니다.

```python
class Browser:
    def new_tab(self, url):
        new_tab = Tab()
        new_tab.load(url)
        self.active_tab = new_tab
        self.tabs.append(new_tab)
        self.draw()
```

시작할 때 이제 탭 하나를 가진 `Browser`를 만들어야 합니다.

```python
if __name__ == "__main__":
    import sys
    Browser().new_tab(URL(sys.argv[1]))
    tkinter.mainloop()
```

물론 _사용자_ 가 탭을 전환하고, 새로 만들고, 그 밖의 일을 할 수 있는 방법이 필요합니다. 다음으로 그 이야기를 해 봅시다.

## 브라우저 크롬

실제 웹 브라우저는 웹 페이지 내용만 보여 주지 않습니다. 라벨과 아이콘과 버튼이 있죠.[^11] 이를 브라우저 "크롬(chrome)"이라고 부릅니다.[^12] 이 모든 것은 브라우저가 페이지 내용과 같은 창에 그리며, (모든 탭의 목록처럼) 브라우저 전체에 관한 정보가 필요하므로 탭 단위가 아니라 브라우저 단위에서 이루어져야 합니다.

다만 브라우저의 UI는 꽤 복잡하므로, 그 코드는 새로운 `Chrome` 헬퍼 클래스에 넣읍시다.

```python
class Chrome:
    def __init__(self, browser):
        self.browser = browser

class Browser:
    def __init__(self):
        # ...
        self.chrome = Chrome(self)
```

브라우저 크롬을 설계해 봅시다. 최종적으로 두 줄로 이루어지면 좋겠다고 생각합니다(그림 1 참조).

- 맨 위에는 세로선으로 구분된 탭 이름 목록과 새 탭을 추가하는 "`+`" 버튼

- 그 아래에는 현재 웹 페이지의 URL과 브라우저 뒤로 가기 버튼을 나타내는 "`<`" 버튼

![그림 1: 브라우저 크롬의 의도한 모습.](chrome-chrome.png)

*그림 1: 브라우저 크롬의 의도한 모습.*

이 디자인의 상당 부분이 텍스트와 관련되므로 폰트를 고르는 것부터 시작합시다.

```python
class Chrome:
    def __init__(self, browser):
        # ...
        self.font = get_font(20, "normal", "roman")
        self.font_height = self.font.metrics("linespace")
```

운영체제마다 폰트를 그리는 방식이 다르므로, 폰트 메트릭을 기준으로 브라우저 크롬의 정확한 디자인을 조정해야 합니다. 그래서 나중에 `font_height`가 필요합니다.[^13]

그 폰트 높이를 사용해 이제 탭 바가 어디서 시작하고 끝나는지 정할 수 있습니다.

```python
class Chrome:
    def __init__(self, browser):
        # ...
        self.padding = 5
        self.tabbar_top = 0
        self.tabbar_bottom = self.font_height + 2*self.padding
```

텍스트가 창 가장자리에 부딪히지 않도록 여백을 조금 추가했다는 점에 주의하세요.

브라우저 크롬의 여러 요소의 크기를 나타내는 직사각형을 저장하려고 합니다. 그러기에는 새로운 `Rect` 클래스가 편리합니다.

```python
class Rect:
    def __init__(self, left, top, right, bottom):
        self.left = left
        self.top = top
        self.right = right
        self.bottom = bottom
```

이제 이 탭 줄에는 새 탭 버튼과 탭 이름들이 들어가야 합니다.

새 탭 버튼 주위에 여백을 넣겠습니다.

```python
class Chrome:
    def __init__(self, browser):
        # ...
        plus_width = self.font.measure("+") + 2*self.padding
        self.newtab_rect = Rect(
           self.padding, self.padding,
           self.padding + plus_width,
           self.padding + self.font_height)
```

그러면 탭들은 새 탭 버튼의 끝에서 `padding`만큼 떨어진 곳에서 시작합니다. 탭의 개수는 바뀔 수 있으므로 각 탭의 위치를 저장하지 않고, 그때그때 경계를 계산하겠습니다.

```python
class Chrome:
    def tab_rect(self, i):
        tabs_start = self.newtab_rect.right + self.padding
        tab_width = self.font.measure("Tab X") + 2*self.padding
        return Rect(
            tabs_start + tab_width * i, self.tabbar_top,
            tabs_start + tab_width * (i + 1), self.tabbar_bottom)
```

"Tab X"라는 텍스트를 측정해 그것을 모든 탭 너비로 사용한다는 점에 주의하세요. 이는 완전히 정확하지는 않습니다. 많은 폰트에서 8 같은 숫자는 1 같은 숫자보다 넓으니까요. 하지만 충분히 비슷하고, 어차피 문자 X는 보통 가장 넓은 숫자만큼 넓습니다.

실제로 UI를 그리기 위해, 먼저 브라우저 크롬이 디스플레이 리스트를 페인트하게 하고 그다음 `Browser`가 그것을 화면에 그리게 하겠습니다.

```python
class Chrome:
    def paint(self):
        cmds = []
        # ...
        return cmds
```

먼저 새 탭 버튼을 그리는 것부터 시작합시다.

```python
class Chrome:
    def paint(self):
        # ...
        cmds.append(DrawOutline(self.newtab_rect, "black", 1))
        cmds.append(DrawText(
            self.newtab_rect.left + self.padding,
            self.newtab_rect.top,
            "+", self.font, "black"))
        # ...
```

`DrawOutline` 명령은 직사각형 테두리를 그립니다.

```python
class DrawOutline:
    def __init__(self, rect, color, thickness):
        self.rect = rect
        self.color = color
        self.thickness = thickness

    def execute(self, scroll, canvas):
        canvas.create_rectangle(
            self.rect.left, self.rect.top - scroll,
            self.rect.right, self.rect.bottom - scroll,
            width=self.thickness,
            outline=self.color)
```

다음은 탭을 그리는 것입니다. Python의 `enumerate` 함수를 쓰면 배열의 인덱스와 내용을 동시에 순회할 수 있습니다. 각 탭마다 왼쪽과 오른쪽에 테두리를 만들고 탭 이름을 그려야 합니다.

```python
class Chrome:
    def paint(self):
        # ...
        for i, tab in enumerate(self.browser.tabs):
            bounds = self.tab_rect(i)
            cmds.append(DrawLine(
                bounds.left, 0, bounds.left, bounds.bottom,
                "black", 1))
            cmds.append(DrawLine(
                bounds.right, 0, bounds.right, bounds.bottom,
                "black", 1))
            cmds.append(DrawText(
                bounds.left + self.padding, bounds.top + self.padding,
                "Tab {}".format(i), self.font, "black"))
        # ...
```

마지막으로, 어느 탭이 활성 탭인지 알 수 있도록 현재 탭이 위로 튀어나온 서류철 모양을 만들어야 합니다.

```python
class Chrome:
    def paint(self):
        for i, tab in enumerate(self.browser.tabs):
            # ...
            if tab == self.browser.active_tab:
                cmds.append(DrawLine(
                    0, bounds.bottom, bounds.left, bounds.bottom,
                    "black", 1))
                cmds.append(DrawLine(
                    bounds.right, bounds.bottom, WIDTH, bounds.bottom,
                    "black", 1))
```

`DrawLine` 명령은 주어진 색과 두께로 선을 그립니다. 다음과 같이 정의됩니다.

```python
class DrawLine:
    def __init__(self, x1, y1, x2, y2, color, thickness):
        self.rect = Rect(x1, y1, x2, y2)
        self.color = color
        self.thickness = thickness

    def execute(self, scroll, canvas):
        canvas.create_line(
            self.rect.left, self.rect.top - scroll,
            self.rect.right, self.rect.bottom - scroll,
            fill=self.color, width=self.thickness)
```

마지막으로 하나 더. 브라우저 크롬이 항상 페이지 내용 위에 그려지도록 해야 합니다. 이를 보장하기 위해 크롬 뒤에 흰색 직사각형을 그릴 수 있습니다.

```python
class Chrome:
    def __init__(self, browser):
        # ...
        self.bottom = self.tabbar_bottom

    def paint(self):
        # ...
        cmds.append(DrawRect(
            Rect(0, 0, WIDTH, self.bottom),
            "white"))
        cmds.append(DrawLine(
            0, self.bottom, WIDTH,
            self.bottom, "black", 1))
        # ...
```

배경이 크롬의 다른 어떤 부분보다 먼저 그려지도록 하세요. 또한 크롬을 페이지와 구분하기 위해 크롬 아래쪽에 선을 하나 추가했습니다. `DrawRect`가 네 모서리 대신 `Rect`를 받도록 바꾼 점도 눈여겨보세요. 이 때문에 `BlockLayout`도 바꿔야 합니다.

```python
class BlockLayout:
    def self_rect(self):
        return Rect(self.x, self.y,
            self.x + self.width, self.y + self.height)

    def paint(self):
        # ...
        if bgcolor != "transparent":
            rect = DrawRect(self.self_rect(), bgcolor)
            cmds.append(rect)
        return cmds
```

`DrawText`와 `DrawLine`에도 `rect` 필드를 추가하세요. (`DrawText`의 너비와 높이는 텍스트의 너비와 높이여야 합니다.)

이제 이 크롬 디스플레이 리스트를 그리는 일은 간단합니다.

```python
class Browser:
    def draw(self):
        # ...
        for cmd in self.chrome.paint():
            cmd.execute(0, self.canvas)
```

이 디스플레이 리스트는 (스크롤되는) 탭 내용과 달리 항상 창의 맨 위에 그려진다는 점에 주의하세요. 크롬이 그 위에 그려지도록 반드시 메인 탭 내용 _뒤에_ 크롬을 그리세요.

다만 브라우저 크롬이 세로 공간을 차지한다는 점을 반영해 탭 그리기도 조금 조정해야 합니다. `Tab`에 `tab_height` 매개변수를 추가합시다.

```python
class Tab:
    def __init__(self, tab_height):
        # ...
        self.tab_height = tab_height
```

이 값을 `new_tab`에 넘길 수 있습니다.

```python
class Browser:
    def new_tab(self, url):
        new_tab = Tab(HEIGHT - self.chrome.bottom)
        # ...
```

그러면 페이지 내용의 높이가 이제 `tab_height`라는 점을 반영해 `scrolldown`을 조정할 수 있습니다.

```python
class Tab:
    def scrolldown(self):
        max_y = max(
            self.document.height + 2*VSTEP - self.tab_height, 0)
        self.scroll = min(self.scroll + SCROLL_STEP, max_y)
```

마지막으로 `Tab`의 `draw` 메서드에서 그리기 명령들을 크롬 높이만큼 아래로 옮겨야 합니다. 크롬 높이를 `offset` 매개변수로 넘기겠습니다.

```python
class Tab:
    def draw(self, canvas, offset):
        for cmd in self.display_list:
            if cmd.rect.top > self.scroll + self.tab_height:
                continue
            if cmd.rect.bottom < self.scroll: continue
            cmd.execute(self.scroll - offset, canvas)
```

이제 `Browser`의 최종 `draw` 메서드는 다음과 같습니다.

```python
class Browser:
    def draw(self):
        self.canvas.delete("all")
        self.active_tab.draw(self.canvas, self.chrome.bottom)
        for cmd in self.chrome.paint():
            cmd.execute(0, self.canvas)
```

한 가지 더 있습니다. 탭을 클릭해 전환하는 것입니다. `Browser`가 클릭을 처리하는데, 이제 브라우저 크롬에 대한 클릭은 `Chrome` 객체에 위임해야 합니다.

```python
class Browser:
    def handle_click(self, e):
        if e.y < self.chrome.bottom:
            self.chrome.click(e.x, e.y)
        else:
            tab_y = e.y - self.chrome.bottom
            self.active_tab.click(e.x, tab_y)
        self.draw()
```

탭 내용을 클릭할 때는 크롬 크기를 빼야 한다는 점에 주의하세요. 브라우저 크롬에 대한 클릭의 경우, `Chrome` 안에서 사용자가 무엇을 클릭했는지 알아내야 합니다. 이를 쉽게 하기 위해 어떤 점이 `Rect` 안에 들어 있는지 검사하는 간단한 메서드를 추가합시다.

```python
class Rect:
    def contains_point(self, x, y):
        return x >= self.left and x < self.right \
            and y >= self.top and y < self.bottom
```

`Chrome` 안에서 클릭을 처리하는 데 이 메서드를 사용하고, 이를 이용해 새 탭을 추가하는 클릭인지 열려 있는 탭을 선택하는 클릭인지 구분합니다.

```python
class Chrome:
    def click(self, x, y):
        if self.newtab_rect.contains_point(x, y):
            self.browser.new_tab(URL("https://browser.engineering/"))
        else:
            for i, tab in enumerate(self.browser.tabs):
                if self.tab_rect(i).contains_point(x, y):
                    self.browser.active_tab = tab
                    break
```

"새 탭" 페이지로 적절하지 않나요? 어쨌든 이제 여러 탭을 로드하고, 각각을 독립적으로 스크롤하고 클릭하고, 탭을 클릭해 전환할 수 있을 것입니다.

### 더 알아보기

Google Chrome 1.0은 그 기능을 소개하는 [만화책](https://www.google.com/googlebooks/chrome/)과 함께 출시되었습니다. 디자인 아이디어와 사용자 인터페이스 기능에 관한 [한 장(章) 전체](https://www.google.com/googlebooks/chrome/big_18.html)가 있는데, 그중 상당수가 지금까지 남아 있습니다. 예를 들어 이 책의 브라우저조차 탭이 위쪽에 있습니다.

## 방문 기록

이제 페이지 사이를 계속 오가게 되었으니, 조금 헤매다가 지금 어떤 웹 페이지를 보고 있는지 잊어버리기 쉽습니다. 현재 URL을 보여 주는 주소창이 큰 도움이 될 것입니다. 크롬에 그 자리를 만듭시다.

```python
class Chrome:
    def __init__(self, browser):
        # ...
        self.urlbar_top = self.tabbar_bottom
        self.urlbar_bottom = self.urlbar_top + \
            self.font_height + 2*self.padding
        self.bottom = self.urlbar_bottom
```

이 "URL 바"에는 뒤로 가기 버튼과 주소창이 들어갑니다.

```python
class Chrome:
    def __init__(self, browser):
        # ...
        back_width = self.font.measure("<") + 2*self.padding
        self.back_rect = Rect(
            self.padding,
            self.urlbar_top + self.padding,
            self.padding + back_width,
            self.urlbar_bottom - self.padding)

        self.address_rect = Rect(
            self.back_rect.right + self.padding,
            self.urlbar_top + self.padding,
            WIDTH - self.padding,
            self.urlbar_bottom - self.padding)
```

뒤로 가기 버튼을 그리는 것은 간단합니다.

```python
class Chrome:
    def paint(self):
        # ...
        cmds.append(DrawOutline(self.back_rect, "black", 1))
        cmds.append(DrawText(
            self.back_rect.left + self.padding,
            self.back_rect.top,
            "<", self.font, "black"))
```

주소창은 브라우저로부터 현재 탭의 URL을 가져와야 합니다.

```python
class Chrome:
    def paint(self):
        # ...
        cmds.append(DrawOutline(self.address_rect, "black", 1))
        url = str(self.browser.active_tab.url)
        cmds.append(DrawText(
            self.address_rect.left + self.padding,
            self.address_rect.top,
            url, self.font, "black"))
```

여기서 `str`은 Python 내장 함수인데, `URL` 객체를 문자열로 올바르게 변환하도록 재정의할 수 있습니다.

```python
class URL:
    def __str__(self):
        port_part = ":" + str(self.port)
        if self.scheme == "https" and self.port == 443:
            port_part = ""
        if self.scheme == "http" and self.port == 80:
            port_part = ""
        return self.scheme + "://" + self.host + port_part + self.path
```

포트 번호를 숨기는 추가 로직은 URL을 더 깔끔하게 만들어 주니 그만한 가치가 있다고 생각합니다.

뒤로 가기 버튼을 클릭하면 무슨 일이 일어나야 할까요? _그 탭_ 이 뒤로 가야 합니다. 다른 탭은 영향을 받지 않습니다. 그러니 `Browser`는 뒤로 가기 위해 현재 탭의 어떤 메서드를 호출해야 합니다.

```python
class Chrome:
    def click(self, x, y):
        # ...
        elif self.back_rect.contains_point(x, y):
            self.browser.active_tab.go_back()
```

활성 탭이 "뒤로 가려면" 이전에 방문한 페이지들의 "기록"을 저장해야 합니다.

```python
class Tab:
    def __init__(self, tab_height):
        # ...
        self.history = []
```

새 페이지로 갈 때마다 기록이 늘어납니다.

```python
class Tab:
    def load(self, url):
        self.history.append(url)
        # ...
```

뒤로 가기는 그 기록을 사용합니다. 이렇게 쓰고 싶어질 수도 있습니다.

```python
class Tab:
    def go_back(self):
        if len(self.history) > 1:
            self.load(self.history[-2])
```

거의 맞지만, `load`가 기록에 추가하기 때문에 뒤로 가기 버튼을 두 번 누르면 동작하지 않습니다. 대신 다음과 비슷하게 해야 합니다.

```python
class Tab:
    def go_back(self):
        if len(self.history) > 1:
            self.history.pop()
            back = self.history.pop()
            self.load(back)
```

이제 뒤로 가면 기록이 줄어들고 링크를 클릭하면 늘어납니다. 마땅히 그래야 하듯이 말이죠.

이제 바로 이 책을 읽기에 꽤 괜찮은 웹 브라우저가 생겼습니다. 링크를 클릭하고, 여기저기 둘러보고, 심지어 여러 장을 동시에 열어 서로 참조할 수도 있습니다. 하지만 현재 페이지에서 링크되지 않은 웹사이트를 방문하기는 조금 어렵습니다.

### 더 알아보기

브라우저의 방문 기록에는 사용자가 어떤 웹사이트를 즐겨 방문하는지에 관한 민감한 정보가 들어 있을 수 있으므로, 이를 안전하게 지키는 것이 중요합니다. 놀랍게도 이는 꽤 어려운 일인데, [`:visited` 선택자](https://developer.mozilla.org/en-US/docs/Web/CSS/:visited) 같은 CSS 기능으로 어떤 URL을 이전에 방문했는지 [알아낼 수 있기](https://blog.mozilla.org/security/2010/03/31/plugging-the-css-history-leak/) 때문입니다. 그래서 `:visited`를 제한하려는 [노력](https://github.com/kyraseevers/Partitioning-visited-links-history)이 있습니다.

## URL 편집하기

다른 페이지로 가는 한 가지 방법은 링크를 클릭하는 것입니다. 하지만 대부분의 브라우저는 URL을 알고 있다면 주소창에 입력해 새 URL로 갈 수 있게도 해 줍니다.

주소를 입력하는 복잡한 의식을 잠시 살펴봅시다(그림 2 참조).

- 먼저 주소창을 클릭해 거기에 "포커스"를 줍니다.

- 그러면 주소 전체가 선택되어, 타이핑을 시작하면 전부 지워집니다.

- 그다음 여러분이 입력하는 글자들이 주소창에 들어갑니다.

- 주소창은 입력에 따라 갱신되지만 브라우저는 아직 새 페이지로 이동하지 않습니다.

- 마지막으로 "Enter" 키를 누르면 새 페이지로 이동합니다.

![그림 2: Apple Safari 16.6에서 주소창을 편집하는 모습의 스크린샷.](chrome-editing.png)

*그림 2: Apple Safari 16.6에서 주소창을 편집하는 모습의 스크린샷.*

이 단계들은 브라우저가 주소창의 내용을 `url` 필드와 별도로 저장하고, 현재 주소창에 입력 중인지를 나타내는 상태도 갖고 있음을 시사합니다. 그 내용을 `address_bar`, 그 상태를 `focus`라고 부릅시다.

```python
class Chrome:
    def __init__(self, browser):
        # ...
        self.focus = None
        self.address_bar = ""
```

주소창을 클릭하면 `focus`가 설정되고, 그 바깥을 클릭하면 `focus`가 해제되어야 합니다.

```python
class Chrome:
    def click(self, x, y):
        self.focus = None
        # ...
        elif self.address_rect.contains_point(x, y):
            self.focus = "address bar"
            self.address_bar = ""
```

주소창을 클릭하면 주소창 내용도 지워진다는 점에 주의하세요. 실제 브라우저가 하는 것과 정확히 같지는 않지만 꽤 비슷하며, 덕분에 텍스트 선택 기능을 추가하는 일을 건너뛸 수 있습니다.

이제 주소창을 그릴 때 현재 URL을 그릴지 현재 입력된 텍스트를 그릴지 확인해야 합니다.

```python
class Chrome:
    def paint(self):
        # ...
        if self.focus == "address bar":
            cmds.append(DrawText(
                self.address_rect.left + self.padding,
                self.address_rect.top,
                self.address_bar, self.font, "black"))
        else:
            url = str(self.browser.active_tab.url)
            cmds.append(DrawText(
                self.address_rect.left + self.padding,
                self.address_rect.top,
                url, self.font, "black"))
```

사용자가 주소창에 입력 중일 때는 커서도 그립시다. (포커스 같은) 상태를 (커서처럼) 화면에 보이게 만들면 소프트웨어를 쓰기가 더 쉬워집니다.

```python
class Chrome:
    def paint(self):
        # ...
        if self.focus == "address bar":
            # ...
            w = self.font.measure(self.address_bar)
            cmds.append(DrawLine(
                self.address_rect.left + self.padding + w,
                self.address_rect.top,
                self.address_rect.left + self.padding + w,
                self.address_rect.bottom,
                "red", 1))
```

다음으로, 주소창에 포커스가 있을 때 URL 입력을 지원해야 합니다. Tk에서는 `<Key>`에 바인딩해 모든 키 입력을 잡을 수 있습니다. 이벤트 객체의 `char` 필드에는 사용자가 입력한 문자가 들어 있습니다.

```python
class Browser:
    def __init__(self):
        # ...
        self.window.bind("<Key>", self.handle_key)

    def handle_key(self, e):
        if len(e.char) == 0: return
        if not (0x20 <= ord(e.char) < 0x7f): return
        self.chrome.keypress(e.char)
        self.draw()
```

이 `handle_key` 핸들러는 몇 가지 조건으로 시작합니다. `<Key>`는 일반 글자뿐 아니라 모든 키 입력에 대해 발생하므로, 문자가 입력되지 않은 경우(수정자 키가 눌린 경우)나 문자가 ASCII 범위 밖인 경우(방향키나 기능키를 나타낼 수 있습니다)는 무시하려고 합니다. 지금은 `Browser`가 모든 키 입력을 `Chrome`에 보내고 그다음 `draw()`를 호출해 새 글자가 실제로 나타나게 합시다.

그러면 `Chrome`은 `focus`를 확인하고 `address_bar`에 덧붙일 수 있습니다.

```python
class Chrome:
    def keypress(self, char):
        if self.focus == "address bar":
            self.address_bar += char
```

마지막으로, 새 URL이 입력되고 나면 Tk가 `<Return>`이라고 부르는 "Enter" 키를 처리해 실제로 브라우저를 새 주소로 보내야 합니다.

```python
class Chrome:
    def enter(self):
        if self.focus == "address bar":
            self.browser.active_tab.load(URL(self.address_bar))
            self.focus = None

class Browser:
    def __init__(self):
        # ...
        self.window.bind("<Return>", self.handle_enter)

    def handle_enter(self, e):
        self.chrome.enter()
        self.draw()
```

자, 긴 장이 끝났으니 이제 웹 서핑을 하며 좀 쉬어도 되겠습니다.

**7-2 _가운데 클릭_.** 링크를 가운데 버튼으로 클릭(`Button-2`)해 새 탭에서 여는 기능을 추가하세요. 테스트할 때는 마우스를 쓰는 편이 좋습니다.

**7-3 _창 제목_.** 브라우저는 창 제목을 현재 탭의 `<title>` 요소 내용으로 설정합니다. 여러분의 브라우저도 똑같이 하도록 만드세요. (창 제목을 바꾸려면 `Browser.window`의 `title` 메서드를 호출하면 됩니다.)

**7-4 _앞으로 가기_.** 뒤로 가기 버튼을 되돌리는 앞으로 가기 버튼을 추가하세요. 가장 최근의 이동 동작이 뒤로 가기 버튼이 아니었다면 앞으로 가기 버튼은 아무 일도 하지 않아야 합니다.[^14] 그런 경우에는 사용자가 왜 동작하지 않는지 궁금해하지 않도록 회색으로 그리세요. 뒤로 갈 곳이 없다면 뒤로 가기 버튼도 회색으로 그리세요.

**7-5 _프래그먼트_.** URL에는 _프래그먼트_ 가 들어갈 수 있습니다. 프래그먼트는 URL의 끝에 오며 해시 기호 `#`로 경로와 구분됩니다. 브라우저가 프래그먼트가 있는 URL로 이동하면, 그 식별자를 가진 요소가 화면 맨 위에 오도록 페이지를 스크롤해야 합니다. 프래그먼트 링크도 구현하세요. `#`로 시작하는 상대 URL은 새 페이지를 로드하지 않고 그 식별자를 가진 요소를 화면 맨 위로 스크롤합니다. [이 장의 웹 버전](https://browser.engineering/chrome.html)의 목차가 프래그먼트 링크를 사용합니다.

**7-6 _검색_.** 사용자가 주소창에 URL이 _아닌_ 것을 입력하면, 브라우저가 자동으로 검색 엔진으로 그것을 검색하게 만드세요. 이는 보통 특별한 URL로 이동하는 것을 뜻합니다. 예를 들어 `https://google.com/search?q=QUERY`로 이동하면 Google에서 검색할 수 있는데, 여기서 `QUERY`는 모든 공백을 `+` 기호로 바꾼 검색어입니다.[^15]

**7-7 _방문한 링크_.** 실제 브라우저에서는 이전에 방문한 링크가 보통 보라색입니다. 그 기능을 구현하세요. 방문한 URL의 집합을 저장하고, 해당하는 HTML 요소에 표시를 하고, 텍스트를 그릴 때 그 표시를 확인해야 합니다.[^16]

**7-8 _북마크_.** 기본적인 _북마크_ 를 구현하세요. 브라우저 크롬에 버튼을 추가하고, 그것을 클릭하면 페이지가 북마크되게 하세요. 북마크된 페이지를 보고 있을 때는 그 북마크 버튼이 (아마 노란색으로?) 다르게 보여서 사용자에게 그 페이지가 북마크되었음을 알려 주어야 하고, 그것을 클릭하면 북마크가 해제되어야 합니다. 북마크 목록을 보기 위한 특별한 웹 페이지 `about:bookmarks`도 추가하세요.

**7-9 _커서_.** 주소창에 포커스가 있을 때 좌우 방향키로 텍스트 커서를 움직일 수 있게 만드세요. 백스페이스 키를 누르면 커서 앞의 문자가 지워지고, 다른 키를 입력하면 커서 위치에 문자가 추가되어야 합니다. (커서가 첫 글자 앞이나 마지막 글자 뒤에 있을 수 있다는 점을 기억하세요!)

**7-10 _여러 창_.** 탭에 더해 여러 브라우저 창을 지원하도록 추가하세요. 여러 Tk 창과 캔버스를 추적하고 탭을 그것이 속한 창별로 묶어야 합니다. 새 창을 만드는 방법도 필요할 텐데, 아마 `Ctrl+N` 같은 키 입력이 좋겠습니다.

**7-11 _디스플레이 리스트를 통한 클릭_.** 지금 우리 브라우저는 클릭 위치를 페이지 좌표로 변환한 다음 그 좌표에 있는 레이아웃 객체를 찾습니다. 하지만 그 대신 그 위치의 그리기 명령을 먼저 찾고, 그 그리기 명령으로부터 그것을 만들어 낸 레이아웃 객체로 갈 수도 있습니다. 이를 구현하세요. 그리기 명령이 자신을 만들어 낸 레이아웃 객체를 알아야 합니다.[^17]
