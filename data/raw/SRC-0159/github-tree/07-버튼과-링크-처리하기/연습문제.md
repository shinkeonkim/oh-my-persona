# 7장 연습문제 구현

[← 7장 결과물로](결과물.md) · [← 본문으로](버튼과-링크-처리하기.md#연습문제)

본문의 연습문제 11개를 모두 구현했습니다. `lab7.py` 는 그대로 두고, 1~6장 연습문제를
이어받아 그 위에 7장 기능을 얹은 것을 `ex7.py` 에 정의했습니다.

7장에서 **줄과 낱말이 각각 레이아웃 객체**(`LineLayout` / `TextLayout`)가 되므로,
3~6장에서 만든 배치 기능도 그 구조로 옮겨 담았습니다. 가운데 정렬은 줄이 자기
자식들을 밀고, 위 첨자는 낱말이 자기 정렬 방식을 알고, 스몰 캡은 낱말 하나가
`TextLayout` 여러 개가 됩니다.

## 실행

```bash
python3 ex7.py https://browser.engineering/
```

## 검증

```bash
python3 test_ex7.py
```

71개 테스트로 확인합니다. 네트워크는 쓰지 않고 `data:` URL 로 페이지를 만듭니다.
마지막 묶음은 1~6장 연습문제가 새 레이아웃 구조에서도 도는지 보는 회귀 테스트입니다.

## 구현 내용

| 문제 | 제목 | 구현 위치 | 요점 |
|---|---|---|---|
| 7-1 | 백스페이스 | `AddressBar.backspace` | 커서 앞 한 글자를 지웁니다. 빈 문자열에서도 안전합니다 |
| 7-2 | 가운데 클릭 | `Tab.link_at`, `Browser.handle_middle_click` | 링크 찾기를 `click` 에서 떼어 내서 새 탭이 재활용합니다 |
| 7-3 | 창 제목 | `Tab.title`, `Browser.set_title` | `<title>` 이 없거나 비어 있으면 URL 로 대신합니다 |
| 7-4 | 앞으로 가기 | `History` | `past`/`future` 두 개의 스택. 새로 이동하면 `future` 를 비웁니다 |
| 7-5 | 프래그먼트 | `URL.fragment`, `Tab.scroll_to` | 같은 페이지면 다시 읽지 않고 스크롤만 합니다 |
| 7-6 | 검색 | `looks_like_url`, `address_to_url` | 공백이 있거나 점이 없으면 검색어로 봅니다 |
| 7-7 | 방문한 링크 | `Tab.mark_visited_links` | 방문한 `<a>` 에 `visited` 클래스를 붙입니다 |
| 7-8 | 북마크 | `toggle_bookmark`, `bookmarks_page` | `about:bookmarks` 는 HTML 을 만들어 돌려주는 URL 입니다 |
| 7-9 | 커서 | `AddressBar` | `cursor` 는 글자 사이 위치라 0 부터 `len(text)` 까지입니다 |
| 7-10 | 여러 창 | `Browser(root=...)`, `WINDOWS` | 탭은 자기 창이 들고, 창은 모듈 목록이 들고 있습니다 |
| 7-11 | 디스플레이 리스트를 통한 클릭 | `DrawCommand.node`, `Tab.link_at` | 그리기 명령이 자기를 만든 노드를 기억합니다 |

## 설계 메모

**7-7 이 6장 덕을 봤습니다.** 방문한 링크를 보라색으로 칠하는 데 그리기 코드를
건드릴 필요가 없었습니다. 스타일을 입히기 전에 방문한 `<a>` 에 `visited` 클래스를
붙이고, 기본 스타일시트에 `a.visited { color: purple; }` 한 줄을 넣는 것으로
끝납니다. 6-3 의 클래스 선택자가 그대로 일합니다.

**7-11 이 7-2 를 쉽게 만들었습니다.** 클릭 좌표에서 링크를 찾는 일을 `Tab.link_at`
으로 떼어 놓으니, 보통 클릭은 그것을 열고 가운데 클릭은 그것을 새 탭에 넘기면
됩니다. 그리기 명령마다 `node` 를 달아 둔 덕에 좌표 → 명령 → 노드 → `<a>` 로
곧장 갑니다.

**7-5 는 "같은 페이지인가"를 물어야 합니다.** 프래그먼트만 다른 링크에서 페이지를
다시 읽으면 스크롤 위치도 폼 상태도 날아갑니다. `URL.same_page` 로 프래그먼트를
뺀 나머지를 견주어, 같으면 `scroll_to` 만 합니다.

**7-9 는 커서를 "글자 사이"로 봅니다.** 인덱스가 아니라 사이의 자리라서 0 부터
`len(text)` 까지 `len+1` 개입니다. `insert` 는 그 자리에 끼워 넣고 커서를 한 칸
밀고, `backspace` 는 커서 **앞** 글자를 지우고 커서를 당깁니다.

**`data:` URL 을 퍼센트 디코딩합니다.** 테스트에서 네트워크 없이 페이지를 만들려고
`data:` URL 을 쓰는데, RFC 2397 대로 내용이 퍼센트 인코딩돼 있습니다. 디코딩을
넣지 않으면 `%EB%91%98` 같은 글자가 그대로 화면에 나옵니다.
