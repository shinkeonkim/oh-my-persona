# 15장 연습문제 구현

[← 15장 결과물로](결과물.md) · [← 본문으로](임베디드-콘텐츠-지원하기.md#연습문제)

본문의 연습문제 12개를 모두 구현했습니다. `lab15.py`·`browser15.css`·`runtime15.js`
는 그대로 두고, 1~14장 연습문제를 이어받아 그 위에 15장 기능을 얹은 것을
`ex15.py`·`ex15_sdl.py`·`runtime15ex.js` 에 두었습니다.

15장 본문 기능(이미지, iframe, `Frame`, `postMessage`)도 함께 들어 있습니다.

## 실행

```bash
python3 server10ex.py               # 다른 터미널에서
python3 ex15_sdl.py http://localhost:8000/
```

`Ctrl` + `Backspace` 가 뒤로 가기입니다(15-10).

## 검증

```bash
python3 test_ex15.py
```

93개 테스트로 확인합니다. 이미지는 그때그때 만든 PNG 를 `data:` URL 로 넣어
쓰므로 네트워크가 필요 없습니다.

## 구현 내용

| 문제 | 제목 | 구현 위치 | 요점 |
|---|---|---|---|
| 15-1 | `canvas` 요소 | `CanvasLayout`, `CanvasContext` | 명령을 모아 두었다가 페인트 때 되돌립니다 |
| 15-2 | 배경 이미지 | `parse_url_value`, `Frame.load_background` | 배경색 위, 글자 아래 |
| 15-3 | `object-fit` | `object_fit_rect` | `contain`/`cover`/`none`/`scale-down` |
| 15-4 | 지연 로딩 | `is_lazy`, `Frame.load_image` | `loading=lazy` 는 나중에 |
| 15-5 | iframe 종횡비 | `parse_aspect_ratio`, `size_from_ratio` | 하나만 주면 나머지를 채웁니다 |
| 15-6 | 이미지 자리 표시자 | `placeholder_size`, `should_hide_broken` | `alt` 가 없으면 아예 숨깁니다 |
| 15-7 | 미디어 쿼리 | `Frame.media`, `Frame.layout` | 프레임마다 자기 너비로 |
| 15-8 | `postMessage` 의 대상 출처 | `origin_matches` | 안 맞으면 조용히 버립니다 |
| 15-9 | 다중 프레임 포커스 | `frame_tab_order`, `next_focus` | 프레임을 넘나드는 한 줄의 탭 순서 |

## 설계 메모

**두 개의 진짜 버그가 15장에서 드러났습니다.**

첫째, 8장의 `resolve()` 는 결과를 `str()` 로 한 번 거치는데, `data:` URL 의
`__repr__` 는 내용을 `...` 로 줄여 버립니다. 지금까지는 `data:` 를 상대 주소로 풀
일이 없어 드러나지 않았지만, 이미지와 iframe 이 `src` 로 `data:` URL 을 받는
순간 내용이 통째로 사라집니다. `resolve()` 헬퍼를 두어 절대 주소는 원문 그대로
다시 파싱하게 했습니다.

둘째, CSS 값 파서가 `;` 를 무조건 선언의 끝으로 봤습니다.
`background-image: url(data:image/png;base64,...)` 에서 값이 `url(data:image/png`
에서 잘립니다. CSS 는 `url(...)` 을 토큰 하나로 보므로 **괄호 깊이**를 세야 합니다.
`CSSParser15.value` 가 그렇게 합니다.

**15-7 은 배치와 스타일의 순서 문제입니다.** iframe 안의 문서를 읽을 때는 아직
그 프레임의 너비를 모릅니다. 너비는 부모가 `IframeLayout` 을 배치하면서 정해
줍니다. 그래서 `Frame.layout()` 이 너비가 바뀐 것을 알아채면 **먼저 다시
스타일을 입히고** 나서 배치합니다. 그래야 `max-width` 쿼리가 프레임의 실제 너비를
보고 판단합니다.

**15-6 의 자리 표시자는 "크기를 아는가"가 기준입니다.** `width`/`height` 나
`aspect-ratio` 로 크기를 알 수 있으면 그만큼 자리를 잡아 두고, 모르면 0×0 입니다.
그래야 이미지가 늦게 도착해도 페이지가 덜 출렁입니다. `alt` 가 없는 깨진 이미지는
읽어 줄 것도 보여 줄 것도 없으므로 아예 그리지 않습니다.

**15-9 는 프레임들을 한 줄로 폅니다.** 각 프레임의 포커스 대상을 프레임 순서대로
이어 붙여 하나의 목록을 만들고, 탭은 그 목록을 돕니다. 프레임 경계를 넘을 때
이전 프레임의 포커스를 풀어 주어 포커스가 언제나 하나만 남습니다.

**15-11 은 9-7 이 이미 뚫어 둔 자리를 씁니다.** 스크립트가 서브트리를 붙이고 뗄
때 지나가는 `attach_resources`/`detach_resources` 에 iframe·이미지·캔버스를
더했습니다. 새로 들어온 iframe 은 읽고, 나가는 iframe 은 자식 프레임 목록에서
빼고 그 자바스크립트 문맥을 버립니다.
