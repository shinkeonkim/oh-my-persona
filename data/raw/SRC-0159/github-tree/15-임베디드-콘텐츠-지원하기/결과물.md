# 15장 결과물 — 임베디드 콘텐츠 지원하기

[← 본문으로 돌아가기](임베디드-콘텐츠-지원하기.md)

15장까지 따라 만들면 완성되는 브라우저입니다. 1장부터 이 장까지의 코드가 모두 들어 있어 `code/` 폴더에서 바로 실행할 수 있습니다.

## 이 시점의 브라우저가 할 수 있는 일

- `<img>` 로 이미지를 내려받아 그린다
- `<iframe>` 으로 페이지 안에 페이지를 띄운다
- 동일 출처 프레임끼리 JS 컨텍스트를 공유하고, 교차 출처는 `postMessage` 로 통신한다

## 실행

```bash
cd code
python3 lab15.py https://browser.engineering/
```

폼·쿠키·스크립트를 시험하려면 다른 터미널에서 웹 서버를 함께 띄우고 `http://localhost:8000/` 에 접속하세요.

```bash
python3 server12.py
```

## 필요한 것

- tkinter (파이썬 표준. 배포판에 따라 `python3-tk` 설치가 필요할 수 있습니다)
- dukpy
- skia-python
- pysdl2
- pysdl2-dll
- PyOpenGL

```bash
python3 -m pip install dukpy skia-python pysdl2 pysdl2-dll PyOpenGL
```

## 이 장에서 새로 추가된 것

`lab15.py` 는 이 장에서 새로 생기거나 바뀐 코드만 담고, 나머지는 이전 장 파일에서 import 합니다.

- 새 클래스: `URL`, `DrawImage`, `DocumentLayout`, `BlockLayout`, `EmbedLayout`, `InputLayout`, `LineLayout`, `TextLayout`, `ImageLayout`, `IframeLayout`, `AttributeParser`, `HTMLParser`, `JSContext`, `AccessibilityNode`, `FrameAccessibilityNode`, `Frame`, `CommitData`, `Tab`, `Browser`
- 기존 클래스 확장: `AccessibilityNode`, `BlockLayout`, `Browser`, `DocumentLayout`, `HTMLParser`, `JSContext`, `LineLayout`, `Tab`, `TextLayout`, `URL`, `style`
- 새 함수: `parse_image_rendering`, `paint_tree`, `font`, `style`
