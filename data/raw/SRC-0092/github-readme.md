## 개요

TCP 소켓 프로그래밍을 이용하여 고정 길이와 가변 길이 데이터를 서버와 클라이언트 간에 주고받는 프로그램을 작성한다.

## 파일 설명

- `main.cpp`: TCP 클라이언트 프로그램
- `server.cpp`: TCP 서버 프로그램
- `Makefile`: 컴파일 및 실행을 위한 Makefile
- `README.md`: 프로젝트 설명 파일

## 컴파일 및 실행 방법

### 1. Make를 활용합니다. (make에 대한 별도 설명은 생략)

### 2. 서버와 클라이언트를 실행합니다.

#### 2.1. 서버와 클라이언트 동시 실행 방법

make run 명령어로 서버와 클라이언트를 실행합니다.

```bash
make run
```

이떄 다음과 같은 동작이 수행됩니다.

1. 서버 프로그램이 백그라운드에서 실행됩니다.
2. 1초 대기 후 클라이언트 프로그램이 실행됩니다.
3. 클라이언트 프로그램이 종료되면 서버 프로그램도 종료됩니다.
4. make clean 명령어로 컴파일된 파일들을 삭제합니다.

#### 2.2. 서버와 클라이언트를 각각 실행하는 방법

1. 서버 프로그램을 먼저 실행합니다.

```bash
make server
```

2. 다른 터미널에서 클라이언트 프로그램을 실행합니다.

```bash
make client
```
