# TreeFellerPlugin (찹트리)

## 간단한 요약

나무의 밑동을 도끼로 부수면 위로 이어진 통나무 전체가 한 번에 파괴되는 편의 기능 플러그인입니다.

## 설명

나무를 벨 때 통나무를 한 칸씩 올라가며 부수는 번거로움을 없애기 위한 "찹트리(chop tree)" 류 기능을 구현합니다.

- **동작 조건**: 손에 도끼(`*_AXE`)를 들고, 아래쪽이 통나무가 아닌 지점(=나무의 밑동)을 부쉈을 때만 발동합니다. 나무 중간을 부수면 원래대로 그 한 칸만 부서집니다.
- **연결된 통나무 탐색**: `BlockBreakEvent`를 가로채서(`TreeChopListener`), 부순 블록을 시작점으로 3x3x3 이웃(대각선 가지 포함)을 따라가는 BFS(`collectTree`)로 `org.bukkit.Tag.LOGS`에 해당하는 블록들을 전부 모읍니다.
- **크기 제한**: 연결된 통나무 개수가 `MAX_TREE_SIZE`(128개)를 넘으면 안전하게 포기하고 평범하게 한 칸만 부서지며, 플레이어에게 "나무가 너무 커서 한 번에 베지 못합니다" 메시지를 보냅니다. 통나무로 지은 건축물 전체가 실수로 연결되는 사고를 막기 위한 안전장치입니다.
- **드롭/내구도 처리**: 모아진 통나무들은 `Block#breakNaturally(tool)`로 순서대로 파괴됩니다. 이 API는 실제 파괴 판정(드롭 계산, 도구 내구도 소모)을 그대로 재현하면서 `BlockBreakEvent`를 다시 발생시키지 않아 무한 재귀를 피합니다. 도끼가 파괴 도중 내구도가 다 닳아 사라지면("도끼가 다 닳아서 나머지는 베지 못했습니다") 남은 통나무는 베지 않고 중단합니다.
- **그리핑 방지(핵심 안전장치)**: `LogPlacementListener`가 `BlockPlaceEvent`/`BlockBreakEvent`를 감시해 플레이어가 직접 심거나 건축용으로 설치한 통나무 위치를 `TreeFellerPlugin.playerPlacedLogs`(월드:x:y:z 키 집합)에 기록합니다. 나무 전체를 훑을 때 이 목록에 있는 블록은 탐색에서 제외되어, 자연 나무를 베어도 인접한 플레이어의 건축물까지 함께 부서지지 않습니다.
  - **알려진 한계**: 이 플러그인을 설치하기 이전에 이미 세워져 있던 플레이어의 통나무 건축물은 추적 기록이 없어 "자연 나무"로 오인될 수 있습니다. 설치 이후 새로 짓는 건축물부터는 정확히 추적됩니다.
- 이 플러그인이 의존하거나 이 플러그인에 의존하는 다른 플러그인은 없습니다.

`src/test/kotlin/com/example/treefeller/TreeFellerPluginTest.kt`에 [MockBukkit](https://github.com/MockBukkit/MockBukkit) 기반 단위 테스트가 있으며, 다음 시나리오를 검증합니다:
- 자연 나무의 밑동을 도끼로 부수면 통나무 전체가 사라지는지
- 나무 중간을 부수면 그 한 칸만 사라지는지
- 도끼가 아닌 도구로는 한 칸만 부서지는지
- 플레이어가 심은 통나무는 자연 나무를 베어도 함께 사라지지 않는지

## 사용 방법(매뉴얼)

이 플러그인은 별도의 명령어나 권한 노드, `config.yml` 설정 없이 동작합니다. 도끼를 들고 나무 밑동을 부수기만 하면 자동으로 발동합니다.

### 빌드

저장소 루트에서:

```bash
./scripts/build-plugin.sh minecraft-treefeller-plugin
```

### 테스트 실행

플러그인 디렉터리에서:

```bash
./gradlew test
```
