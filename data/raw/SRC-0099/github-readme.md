# AutoFurnacePlugin

## 요약

화로(일반 화로/용광로/훈연기) 바로 위에 상자류 블록을 놓으면, 그 상자의 원료와 연료를 자동으로 화로에 채워주고 완성된 결과물을 다시 상자로 꺼내주는 편의 플러그인입니다. 명령어나 설정 없이 블록 배치만으로 동작합니다.

## 설명

- **자동화 대상 등록/해제** (`FurnaceRegistryListener`): `BlockPlaceEvent`/`BlockBreakEvent`를 감시하다가 `FURNACE`, `BLAST_FURNACE`, `SMOKER` 블록이 설치되면 해당 위치를 `world:x:y:z` 형태의 키로 만들어 등록 목록(`AutoFurnacePlugin.furnaceKeys`)에 추가하고, 파괴되면 목록에서 제거합니다.
- **주기 점검 작업** (`AutoFurnaceTask`): 플러그인이 활성화될 때 `BukkitScheduler#runTaskTimer`로 40틱(2초)마다 등록된 모든 화로를 순회하며 다음 순서로 처리합니다.
  1. **빈 양동이 회수**: 연료 슬롯에 `BUCKET`(빈 양동이)이 남아 있으면 위쪽 상자로 돌려보내고 슬롯을 비웁니다. (용암 양동이가 다 타고 남은 빈 양동이가 연료 슬롯을 막는 문제를 방지)
  2. **연료 보충**: 연료 슬롯이 비어 있으면 위쪽 상자에서 연료 아이템(`COAL`, `CHARCOAL`, `COAL_BLOCK`, `LAVA_BUCKET`, `BLAZE_ROD`)을 찾아 채웁니다.
  3. **원료 보충**: 제련 원료 슬롯이 비어 있으면 위쪽 상자에서 연료류/빈 양동이가 아닌 첫 아이템을 찾아 채웁니다.
  4. **결과물 배출**: 화로의 결과 슬롯에 완성품이 있으면 위쪽 상자로 옮깁니다.
  - 자동화 대상이 되려면 화로 **바로 위 블록**이 인벤토리를 가진 블록(상자, 트랩상자 등 `InventoryHolder`)이어야 합니다.
  - 점검 중 더 이상 화로가 아니게 된(예: 언로드되었거나 다른 방식으로 사라진) 위치는 목록에서 자동으로 정리됩니다.
- 다른 플러그인에 대한 의존성은 없습니다.

## 사용 방법

이 플러그인은 등록된 명령어와 권한 노드가 없습니다. 화로 바로 위에 상자류 블록을 설치하면 자동으로 동작합니다.

- **명령어**: 없음
- **권한**: 없음
- **config.yml**: 없음 (설정 항목 없음)

### 빌드 방법

저장소 루트에서 다음을 실행합니다.

```bash
./scripts/build-plugin.sh minecraft-autofurnace-plugin
```
