# minecraft-rtp-plugin

## 간단한 요약
`/rtp` 명령어로 플레이어를 현재 월드의 무작위 위치 중 안전한 곳으로 순간이동시켜 주는 Paper(Kotlin) 플러그인입니다. 스폰 근처 과밀을 줄이고 새 거점을 찾는 플레이어를 흩어지게 해줍니다.

## 설명

### 주요 기능
- **랜덤 텔레포트 범위**: 명령어 인자로 반경(radius)을 지정할 수 있으며, 100 ~ 50,000 사이 값으로 제한(clamp)됩니다. 인자를 생략하면 기본 반경 `5000`이 적용됩니다. 좌표는 `(-radius, radius)` 범위에서 X, Z를 각각 무작위로 뽑습니다.
- **안전한 위치 탐색 로직**: 뽑은 (x, z) 좌표에 대해 다음을 확인해 안전 여부를 판정합니다.
  - `World#getHighestBlockYAt`으로 지면 Y좌표를 구하고, 그 값이 월드 최저 높이 + 4 이하면(허공/공허에 가까움) 실패 처리합니다.
  - 지면 블록이 고체(solid)가 아니거나, 용암·물·불·선인장·마그마 블록·가루눈(LAVA, WATER, FIRE, CACTUS, MAGMA_BLOCK, POWDER_SNOW) 중 하나면 실패 처리합니다.
  - 착지 지점 위 두 칸(머리 높이, 그 위)이 모두 공기(AIR)가 아니면 실패 처리합니다.
  - 안전하지 않으면 좌표를 다시 뽑아 재시도하며, 최대 시도 횟수는 `10회`(`MAX_SAFETY_ATTEMPTS`)입니다. 10회 안에 안전한 곳을 찾지 못하면 "안전한 위치를 찾지 못했습니다" 메시지를 보내고 종료합니다.
- **비동기 청크 로드**: 좌표를 뽑을 때마다 `World#getChunkAtAsync`로 해당 청크를 비동기로 로드한 뒤, 완료 콜백에서 메인 스레드(`Bukkit.getScheduler().runTask`)로 돌아와 안전 검사와 텔레포트를 수행합니다. 텔레포트 자체는 `Player#teleportAsync`를 사용합니다. 즉 메인 스레드를 막지 않는 방식으로 동작합니다.
- **쿨다운**: 플레이어별로 마지막 텔레포트 시각을 메모리(`Map<UUID, Long>`)에 저장해, `30초`(`COOLDOWN_MILLIS`) 이내 재사용을 막습니다. 쿨다운 중에는 남은 초를 안내하는 메시지가 표시됩니다. 쿨다운은 실제로 안전한 위치를 찾아 텔레포트에 성공한 시점에만 갱신되며, 플러그인이 비활성화(`onDisable`)되면 초기화됩니다.
- **월드 제한**: 별도의 월드 화이트/블랙리스트는 없습니다. 명령어를 실행한 플레이어가 현재 있는 월드(`player.world`) 안에서만 랜덤 좌표를 뽑습니다.
- 플레이어가 아닌 콘솔 등에서 명령어를 실행하면 "플레이어만 사용할 수 있습니다" 메시지만 표시하고 종료합니다.

### 의존성
다른 플러그인에 대한 의존성은 없습니다(Paper API만 사용).

### 설정 파일
`config.yml`은 존재하지 않습니다. 반경 기본값(5000), 쿨다운(30초), 최대 안전 탐색 횟수(10회) 등은 모두 소스 코드 상수(`RtpPlugin.kt`)로 하드코딩되어 있으며, 별도의 설정 파일을 통한 변경은 지원하지 않습니다.

## 사용 방법(매뉴얼)

### 명령어
| 명령어 | 설명 |
| --- | --- |
| `/rtp` | 기본 반경(5000블록) 내 무작위 안전 위치로 순간이동 |
| `/rtp <반경>` | 지정한 반경(100~50000 범위로 자동 보정) 내 무작위 안전 위치로 순간이동 |

- 명령어는 Paper의 Brigadier `BasicCommand`(`RtpCommand`)로 등록되며, 플러그인 `onEnable`에서 `registerCommand("rtp", RtpCommand(this))`로 등록됩니다.
- 쿨다운(30초) 중 재사용 시 남은 시간을 알려주는 메시지가 표시됩니다.

### 권한 노드
소스 코드 및 `paper-plugin.yml`에 별도로 등록된 권한(permission) 노드가 없습니다. 즉 `/rtp` 명령어는 서버에 접속한 모든 플레이어가 별도 권한 없이 사용할 수 있습니다.

### 빌드 방법
저장소 루트에서 다음 명령을 실행합니다.

```bash
./scripts/build-plugin.sh minecraft-rtp-plugin
```
